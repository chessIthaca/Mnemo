BUG (2027-01-11, plan 9441d776; live case plan c87093c1): bug_fixing "## Detailed steps" persisted as raw text with no per-sub-step completion state — a mid-fix restart resumed against an unchecked "Minimal fix" mega-step plus a wall of detail text; nothing recorded which sub-steps shipped (c87093c1: ~2000 lines across 5 files in one unchecked step; would not have survived restart). Root cause: src/workflow/plan_file.rs Section::DetailedSteps accumulated raw lines into Option<String> (parse_checkbox only ran in Section::Steps); serialize wrote the body verbatim; no tool could flip a mark. Fix: structured Vec<Step> with checkbox parse/serialize (legacy plain-dash lines = unchecked sub-steps, non-dash lines = continuations preserving the escape round-trip), complete_step gains detailed_step_index (1-indexed tick, no state transitions — sub-steps never trigger Reviewing/Complete), create_plan renders "- [ ] {text}". Regression tests: create_plan_bug_fixing_renders_detailed_steps_as_checkable_substeps (red→green) + bug_fixing_detailed_step_ticks_survive_restart (killed-and-resumed acceptance).
