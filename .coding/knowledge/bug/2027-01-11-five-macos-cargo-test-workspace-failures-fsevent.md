Symptom (v0.1.1 release run 35521221353, macOS CI leg `cargo test --workspace`): five failures — secondary_udf_is_per_pid_under_webview2 (hardcoded backslash expected path), watcher_spawns_and_indexes_outside_runtime + watcher_reindexes_on_new_source_file ("watcher must auto-index…"), profile_dir_is_removed_on_close (profile dir outlives the 15s poll), tools_array_stays_within_context_budget (deferral delta 11246 < 12000).

Root causes: (1) watcher — FSEvents delivers event paths with symlinks resolved, so a watched root under a symlink (every macOS tempdir: /var → /private/var) never prefix-matched in is_indexable_path (plain strip_prefix) and the watcher filtered ALL events out; (2) webview test — platform-shaped assertion, production fn is a pure join (no production bug); (3) profile test — macOS Chromium lock-release timing, undiagnosable from a Windows host; (4) deferral — the browser deferred group carries six Windows-only WebView2 tools (factory.rs:1127, cfg(windows)), so the macOS all-loaded array is ~3.5k chars smaller and the delta is inherently below 12k (Windows measures 14700; default array identical at 32796 on both sides — NOT feature unification).

Fix (plan 5cff52cf, wt/mnemo): is_indexable_path retries the component check against canonicalize(root) on raw miss (Windows fast path unchanged, fallback inert there); webview test asserts structure (component-wise ends_with + parent chain); profile test cfg(windows)-gated and deferral block cfg(all(feature="browser", windows))-gated per user decision 2026-09-20 (platform-gate over recalibrate/widen); watcher test poll budgets doubled as FSEvents-latency insurance. Regression test: is_indexable_path_accepts_canonical_event_paths (cfg(unix), src/codegraph/watcher.rs — fail-first on Unix; live fail-first evidence is run 35521221353).
