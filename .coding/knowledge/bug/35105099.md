Symptom: Rust tests create their temp folders in the user's system temp dir (C:\Users\<user>\AppData\Local\Temp on this machine — outside the repo and on another drive) and many are never deleted: about 31,000 `.tmpXXXXXX` folders built up in two days (an earlier cleanup removed about 120,000 more). Measured on 2026-11-24: one `cargo test --lib` run of the root crate (3,761 tests) left 12 folders, two still holding `.coding/memory.db` with its `-wal` and `-shm` files and ten empty. Older leftovers also hold `.worktrees`, `team.json` and `transcripts`, so the mnemo-app/mnemo2 team tests and the integration tests leak too. · regression test: temp_dir_is_inside_the_checkouts_target_dir
