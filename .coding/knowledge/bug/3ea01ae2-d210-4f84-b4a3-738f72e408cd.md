Symptom: Backlog items are marked failed ("plan loop did not close (workflow: Skill)") even though the work is done and merged into main. Root cause: TurnResolveLatch defers success resolution when the main agent finishes while descendants (reviewers) are running, but never flushes the deferred success when descendants drain — only deferred failures are flushed. The resolution slides to a later turn (e.g. a merge skill) where the workflow state is wrong. · regression test: deferred_success_is_flushed_when_descendants_drain
