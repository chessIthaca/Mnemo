Symptom: After a merge, a worker's checkout under .worktrees/agent-* can be left half-removed: git deregisters the worktree but the folder stays (Windows file locks), and the merge reports "merged, but worktree cleanup needs attention: git status --porcelain failed: fatal: not a git repository". Such workers can then never be deleted in Mnemo2: delete refuses with "its checkout could not be read" or, when only fragments without .git remain, "its checkout is on 'wt/mnemo', not wt/agent-…" because git resolves the folder to the main repo. The user had 11 undeletable workers this way. · regression test: a_leftover_checkout_does_not_block_deleting_its_worker
