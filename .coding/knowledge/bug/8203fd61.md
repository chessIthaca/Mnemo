Symptom: Mnemo2 refuses a project folder it created itself: "C:\mnemo\.coding\mnemo2 was not created by Mnemo2 on this machine (it may have come with the repository)…". Under Claude Desktop (an MSIX package) Windows gives processes below it a private copy of AppData\Roaming\com.mnemo.mnemo2, so a Mnemo2 started by the plugin and one started by the user hold two different state-owner-id values and each refuses the other's project stamps. · regression test: two_app_data_views_converge_on_one_shared_owner_id
