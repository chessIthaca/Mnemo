Symptom: At startup Mnemo restores the persisted window size/position verbatim: the user observed a tiny window at the top-left of the screen. The OS-level min_inner_size (main.rs:244) does not constrain the restore's programmatic setSize() (frontend/src/App.tsx:524), and the position gate (≥80px overlap on any monitor) passes near-origin rects — a saved geometry from a different monitor/DPI (e.g. RDP resolution change) restores unusably small and mispositioned. Root cause: no clamp in the startup restore path (frontend/src/App.tsx:478-531), plus outer/inner size asymmetry causing cross-restart drift. · regression test: clampRestoredGeometry
