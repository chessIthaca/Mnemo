Symptom: A lead's reply to a read-back ("proceed as specified", "your proposals stand, implement") and a team_route_fix prompt draw a Laya nudge "this got harder (Laya reads the message as involved, 1.00); consider team_resume with tier medium", although neither adds work. It fired on nearly every read-back answer on 2026-11-08 and the lead ignored all of them. Each misfire also spends the worker's one nudge, so a later genuine strike or review nudge never fires, and it writes a nudge_ignored row into the routing log. · regression test: read_back_answer_draws_no_drift_nudge

Root cause: the drift check classified every delivered message of 20+ words on its text alone, and these messages read like implementation specs. Fix: message_can_show_drift (src-tauri/src/mnemo2/team/nudge.rs) keeps Mnemo2's own text and a read-back worker's first lead or user message out of the check; any other lead or user message is still classified. Second regression test: route_fix_prompt_draws_no_drift_nudge.
