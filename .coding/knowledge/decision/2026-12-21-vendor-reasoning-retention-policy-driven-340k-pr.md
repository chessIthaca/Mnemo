DECISION (plan ffe59699, 2026-12-22): vendor-specific reasoning retention is policy-driven via ReasoningRetention on ProviderPolicy (src/provider/policy.rs) — Gemini {keep_recent:1, historical_droppable:true, signatures_required:true} drops historical thinking text but keeps thought_signatures; DeepSeek {1,false,false} drops historical reasoning_content ONLY under cache pressure (estimate_prompt_tokens + PROXY_CACHE_PRESSURE_MARGIN_TOKENS=32_768 > PROXY_CACHE_CEILING_TOKENS=340_000); all other providers NEVER_STRIP (full Rule-1 verbatim echo, age 0 always protected). Strip is WIRE-ONLY — stored Message::raw never mutated; applied in OpenAiClient::build_request_json on both raw-echo and synthetic paths (anthropic.rs needs none: claude is NEVER_STRIP). Compaction ceiling: ContextManager.effective_summarize_at() = min(summarize_at, ceiling − margin), wired at both check sites, config context.proxy_cache_ceiling_tokens (default Some(340_000), 0 disables, validation >=65_536), Settings→Advanced UI control (null=cleared, saves 0). Rationale: thinking tokens outnumber completion 3:1–10:1; Rule-1 raw echo balloons history; LiteLLM-class proxies drop whole-conversation prefix caching above ~340K input tokens (hit rate ~99%→~4%). Full detail lives in the code + tests: policy.rs (retention_values_per_provider, strips_reasoning_matrix), mod.rs (strip_reasoning_text_fields_* tests), openai.rs (retention_gemini_*/retention_deepseek_*/retention_qwen_*/retention_strip_is_repeatable_*), context.rs (proxy_cache_ceiling_caps_effective_summarize_at), settings_dto.rs (proxy_cache_ceiling_validation_rejects_tiny_and_accepts_disable_or_sane). Design doc: this record IS the knowledge sidecar (memory system auto-file); PLAN.md "Prompt caching strategy" bullet (items 6–7) + reasoning-state paragraph carry the user-facing summary.
