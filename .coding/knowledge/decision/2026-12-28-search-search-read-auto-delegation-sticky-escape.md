DECISION (2026-12-29, plan 7b77cf0c, backlog b804012f): search/search_read auto-delegation design — (1) STICKY ESCAPE KEY: the last delegated query (pattern+glob+literal) is stored on the tool (Arc<Mutex<Option<DelegatedKey>>>); an immediate repeat skips delegation and runs the plain search, and the key persists until a DIFFERENT query delegates (no delegate/escape ping-pong). (2) STEERING COHERENCE: the delegated block's first line carries the byte-pinned "is an indexed symbol" marker, and observe_result auto-registers a SWITCH when the first line carries "AUTO-DELEGATED" — delegated answers count as fires AND switches, so the C5 intercept gate never punishes delegation (without this, 2 delegations = 2 "ignored" fires → the 3rd symbol search would be intercepted). (3) EXACT-ONLY delegation: symbol_delegation_block resolves via resolve_exact (name == symbol name), matching the nudge's symbol_id semantics — fuzzy substring candidates keep the advisory alternation-absorption note (conservative; "update" must not delegate to "update_index"). (4) CONSERVATIVE memory detection: only a glob containing .coding/knowledge/.coding/reviews or a typed prefix (SPEC:/DECISION:/BUG:/PLAN:/HOW:/REVIEW:) fires memory delegation; a pattern merely MENTIONING the path stays a content search. (5) FAST-PATH: memory delegation (always) and symbol delegation without a glob skip the walk entirely and return the block as the whole output; a symbol hunt WITH a glob prepends the block above normal results. (6) The advisory nudge survives for the escape repeat + fuzzy alternations; the byte-pinned sentence is unchanged (assertions moved into the escape-repeat phase of the same tests).
