Agent-chat activity cards are FRAMELESS by design (user request 2026-12-28, plan 3de07a3b, commit 51bbe72 on wt/agenticcoding; extended to the memory/vision/skill families by backlog 900fe8d8, plan 10650092): no rounded-lg/border/background tint on the outer div of ANY activity card — ToolCard, MemoryEntryCard, VisionEntryCard, and the skill announcement case, all in frontend/src/components/chat/Message.tsx — just py-[0.125em]. Running/failed state is signaled redundantly by header text color (yellow-400/red-400) + animated dots + ✓/✗ + one-line error summary, so do NOT re-add a border/frame thinking it's missing styling. The tier badges' bg-violet-900/50 chip is a label treatment, not a card frame. Card BODY text inherits 1em of the chat content (--app-font-size) — no text-xs/text-sm/text-[0.875em] downscale on card containers (backlog 900fe8d8); labels/status keep a smaller em-based treatment (text-[0.75em] status/running/section labels/code pre blocks, text-[0.65em] tier badges). All utilities in the card components (Message.tsx) are em-based per SPEC: tool-card spacing must be em-based (4c2f16ba) — including the CallDetail pre-block scroll caps (max-h-[24em], resolving against the pre's own 0.75em font ≈ the old 16rem at the default size; review round-1 F1), the diff viewer's card-path scroll cap (CallDetail passes maxHeightClass="max-h-[24em]" to UnifiedDiffView; the shared max-h-64 default stays for non-card consumers — review round-2 L1), and the inter-card gap (transcript stack space-y-[0.5em], Conversation.tsx — converted from space-y-2 by the 900fe8d8 review, finding F4). Shared child viewers keep their own treatment (CodeBlock/InlineMarkdown for assistant prose; UnifiedDiffView's rem line padding) — the carve-out alongside the tier-badge chip. Pinned by the "frameless + normal-size cards (backlog 900fe8d8)" source-contract block in frontend/src/lib/toolCardPaths.test.ts (scoped via fnSrc over ToolCard/MemoryEntryCard/VisionEntryCard and caseSrc over the skill case: no frame classes, no rem utilities incl. text-sm/max-h-64, py-[0.125em] outer, affordances intact for memory + vision, the card-path diff cap pinned).
