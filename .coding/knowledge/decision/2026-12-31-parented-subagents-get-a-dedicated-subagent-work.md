DECISION (2026-01-03, plan 3fb064c4, backlog c5ded15d / round-3 review §6 of plan 75deaec0): parented subagents get a dedicated WorkflowState::Subagent instead of deriving the main plan's state. The user explicitly chose the restructure (option B) over the round-3 "keep + document" lean (option A, which the analysis recommended). Design: the plan stack still loads from the shared plans dir (read-only mirror — current_plan for reviewers + the UI staircase keep working, round-3 warning #1 addressed); the state never claims Executing/Reviewing; the model resolver deliberately drops the lifecycle-state fallback for subagents ([models.subagent] if set, else configured default — warning #2 made deliberate); subagent tabs report "Subagent" + the mirrored staircase (warning #3). The state is stamped by the parented spawn path (src-tauri/src/ipc/spawn.rs parented block), not by build_inner (which can't know parented-ness).

IMPLEMENTATION (plan 3fb064c4): WorkflowState::Subagent is a role-state variant like Skill (src/workflow/mod.rs; enter_subagent_state() keeps the loaded stack; Display "Subagent", serde "subagent"). ToolFilter::from_state returns None for it (src/tool/mod.rs) — Workflow::allowed_tools fails loudly on Subagent without an allow-list (invariant: compute_subagent_allowlist returns Some for every parented spawn). Model resolver: Subagent => None (src/model_resolver.rs) — subagent model = [models.subagent] else default, lifecycle tier deliberately gone. Prompt: new Subagent arm (PARENT PLAN read-only context/GOAL/PROGRESS + STATE_SUBAGENT guidance; the dead Planning/Executing sub-agent notes removed — src/agent/prompt.rs). Auto-continue: is_subagent() guard kept as belt-and-braces (workflow_expects_progress already false for Subagent — src/runtime/agent.rs). UI: frontend WorkflowState union + StatusBar label + PlanProgress slate badge + ModelsSection hints (subagents skip the state tier). Skills unavailable in Subagent state (no skill lists it) — deliberate. Pinning tests: subagent_stamp_replaces_derived_state_keeps_mirror (factory.rs), subagent_state_with_allowlist_uses_allowlist_filter + subagent_state_without_allowlist_fails_loudly (workflow/mod.rs), current_plan_on_subagent_state_returns_mirrored_plan (plan.rs), subagent_state_never_resolves_a_lifecycle_model (model_resolver.rs), workflow_section_subagent_shows_read_only_parent_plan (prompt.rs).
