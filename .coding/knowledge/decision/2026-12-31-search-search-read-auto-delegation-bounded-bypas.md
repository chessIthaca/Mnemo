DECISION (2026-12-29, plan 7b77cf0c, backlog b804012f; point 1 superseded 2026-01-03 by plan 2a78cc3c): search/search_read auto-delegation design — (1) BOUNDED BYPASS-KEY SET (supersedes the single sticky escape key): every delegated query's key (pattern+glob+literal) joins a bounded set on the tool (Arc<Mutex<Vec<DelegatedKey>>>, cap DELEGATION_SET_CAP=32, dedup + oldest-evict); a repeat of ANY recorded key skips delegation and runs the plain search, and keys are never displaced by other delegating queries — the 2026-12-29 session (plan 72329f2c) saw the old single-key design re-delegate an escaped query twice because an interleaved delegating search had replaced the key (no delegate/escape ping-pong either way). (2) STEERING COHERENCE: the delegated block's first line carries the byte-pinned "is an indexed symbol" marker, and observe_result auto-registers a SWITCH when the first line carries "AUTO-DELEGATED" — delegated answers count as fires AND switches, so the C5 intercept gate never punishes delegation (without this, 2 delegations = 2 "ignored" fires → the 3rd symbol search would be intercepted). (3) EXACT-ONLY delegation: symbol_delegation_block resolves via resolve_exact (name == symbol name), matching the nudge's symbol_id semantics — fuzzy substring candidates keep the advisory alternation-absorption note (conservative; "update" must not delegate to "update_index"). (4) CONSERVATIVE memory detection: only a glob containing .coding/knowledge/.coding/reviews or a typed prefix (SPEC:/DECISION:/BUG:/PLAN:/HOW:/REVIEW:) fires memory delegation; a pattern merely MENTIONING the path stays a content search. (5) FAST-PATH: memory delegation (always) and symbol delegation without a glob skip the walk entirely and return the block as the whole output; a symbol hunt WITH a glob prepends the block above normal results. (6) The advisory nudge survives for the escape repeat + fuzzy alternations; the byte-pinned sentence is unchanged (assertions moved into the escape-repeat phase of the same tests).
