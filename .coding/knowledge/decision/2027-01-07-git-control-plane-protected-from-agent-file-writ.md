DECISION: .git control plane protected from agent file writes (2027-01-09, plan eda38891, backlog 0296d448). is_protected_write_target (src/tool/agent/sandbox.rs) now refuses ANY path containing a .git component — the root control-plane dir + contents, nested repos' .git, and the linked-worktree .git plain file — with per-component trailing dot/space trimming (Win32 path normalization strips them, so mkdir(".git.") creates the real .git). Component EQUALITY only: .gitignore/.gitattributes/.gitmodules stay writable. Covers all five write gates: file_write/file_append (validate_for_write), file_edit/convert_line_endings (refuse_if_protected), and the IPC write_sandboxed mirror. Defense-in-depth: the agent git tool passes --no-verify on commit/merge (bypasses pre-commit/commit-msg/pre-merge-commit; prepare-commit-msg and post-* still run — acceptable because .git writes are refused by the sandbox and shell is the documented approval-gated residual; the user's own terminal git is unaffected). Rationale: planted hooks/core.fsmonitor execute unsandboxed on the next commit or an auto-approved git status (2027-01-09 security review HIGH-1). Commits f4a2e6d, 8f435d5, 0b55b23, 71b4cb1, 50969db on wt/agenticcoding; reports .coding/reviews/2026-09-10-git-sandbox-escape-review{,-round2,-round3}.md (round-3 PASS).
