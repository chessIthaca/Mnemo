src-tauri/tauri.conf.json `identifier` was renamed `com.mnemo.app` → `com.mnemo.desktop` (2027-01-16, plan 96fe545c, commit 37f8daa on wt/mnemo; round-2 review .coding/reviews/2026-09-18-macos-identifier-app-suffix-review-round2.md PASS). Reason: the release build warned the `.app` suffix conflicts with the macOS application-bundle extension. No code change was needed — src-tauri/src/webview_udf.rs:41-42 derives the WebView2 base/UDF and the named mutex from `_app.config().identifier`. CONSEQUENCES for future readers: (1) the Windows WebView2 default user-data folder moves %LOCALAPPDATA%\com.mnemo.app\EBWebView → %LOCALAPPDATA%\com.mnemo.desktop\EBWebView — a one-time cookie/OS-SSO profile reset for existing installs (acceptable: pre-release v0.1.0); (2) the macOS CFBundleIdentifier changes, so LaunchServices/TCC treat it as a new app identity; (3) an instance still running the OLD build holds the old mutex+UDF, so it neither collides with nor blocks a new-build primary. Live docs/fixtures were swept with it (webview_udf.rs module doc, src/webview_args.rs:243/:248, PLAN.md:353, docs/FEATURES.md:56, .coding/browser-debugging.md:133); .coding/knowledge/**, reviews/** and plans/** keep the old spelling deliberately (history).
