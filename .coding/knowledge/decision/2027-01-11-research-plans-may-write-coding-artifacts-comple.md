A — research plans may write NON-SOURCE artifacts under `.coding/**`. `ToolFilter::ExecutingResearch` still denies the four write tools BY NAME, so the advertised tools array stays the ONE plan-frozen surface for every plan kind (prefix-cache law); the grant is a dispatch-time path-scoped verdict — src/agent/dispatch.rs: `RESEARCH_ARTIFACT_TOOLS` + `research_write_verdict` → `Artifact | NotAnArtifact | Protected | NotApplicable`, granting only non-protected `.coding/**` targets (`Sandbox::is_artifact_write_target` = first component `.coding` case-insensitively, a second component present, and NOT `is_protected_write_target`). Both resolution branches require `Sandbox::lexical_path_is_link_free` before granting, so ANY surviving symlink/junction component — including a dangling leaf, which `validate`'s parent-fallback leaves unresolved — fails closed to `NotApplicable`; protected-target and research-boundary denials carry distinct messages. The gate fires only under exact `ToolFilter::ExecutingResearch` equality, so reviewer/skill allow-list overlays lose the carve-out (fail closed). NOT a security boundary: shell stays visible.

D — a non-reviewing root owes a review when a sub-plan landed source work. `Workflow::review_required` (src/workflow/mod.rs) is armed on the pop of a COMPLETED or ABANDONED non-root sub-plan of kind `Implementation | BugFixing` ("was a sub-plan" = stack non-empty AFTER the pop; `stack.pop()` has exactly two sites), persisted in the stack sidecar with `#[serde(default)]` (a pre-field sidecar still loads) and restored before the skill early-return, cleared when a fresh root replaces the stack. The research root then completes into Reviewing (`reviewed = false`) instead of Complete. Root abandonment stays the sanctioned escape hatch; research sub-plan pops never arm it.
