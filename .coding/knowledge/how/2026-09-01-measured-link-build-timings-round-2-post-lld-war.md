Link-time research measurements (2026-12-07, toolchain 1.95.0, rust-lld active, Windows 11, NVMe). WARM loop is healthy post-lld: no-op build 0.4s; lib rlib incremental recompile 3.5s; app exe link (-p mnemo-app) 8.6s; cargo test --lib 13.7s (incl. 4.6s test run); FULL cargo test 19.4s (lib + 4 integration bins + tao_backport + doctests). KEY GOTCHAS learned: (1) `cargo build` at this workspace root builds ONLY the mnemo lib rlib (root package default-members) — no linking at all; the app needs -p mnemo-app or --workspace. mtime-only touches do NOT dirty cargo fingerprints — real (reverted) edits required for measurement. (2) First no-op-looking build measured 33.8s = full lib crate recompile after incremental-cache invalidation (Compiling lines are noise-filtered by the shell tool). (3) PDB mass: EVERY binary's PDB is ~470-490MB; target\debug = 158.1GB total (26.9GB across 2649 rlibs ≈ 4-5 stale variants per crate, 25.1GB across 392 PDBs, 84 exes incl. stale myharness_app relics from the old crate name). (4) Windows Defender real-time protection ON; exclusions not readable non-admin (action item). Number of separately-linked binaries per full test run: 6 (lib test, contract_fixtures, ipc_bridge, provider_integration, workflow_integration, tao_backport) + app exe.
