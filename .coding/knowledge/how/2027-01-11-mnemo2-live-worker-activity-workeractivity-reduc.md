created = "2027-01-11"

Mnemo2's live worker activity lives in `mnemo2/src/lib/workerActivity.ts`: `applyWorkerEvent(activity, TeamEvent, nowMs)` maps streamed events to phases (started→starting + turn anchor, reasoning_delta→thinking, text_delta→writing, tool_call_start→tool with name, tool arg/execution/output deltas hold tool, tool_result→thinking, approval_request/user_question→waiting, finished/exited→clear; no-op events return the same object reference) and `applyWorkerStatus(activity, status, nowMs)` folds snapshot statuses (dispatching→starting, working/fixing/merging keep the streamed phase, waiting→thinking when the answer arrives, needs_you→waiting, every non-running status clears). `workerPhaseLabel` renders the labels; a tool phase prefers toolSummary's phrase, else "Running <name>…". store.ts keeps the authoritative per-worker activity in a module-level Map (`workerActivity`), folded by every streamed TeamEvent before the saved-thread guard — so a worker's row updates even with no thread open — and by every syncTeam snapshot inside workerFromRecord; the Map is pruned when a worker leaves the snapshot and cleared on disconnect. The `Worker` interface (mnemo2/src/lib/types.ts) carries `createdAtMs: number` (rows tick their timer from it) and `activity: WorkerActivity | null` (the phase record: phase, toolName, turnStartedAtMs, phaseSinceMs). `mnemo2/src/components/ActivityStatus.svelte` is the shared pulsing status row (dot + label + ElapsedTime; props label, startedAtMs, pulse, size "body"|"meta"; classes `thinking-status`, `meta`, `still`; a prefers-reduced-motion media rule stops the pulse); LeadChat's Thinking row, WorkerThread's thread tail, and WorkerRow's live meta line all render it. In LeadChat the component is wrapped in a div that keeps the `thinking-status` class — its component test locates the row via querySelector(".thinking-status") and checks the previous sibling is `.tool-activity-row`, so a differently-named wrapper would break it.
