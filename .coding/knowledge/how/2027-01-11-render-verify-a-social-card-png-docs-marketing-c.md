Workflow for producing a 1200x630 upload-ready PNG from a marketing SVG in assets/social/ (no Inkscape/ImageMagick/resvg on this machine; only Pillow + the app's Browser tab). (1) Author the card as SVG (viewBox 0 0 1200 630); the repo's own visual language is LIGHT (assets/workflow.svg: cyan #0891b2/#0e7490, slate #64748b/#94a3b8) — a dark-SaaS card was rejected by the user as "lame"; what worked: one hero headline ~64px as the single focal point, one mechanism strip, supporting claims demoted to two muted 17px lines. (2) Render via docs/marketing/card-to-png.html (`browser_navigate file:///C:/Mnemo/docs/marketing/card-to-png.html?v=N` — bump v to bust cache; ?src= selects another card). The harness shows the card at 800x420 CSS px because the Browser tab runs at devicePixelRatio 1.5 in a 910x1280 CSS viewport, so 800x420 = exactly 1200x630 device px and 1200 CSS px would CLIP the right edge. The sandboxed offscreen browser cannot load file:// at all and is fixed at 800x600 — use the Browser tab. (3) Before screenshotting, `browser_eval` that img.complete is true and naturalWidth==1200 (an early capture races the navigation and yields the previous frame). (4) `browser_screenshot`, then Pillow crop (0,0,1200,630); the harness's magenta background makes bleed detectable — assert 0 magenta pixels inside the crop. (5) VERIFY: the vision/OCR tools returned blank or non-answers on some rounds, so trust pixel evidence — measure text-run extents vs arrow x-positions with a column-scan (text widths beat my estimates by ~30px; a 2px near-touch was only caught by measuring). (6) Delete diagnostic screenshots under .coding/browser/screenshots/ before committing or they get swept into the commit. (7) Every product claim on a public card must be checked against SOURCE, not docs/memories — the "six token levers" count was stale in README/PLAN.md/CONFIGURATION.md/memories simultaneously and cost three review rounds; and sweep ALL published files (README.md, PLAN.md, docs/**/*.md) for the same stale phrase, not just the ones you edited.
