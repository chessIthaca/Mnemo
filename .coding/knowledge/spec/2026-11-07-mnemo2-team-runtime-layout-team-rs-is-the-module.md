src-tauri/src/mnemo2/team.rs (about 760 lines) keeps the TeamRuntime struct (its fields stay private to `team`, visible to every child), open, the core methods (subscribe, attach_board, board_snapshot, snapshot, persist, update_worker, set_slots, cleanup, usage, stop_all, shutdown), shared helpers (unix_ms, status_name, now_key, project_relative), private `mod` lines and `pub use` re-exports so every `crate::mnemo2::team::X` path is unchanged. Children, each with its own `impl TeamRuntime` where needed: record.rs (WorkerRecord and worker types), persistence.rs (team.json), guardrails.rs (executor/audit prompts and gate rules), routing.rs (tier ladder, dispatch routing, reroute rows), nudge.rs (strikes, Laya nudges, route-fix brief), escalation.rs (auto-escalation), external_lead.rs (Claude Code lead state, notice queue, waiter), lead_tools.rs (lead/worker host tools, team_status views), dispatch.rs, spawn.rs (provision/start/spawn sessions, WorkerSessionSpec), audit.rs, control.rs (message, pause, stop, resume, change_model, compact, recover_worker), review.rs (review, checks, findings, review_fix, route_fix), pump.rs (pump_worker event loop, save_workers, worker host-tool results), merge.rs (merge/revert, stuck-checkout retry, branch sweep), deletion.rs (worker deletion, checkout trash, cleanup_workspace), tests.rs (all team tests, `#[cfg(test)] #[path = "team/tests.rs"]`). Cross-child calls use `super::<module>::item` and `pub(super)`. All team/*.rs files are listed in .coding/openspec/config.yaml governed_files beside team.rs.
