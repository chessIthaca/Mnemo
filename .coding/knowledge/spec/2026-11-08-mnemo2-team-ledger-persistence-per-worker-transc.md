src-tauri/src/mnemo2/team/persistence.rs and team/pump.rs. `WorkerRecord.transcript` is `Arc<Transcript>`: a change always assigns a new Arc, and `Arc::ptr_eq` is the "unchanged" test for both file writes and the window's revision cache (`TeamRuntime::snapshot_known`, so team syncs omit transcripts the window holds). Conversations live in `<state dir>/transcripts/<worker_id>.json`; team.json holds an empty placeholder plus `saved_messages`, which exists only on disk and resets to 0 after load. team.json is replaced by one atomic rename, never moved aside, so readers never see it missing. Saves run on the blocking pool under save_lock; Usage, ContextUsage and record_usage coalesce into one flush after 1 s (`save_workers_soon`), everything else saves at once. Safety rules: a transcript read failure aborts load before any save, because TeamRuntime::open persists immediately after load and would otherwise overwrite a good file; a decode failure keeps the bytes as `<id>.json.corrupt` (failing the load if that cannot be done) and flags `worker.error`; a missing file with saved_messages above 0 flags `worker.error`; an empty transcript writes no new file; a save deletes only files this instance recorded and then removed, never by scanning; temp sweeps skip anything younger than 60 s. Two live instances can share a state dir through "Open anyway" (project::attach(root, true)): team.json stays last-writer-wins. Accepted limits, documented in the module: the same worker driven from both instances means the last replaced transcript wins; deleting a worker in one instance during another's save can leave that record without a file (flagged). Ids that are not ASCII alphanumeric and 8+ chars stay embedded. No fsync.
