An AgentTask between commands compacts its conversation once per idle spell when ALL hold: idle >= the measured prompt-cache lifetime of the model its last turn ran on (MemoryStoreTrait::cache_lifetime_secs over this project's request_stats, 30 days, prompts >= 20k tokens, summarize rows excluded; first probe 300/600/900/1200/1800/2700/3600 s whose window [p,2p) has >= 3 samples with mean hit ratio < 0.5; else 3600 s; re-measured hourly); context >= 50,000 tokens; [general.optimizer] idle_compaction (default true, Mnemo2 Settings > Savings "Idle compaction"); a dedicated summarizer (the [models.summarize] provider builds and its model differs from the last turn's model — so agents running ON the summarize model never idle-compact); not a subagent. Conditions are re-checked when the timer fires. The summary races the real inbox: the first command is stashed and soft-interrupts it, a 2 s grace hard-cuts a stalled provider, and the command then runs through the normal arms. A summary committed before a cut is kept. Each shrinking compaction writes a savings row of kind idle_compaction (Cost tab label "Idle compaction"). Code: src/runtime/agent.rs idle_compaction_deadline / run_idle_compaction; src/memory/mod.rs cache_lifetime_from_gaps. Measured on this project 2026-11-10: deepseek-v4.1-flash:1017 600 s, kimi-k3.1-pro 1200 s, glm-5.3 1800 s.
