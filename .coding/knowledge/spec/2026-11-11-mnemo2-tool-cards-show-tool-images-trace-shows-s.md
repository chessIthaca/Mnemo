Tool images: ToolActivity.svelte derives image paths with lib/toolImages.ts toolImagePaths (Mnemo1's rules: *_screenshot -> result.data.path or the .coding/browser/screenshots/*.png in the output; image_* -> args.image, image_ui_diff -> image_a/image_b) and renders ToolImages.svelte thumbnails with a Sheet viewer (Copy image, Close). Host command workbench_tool_image(workerId|null, path) in src-tauri/src/mnemo2/ipc.rs reads via workbench::read_tool_image from the project root (lead) or the worker's registered checkout, sandboxed (no '..', inside the canonical root, no symlinks, no .git/secret names, image extensions, 20 MiB). Steering: trace_view::trace_steering_stats returns engine.host().factory.steering().snapshot() (lead and workers share one factory); TraceSteering.svelte in the Trace Insights shows followed share, per-kind rows (labels in lib/steering.ts MARKER_LABELS) and file edits by file tools vs shell, polled every 1.5 s. About: Settings rail group 'Mnemo2' > About (AboutPage.svelte, lib/about.ts) shows getVersion(), the MIT license, the repository link and Mnemo1's Rust dependency groups plus Mnemo2's own npm groups; links open through browser_open_external. The version comes from the running app, so releases need no extra bump.
