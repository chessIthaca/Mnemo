Any tier except escalate may carry `claude_agent` = opus|sonnet|haiku|fable (`[[tier]]` in ~/.mnemo/endpoints.toml; Tier/TierDto in src/config/endpoints.rs and src/headless/setup/endpoint_detail.rs; "Run as" select on the Tiers page). The setting only applies to a team_dispatch from the attached external lead, by tier (no explicit model), on the tier routing settled on before fold-down. On that path Mnemo provisions the pool checkout and branch, starts no session, marks the record Working with claude_agent set (status shows claude-code/<model>), and returns `claude_agent {model, worktree, branch, prompt}`. The prompt comes from record.rs agent_prompt: AGENT_KICKOFF or AGENT_READ_BACK_KICKOFF, the opening prompt with the plan_read sentence (plan_board.rs PLAN_READ_TOOL_GUIDANCE) swapped for plan_show, and the worktree/branch rules. The lead runs its own Agent, then calls team_agent_done once (external_lead.rs agent_done). Fix rounds go through SendMessage to the same agent, then team_check and team_review on the new tip. team_message, team_resume, team_route_fix and team_compact refuse these workers with status-dependent text (record.rs agent_worker_refusal). The gate-agent hook allows Agent calls while any agent worker is Working. Agent workers count against slots (team.rs active_workers_for_slots). The lead-facing guide is the "Tiers that run as a Claude Code agent" section of the mnemo-lead skill.
