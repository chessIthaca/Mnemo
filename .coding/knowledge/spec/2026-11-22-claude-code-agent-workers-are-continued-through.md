An agent worker (record.claude_agent set) has no Mnemo session. From the external lead, team_message records the inbox entry, moves an idle worker (Completed/InReview/Conflict/Interrupted) back to Working or Fixing, and answers with continue_agent {agent_id, worktree, message} for the lead to SendMessage; team_route_fix records the round exactly like the Mnemo path (Fixing, fixer_finding_id, fix_rounds+1, checks/review cleared, brief in the inbox as Mnemo/Fix). team_agent_done is called once per agent run and accepts Working, Fixing, Interrupted (clears fixer_finding_id). The in-app lead and the UI are still refused (only the external lead owns the Agent). team_resume/team_compact refuse with guidance; Failed/Stopped agent workers can only be redispatched. Moving a Mnemo worker onto a tier with claude_agent (team_resume tier without model, auto escalation, usage-limit resume) hands it to the agent instead: control.rs hand_to_agent_locked stops the session via stop_inner and returns a block whose prompt is record::agent_continue_prompt. Pointers: control.rs message_agent_locked, review.rs route_fix_to_agent_locked, external_lead.rs agent_done, escalation.rs escalate_to_agent_locked, lead_tools.rs continue_agent_answer/agent_handoff_answer.
