A worker on a tier that runs as a Claude Code agent has no Mnemo session; Mnemo2 keeps its state coherent itself. (1) Phase: team_status and the window show a derived, never persisted `agent_phase` — awaiting_launch (no agent registered yet), running, stalled (10 silent minutes), finished — shown in Mission Control as "Waiting for Claude Code agent" / "Claude Code agent running" / "Claude Code agent silent for 10+ min". (2) Finish: when the registered agent's transcript says finished, the watcher completes the worker with the agent's last assistant text as the report and sends the normal finished notice; team_agent_done is only for a failed run or a fuller report and never causes a second finished notice. Once-per-run is keyed on the worker's turn count, and a continuation/fix round records the transcript length as a floor BEFORE the status change, so an old finish is never taken for a new run. (3) Hand-back: when the external lead leaves (session end, idle-out, project close) or Mnemo2 starts without one, an agent worker that was never launched or has stalled becomes an ordinary Interrupted Mnemo worker (agent fields cleared, branch/checkout/commits kept, resumable on a Mnemo model); a running agent stays and is watched across a restart. Silence falls back to the record's last_activity_ms when the transcript is missing. Code: src-tauri/src/mnemo2/team/agent_watch.rs (agent_phase, tick, hand_back, note_run_start), external_lead.rs (auto_finish_agent, close_agent_run_locked, leave_external_lead, hand_back_agent_workers), control.rs recover_worker, team.rs TeamSnapshot Serialize; mnemo2/src/lib/types.ts workerAgentPhaseText. Known residual: a continuation whose transcript path was never recorded floors at 0.
