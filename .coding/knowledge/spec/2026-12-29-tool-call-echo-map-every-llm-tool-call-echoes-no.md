Audit (backlog c8531c34, plans 34817533 + e626f6d2, 2026-12-29): every LLM tool call echoes into BOTH the GUI chat (ToolCard) and the -console REPL ('-> name') — no name-based suppression anywhere in the chain. Emission: turn.rs:1104-1121 forwards every ToolCallStart unconditionally; six ToolResult sites close every announced call (real result 1816; synthetic not-run closers 1329/1432/1537/1664/1975). GUI: agentEventReducer.ts:486 cards every call (neverGroups:545 = merge rules only, not visibility). Console: console.rs:241 render_event prints '-> {name}' for every tool; Silent set = {Started, ToolCallArgDelta, ContextUsage, PromptDispatched, Phase}. By-design exceptions: (1) agent-activity cards (all tool calls + MEMORY_TOOLS write/search/consolidate/update/supersede/delete + vision + skill) hidden from GUI chat at RENDER time when [ui] show_tool_activity=false — default false (backlog db489070, 2026-12-30; supersedes the old memory-only show_memory_activity reducer suppression, default true); the transcript store keeps every entry and the model context echo is unaffected; Output tab + console still show them; (2) auto-delegated graph/memory lookups inside search/search_read (codegraph.rs:106, search.rs:1057) emit no ToolCallStart — the answer rides inline 'AUTO-DELEGATED...'; (3) sub-agent tool calls echo into the child's transcript only (parent sees spawn_agent + ChildFinished). Graph/search cards are rare because auto-delegation absorbs symbol lookups and read_files is the workhorse (consecutive read_files merge into one card).
