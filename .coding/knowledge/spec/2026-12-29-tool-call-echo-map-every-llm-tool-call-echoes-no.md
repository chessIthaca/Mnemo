Audit (backlog c8531c34, plans 34817533 + e626f6d2, 2026-12-29): every LLM tool call echoes into BOTH the GUI chat (ToolCard) and the -console REPL ('-> name') — no name-based suppression anywhere in the chain. Emission: turn.rs:1104-1121 forwards every ToolCallStart unconditionally; six ToolResult sites close every announced call (real result 1816; synthetic not-run closers 1329/1432/1537/1664/1975). GUI: agentEventReducer.ts:486 cards every call (neverGroups:545 = merge rules only, not visibility). Console: console.rs:241 render_event prints '-> {name}' for every tool; Silent set = {Started, ToolCallArgDelta, ContextUsage, PromptDispatched, Phase}. By-design exceptions: (1) agent-activity cards (all tool calls + MEMORY_TOOLS write/search/consolidate/update/supersede/delete + vision + skill) hidden from GUI chat at RENDER time when [ui] show_tool_activity=false — default false (backlog db489070, 2026-12-30; supersedes the old memory-only show_memory_activity reducer suppression, default true); the transcript store keeps every entry and the model context echo is unaffected; Output tab + console still show them; (2) auto-delegated graph/memory lookups inside search/search_read (codegraph.rs:106, search.rs:1057) emit no ToolCallStart — the answer rides inline 'AUTO-DELEGATED...'; (3) sub-agent tool calls echo into the child's transcript only (parent sees spawn_agent + ChildFinished). Graph/search cards are rare because auto-delegation absorbs symbol lookups and read_files is the workhorse (consecutive read_files merge into one card). Amended 2027-01-11: Live shell output streaming — a NEW display-only event variant (plan 0d2c1221, backlog 7e6385b3). `AgentEvent::ToolOutputDelta { tool_call_id, stream, text }` (wire `tool_output_delta`, golden fixture `frontend/src/lib/ipc-fixtures/event-tool-output-delta.json`) carries throttled chunks of a RUNNING shell call's stdout/stderr, emitted from the per-call `OutputSink` built at the dispatch site (`AgentLoop::output_sink`, src/agent/dispatch.rs) and throttled in src/tool/agent/shell.rs (`STREAM_FLUSH_INTERVAL` 60 ms / `STREAM_FLUSH_BYTES` 8 KiB, `STREAM_CAP` 256 KiB live budget + a one-time truncation note). This is an ADDITIONAL event, so the echo chain itself is unchanged — still exactly one ToolCallStart and one ToolResult per call, and the answer to "does every tool call echo?" stays YES. The delta IS silent in the console: the `-console` REPL Silent set (src-tauri/src/console.rs `render_event`) is now {Started, ToolCallArgDelta, ToolOutputDelta, ContextUsage, PromptDispatched, Phase}. GUI: the chat ToolCard renders the live tail under a RUNNING card's header (frontend/src/components/chat/Message.tsx, gated on `result === null && liveOutput`, `aria-live="polite"`, bounded by `liveTailPreview` = last 6 lines / 400 chars), fed by `reduceToolOutputDelta` (rolling 16 KiB tail per running call, head-dropped, cleared the moment the result lands) after useAgentEvents.ts coalesces chunks per (agent, tool_call_id) — a buffer drained by /clear like the other delta buffers. The ToolCard remains the ONLY GUI surface for tool text (the "Output tab" does not exist; this map's earlier correction stands, and docs/FEATURES.md + debug.config.toml + the shell.rs test comment were synced to drop the stale phrase in the same change).
