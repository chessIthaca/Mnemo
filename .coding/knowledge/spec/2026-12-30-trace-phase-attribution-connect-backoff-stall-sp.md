Per-request record fields (src/provider/trace.rs LlmRequestRecord): prep_ms = turn-loop start → record created (parked + the client adds the local sliver from complete() entry to record creation — body build + log start; includes compact_ms); backoff_ms (NEW) = the ACTUAL jittered retry sleeps — equal jitter via retry_backoff_ms (src/error.rs, shared by BOTH retry layers: half fixed + half random, attempt 1 → 500–1000ms, 2 → 1000–2000ms, 3 → 2000–4000ms; SystemTime-nanos randomness, non-crypto) — parked on the provider via LlmClient::record_backoff_ms and stamped on the NEXT attempt's record; BOTH layers park it: complete_with_retry (dispatch.rs, request-level) AND run_turn_attempt (runtime/agent.rs, turn-level — plan 26c01541); connect_ms (RENAMED from send_ms) = record created → response headers (TCP/TLS + upload + server ack + the reasoning_effort fallback retry); ttft_ms = headers → first chunk (server thinking; docs fixed from the wrong "POST → first chunk"); generation_ms = first → last chunk (unchanged); stall_ms (NEW) = byte-silence gaps > StallTracker::THRESHOLD (2s, src/provider/mod.rs) inside generation, subset of generation_ms, stamped at Usage + timeout (finalize adds the trailing gap); tools_ms unchanged. Error paths stamp the SAME windows as success: transport/HTTP errors → set_connect_ms(record_created.elapsed()) (was set_ttft_ms — the misattribution); stream timeout with no chunk → connect (record→headers) + ttft (headers→timeout); mid-stream errors → generation + stall.
