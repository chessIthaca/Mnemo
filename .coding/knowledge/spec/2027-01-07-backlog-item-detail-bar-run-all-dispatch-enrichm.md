SPEC (2027-01-07, commit 08a9295 on wt/agenticcoding, plan 4354296c): backlog item detail bar + run-all dispatch enrichment — items must be detailed enough for a dispatched lesser-reasoning model to succeed without re-deriving context.

Detail bar (src/backlog.rs, enforced in normalize_item_text — the single shape contract both write paths route through; image-only items exempt, existing items grandfathered): body ≥ MIN_BODY_CHARS (160) AND at least one file-path-like token OR an explicit no-code marker ("no-code research"/"no code changes"/"research only"/"research-only", case-insensitive). The path regex (OnceLock static): two-separator path | separator+extension | drive prefix | bare code-extension filename — and every match must carry an alphabetic char (round-1 LOW-2: slash-dates like 10/10/2027 are digits+separators only and must NOT count; "and/or" prose never counted). Rejection messages name the 5-element bar (problem+repro with dates, paths+symbols, fix direction, acceptance, related pointers) so an LLM retries in one shot. The backlog_add tool schema teaches the bar upfront, built from the enforcing consts (MAX_ITEM_TEXT_CHARS/MAX_HEADLINE_CHARS/MIN_BODY_CHARS) so it can't drift.

Dispatch enrichment (src-tauri/src/ipc/run_all.rs): run_all_prompt(item_text, context_block: Option<&str>) appends the block after the task; run_all_dispatch_next computes it via recalled_context_block → MemoryStoreTrait::recall_peek (PASSIVE — no access-count bump; the bump is reserved for agent-initiated lookups) with MemoryFilter{limit:5}, best-effort (None store/error/empty → no block, never blocks a dispatch). format_recalled_context: top-5 hits, tier-prefixed title + 300-char gist (control chars → spaces), bracketed verify-against-the-code caveat. CRITICAL lock discipline (round-1 HIGH-1): the recall is computed BEFORE the manager lock is taken — recall_peek awaits the embedder (network round-trip or ONNX inference + sqlite read) and must never run under the manager lock. Scoped to run-all only; the single-dispatch path (dispatch_item) sends raw item text (attended — the user is watching).

Composer Template button (BacklogView.tsx): backlogItemTemplate() = the 5-section skeleton with a src/... path placeholder; fills ONLY an empty composer (guard + disabled button); focus + headline selection apply POST-COMMIT via a templateJustInserted useEffect (round-1 LOW-1: a synchronous setSelectionRange runs before React 18's batched commit, so the selection clamps to the old empty value).
