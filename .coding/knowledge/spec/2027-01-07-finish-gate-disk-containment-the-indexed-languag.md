The finish gate's regression-test symbol check covers ALL programming languages (plan c87093c1, 2027-01-11). Two layers: (1) Code-graph indexing — Lang (src/codegraph/walk.rs) parses Rust, TypeScript/TSX (.ts/.mts/.cts/.tsx), JavaScript (.js/.jsx/.mjs/.cjs), Python (.py/.pyi), Go, Java, C (.c/.h), C++ (.cpp/.cc/.cxx/.hpp/.hh/.hxx), C# (.cs), Ruby (.rb), PHP (.php), and HTML (.html/.htm — <script> blocks sub-parsed as JS with line offsets, visit_html in src/codegraph/extract.rs). (2) Gate disk check — reindex_files_containing (src/codegraph/mod.rs) scans every file with a code extension (is_code_extension in walk.rs: the Lang set + swift/kt/scala/sh/ps1/lua/pl/r/ex/hs/ml/fs/clj/dart/zig/nim/v/sql/groovy/tf/vue/svelte/astro/html/css/scss/sass/less/proto/graphql/…; data/config/docs deliberately excluded so plan files can't satisfy the check). When the test name is found only in non-parseable code files (ReindexOutcome.matched_unparsed > 0), the gate PASSES with the note "symbol check satisfied by disk containment" — the name is real, the language just isn't graph-indexed. Only a name in NO code file errors ("no code file on disk contains the name"). Regression test: finish_passes_when_regression_test_is_in_non_indexed_language (src/tool/workflow/plan.rs). Boundary: Swift/Kotlin/Scala etc. are gate-only (no grammar wired); CSS is gate-only (selectors aren't symbols).
