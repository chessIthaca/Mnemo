SPEC (2027-01-10, plan 7c8d90cd, L3 from .coding/reviews/2026-09-09-perf-comm-review.md): the OpenAI-compat chat-completions request body is PRE-SERIALIZED — `OpenAiClient::build_request_body(messages, tools, tool_choice, omit_effort) -> Result<String>` (src/provider/openai/request.rs) serializes each message exactly once into a Box<serde_json::value::RawValue> (borrowed raws serialize directly — no deep clone) and splices them verbatim; the send path ships the wire string via reqwest .body() (no .json() re-serialization); `build_request_json` is a #[cfg(test)] lens (build + parse). Echo path: `echo_assistant_raw` returns Cow — Borrowed when NEITHER ReasoningRetention::strips_reasoning(age, pressure) NOR the age-0 DeepSeek reasoning_content re-add applies (the two mutations are mutually exclusive: the strip never runs at age 0). Serialized-prefix cache: `request::PrefixCache` (single-slot Mutex on the client) — the stable prefix (messages MINUS the trailing system run: the volatile tail + CONTEXT_FOOTER are pushed after the token accounting and popped after the request) serialized boxes circulate between iterations (taken on hit, stored back on refresh — never re-serialized or cloned); validated by `fingerprint_prefix` — a fresh O(n) no-alloc fold with length-prefixed strings (injective encoding, 2^-64-collision-only residual) hashing role/content/tool-calls(+provider_meta)/tool_call_id/name/reasoning_content/reasoning_stripped/raw + per-assistant the two age-dependent mutation decisions (ages counted from the END of history — each flips at most once: the re-add at age 0→1, the strip when age crosses keep_recent under pressure) + the pressure flag + len. Estimate: skipped on hits (cached prefix_chars + fresh tail chars + tools_chars — same formula/basis as estimate_prompt_tokens via the shared message_estimate_chars). DELIBERATE DEVIATION (documented in the builder): TokenAccounting's incremental total is NOT fed into the max-token cap — it is computed before the per-request head/tail scaffolding (turn.rs:335 vs :2094) so it understates the request input, and its BPE basis would loosen the cap. Retry: the reasoning_effort 400 rejection rebuilds via build_request_body(omit_effort=true) (chat) or build+remove+to_string (Responses path). Trace: the wire string is cloned (memcpy — the async worker no longer deep-clones a Value tree) and parsed to a Value on the blocking pool for log.start. Pinned by 12 tests in src/provider/openai/tests.rs (5 echo Borrowed/Owned + 7 cache: warm==cold byte equivalence, append hit, trailing-system exclusion with the cached-len pin, shrink, head-swap, pressure flip with the strip asserted on the wire, re-add aging out) + a #[cfg(test)] hit_count AtomicUsize pinning genuine hits.
