SPEC (2027-01-10, plan c6b5a6e1, backlog a6b3fa57, D2 from .coding/reviews/2026-09-09-perf-comm-review.md): when compact_old_tool_results (src/agent/context.rs) truncates a tool result, the COMPACTED_MARKER is followed by a one-line re-read/re-run pointer derived from the originating tool call's arguments — read_files → `[re-read: read_files <path>:<start>-<end>, ...]` (path/start_line/max_lines + files[], capped at 3 specs + " (+N more)"); search/search_read → `[re-run: <name> pattern="..." glob="..."]` (control chars collapsed, pattern capped at 80 chars). The arguments are read from the preceding assistant message's tool_calls (matched by tool_call_id) — the ToolResult envelope's structured `data` is dropped at message construction (src/agent/turn.rs:1400-1406 keeps only result.output), so the arguments are the only creation-time metadata that survives into history. Unmatched id or non-pointer tool → plain marker. Idempotency unaffected (the pointer rides after the marker and never contains it); prefix-cache safe (lands within the same single-pass mutation). Regression tests: compact_appends_reread_pointer_for_read_files, compact_appends_rerun_pointer_for_search, compact_pointer_keeps_idempotency, compact_no_pointer_without_matching_tool_call.

Amended 2027-01-07: Amendment (2027-01-10, review round 1 — .coding/reviews/2026-09-10-d2-reread-pointers-c6b5a6e1-review.md): the read arm now also matches `file_read` (identical {path, start_line, max_lines} args; the pointer is prefixed with the actual tool name, e.g. `[re-read: file_read src/bar.rs:5-24]`); search/search_read pointers append ` literal=true` when the call set it (a literal pattern re-run as regex typically matches nothing); start_line 0 normalizes to 1 and max_lines 0 is treated as absent, with saturating arithmetic (start.saturating_add(m).saturating_sub(1)) so degenerate args cannot underflow-panic in debug builds; glob and read paths get the same one_line() control-char collapse + cap (80/160 chars) as patterns. Regression tests added: compact_appends_reread_pointer_for_file_read, rerun_pointer_normalizes_degenerate_read_args, rerun_pointer_covers_batch_form_and_literal_flag.
