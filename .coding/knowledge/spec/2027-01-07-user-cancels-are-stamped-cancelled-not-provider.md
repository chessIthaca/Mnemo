D1 (plan 814f27c9, bug_fixing, shipped 2027-01-10 at commits 69cc228 + 27e1d2e on wt/agenticcoding): a user interrupt that drops a live stream mid-flight (Interrupt/Cancel/Compact/Clear) is classified as CANCELLED, not a provider failure. (1) Trace layer: LlmRequestRecord + LlmRequestSummary gain `cancelled: bool` (terminal — is_complete includes it, so the UI stops polling); the new LlmRequestLog::cancelled(id, status) stamps terminal-cancelled with the healthy http_status and NO error text — so maybe_log_error (fires on http_status>=400 || error.is_some()) can never mirror a cancelled record into provider-errors.jsonl — and is a NO-OP when error or finish_reason is already present (a genuine stream error that lands just before the consumer exits is not masked). (2) The SSE pump's consumer-drop arms (src/provider/openai/stream.rs + src/provider/anthropic.rs) call log.cancelled(*id, status.as_u16()) instead of log.fail(...), keeping the timing stamps (generation_ms when a chunk arrived, else connect_ms+ttft_ms). (3) Agent layer: consume_stream's hard-stop arm records a request_stats row with outcome='cancelled' (the R21 scaffolding-inclusive estimate, completion 0, cached_tokens NULL — no usage was reported) guarded by `!usage_recorded && !had_error` (the Error arm does not break the select loop, so a queued hard-stop can win the next iteration — Error-then-interrupt must not double-record); all three compaction call sites (turn.rs handle_pending_swap + maybe_compact, runtime/agent.rs compact_context) record cancelled summarize rows (outcome='cancelled' + purpose='summarize', the full-conversation estimate) on the summarizer's interrupt path. (4) Frontend: types.ts carries `cancelled: boolean` on LlmRequestDetail + LlmRequestSummary; the row badge renders via the pure rowBadges(r) helper (cancelled already excludes failed — a genuine error keeps its ERR badge), pinned by a 5-case badge-table test. (5) The extraction script (.coding/analysis/cache-hit-5-extract.py) segments cancelled rows (they previously fell into NO segment — outcome='cancelled' matches neither the error filter, the summarize filter, nor the main-rows filter); the hit aggregates still run on main-loop rows only. PRESERVED: record_interrupted_output keeps partial text + tool calls with "not run" results (mid_stream_interrupt_sanitizes_truncated_args_in_history untouched). Tests: consumer_drop_stamps_cancelled_not_failed (a SlowSseServer TcpListener harness — drop the receiver mid-flight, assert cancelled + no provider-errors row), cancelled_is_a_noop_after_a_genuine_error, run_turn_records_cancelled_request_stats, run_turn_usage_then_interrupt_records_no_cancelled_row.
