Landed design for the kNN overlay classifier for failure triage (plan f37e80f3, backlog 057f7a34, branch wt/mnemo — Laya chain item 4b, follow-up to item 4/commit f6ca8c6).

ARCHITECTURE. KnnClassifier (src/agent/failure_triage_knn.rs) implements the existing Classifier trait (src/memory/classifier.rs) and rides INSIDE FailureTriageHandle (src/agent/failure_triage.rs) — zero new classifier-slot swap sites, zero triage-call-site changes. Handle gained pub knn: Option<Arc<KnnClassifier>> + pub knn_enabled: Arc<AtomicBool>; new() keeps its 2-arg signature (knn None, flag false ⇒ all pre-existing call sites/tests byte-identical); builder with_knn(knn, enabled: bool); is_knn_enabled(). triage(): master flag first, then overlay-first while knn_enabled — Classified short-circuits (base slot never asked); any Fallback falls through to the base; base absent ⇒ the overlay's own Fallback reason surfaces (informative LowConfidence). Flag off ⇒ the exact pre-overlay code path.

INDEX (genuinely online). Self-refreshing from the training-log FILE (~/.mnemo/laya/training/failure_triage.jsonl), not in-memory events: per classify a stat byte-length check; growth ⇒ embed only parsed rows past the rows_seen watermark (rows_seen counts label-unknown rows too, so they are never re-embedded); shrink OR embedder model_id change ⇒ full rebuild. First classify builds lazily from the full log (startup corpus); a disposition appended by ANY writer is retrievable on the next classification, no restart. Locking: tokio::sync::Mutex serializes refreshes (held across embeds); the std RwLock<KnnIndex> is never held across an await (embeds happen before the write-lock store); double-checked after awaiting the mutex; poison-tolerant (degrades to no-refresh/no-answer — never panics a turn).

VOTE. k = KNN_K = 5 (min with corpus size); cosine similarity (zero norms/non-finite ⇒ 0.0); majority vote per FailureClass in fixed enum order (strictly-greater — deterministic; a top tie ≤ k/2 votes can never reach the gate); confidence = winner_votes/k (vote share), inclusive 0.80 TRIAGE_THRESHOLD (4/5 = exactly 0.80 classifies); Answer::Choice probabilities = per-class shares. Every logged row votes by the class label IT CARRIES (disposition does NOT filter — escalated needs_user/permanent rows teach the overlay); rows with unknown labels and all-zero vectors are never indexed.

SAFETY GUARDS. classify answers ONLY question == triage_question() (None for auto-typing/any other consumer, so it can never leak failure labels through the shared slot); all-zero QUERY vector ⇒ None (embedder failure mode); empty index (cold start) ⇒ None.

EMBEDDER. Live getter closure EmbedderGetter = Arc<dyn Fn() -> Arc<dyn Embedder> + Send + Sync> (mirrors MemoryStore::now); the app passes move || store.embedder_handle() (the LIVE shared slot — bundled-model background loads and Settings swaps flow in; model_id drift triggers the re-embed, no rewire needed). Constructors: new(getter, path) + with_embedder(fixed, path) (tests). main.rs constructs the store BEFORE the handle (in-memory fallback keeps the Arc non-optional), captures a store clone, chains .with_knn(knn, cfg flag).

WIRING/CONFIG CHAIN. Config: LayaConfig.failure_triage_knn (default off, skip_serializing_if laya_flag_off, is_default, round-trip test config::general::tests::laya_failure_triage_flags_default_off_and_round_trip). Settings: patch field laya_failure_triage_knn (src/config/settings_dto.rs) + apply arm + test laya_patch_applies_failure_triage_flags_and_auto_finetune; LayaWire DTO field + read + both fixtures (src-tauri/src/ipc/settings.rs); contract fixture (frontend/src/lib/ipc-fixtures/dto-get-settings.json — the Rust dto_fixtures_match_serde test pins it); frontend draft failureTriageKnn + laya_failure_triage_knn serialize + toggle ("Learn from logged failures between fine-tunes (kNN)") + test pins (types.ts, tauri.ts, ClassifierSection.tsx/.test.ts). Factory: set_failure_triage_knn_enabled (mirrors set_failure_triage_enabled); rewire.rs calls it (the ONLY rewire addition). Flag writers: startup main.rs + rewire — same two-writer invariant as failure_triage.

TESTS (11, in failure_triage_knn.rs #[cfg(test)]): knn_near_identical_error_text_retrieves_the_stored_class; knn_empty_index_returns_none_cold_start; knn_below_threshold_vote_falls_back_to_pre_classifier_rules (3/5 = 0.6, gate-level fall-through + base-absent reason); knn_appended_disposition_is_retrievable_without_restart; knn_confident_answer_short_circuits_the_base_classifier (base CountingClassifier 0 calls); knn_flag_off_keeps_the_byte_identical_base_path; knn_never_answers_foreign_questions; knn_zero_vector_query_returns_none; knn_unknown_class_label_rows_are_skipped; knn_model_id_change_rebuilds_the_index; knn_vote_share_is_the_confidence_and_the_threshold_is_inclusive (4/5 = 0.8).
