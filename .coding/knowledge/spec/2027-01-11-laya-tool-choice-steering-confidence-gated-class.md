Shipped the Laya tool-choice steering (Laya chain item 3) at commit 7b7691b on wt/mnemo (NOT yet landed in main). Optional, off by default via `[general.laya] steer_tool_choice`.

MECHANISM: the `search`/`search_read` auto-delegation DECISION (previously pure regex shape heuristics) is optionally made by the Laya `Classifier` over three classes — SYMBOL / TEXT / MEMORY — routing the winning class into the EXISTING delegation emitters; the delegation mechanics are untouched (only the decision changed).

- src/tool/agent/tool_choice.rs (NEW): `TOOL_CHOICE_THRESHOLD = 0.80`; `ToolChoice{Symbol,Text,Memory}`; `ToolChoiceFallback{Disabled,NoClassifier,NoAnswer,LowConfidence(f64),UnknownLabel}` (+`as_str` slugs); `ToolChoiceDecision::{Steered{choice,confidence},FellBack{reason}}` with `choice()`; `tool_choice_question()` (3 labels); `state_text()` (2000-char cap); `async steer()`; `steer_with_handle()` (clones the classifier Arc out of the RwLock and drops the read guard BEFORE the await — holding it across an await would deadlock a concurrent rewire); `ToolChoiceHandle{classifier: Arc<RwLock<Option<Arc<dyn Classifier>>>>, enabled: Arc<AtomicBool>, log_path: Option<PathBuf>}` (+`with_log_path`); `is_live()`; `ToolChoiceLogRow` + `log_decision()` (best-effort JSONL).
- INTEGRATION (src/tool/agent/search.rs ~1332-1426, src/tool/agent/search_read.rs twin): the steer is computed ONCE before `spawn_blocking` (skip when `escape`); it yields an allow-triple overriding the existing gates — Symbol ⇒ (allow_memory=false, allow_symbol=true, allow_nudge=true); Memory ⇒ (true,false,false); Text ⇒ (false,false,false) (plain search, no nudge); None (fallback) ⇒ (true,true,true) = the pre-change `escape ||` form, so disabled behavior is byte-identical by construction. The training row is logged inside the closure AFTER `delegated` is computed and BEFORE any output branch (covers the fast-path return, the glob-narrowed prepend, and the plain fall-through). `steer_decision`/`log_live`/`log_path` are owned values moved into the 'static closure.
- GATE: src/agent/factory.rs `tool_choice: Option<ToolChoiceHandle>` + `with_tool_choice` + `set_tool_choice_enabled` (live flag flip, no registry rebuild), handed to both tools at registration. Config chain: src/config/general.rs `LayaConfig.steer_tool_choice` → src-tauri/src/ipc/settings.rs DTO field + mapping + BOTH defaults → contract_fixtures.rs → src-tauri/src/main.rs (flag + handle, `log_path: None`) → rewire.rs `set_tool_choice_enabled`. Frontend: ClassifierSection.tsx / types.ts / tauri.ts.
- TRAINING LOG: `~/.mnemo/laya/training/tool_choice.jsonl` (same home as the failure-triage log; path via failure_triage::training_log_dir). Row = {ts, pattern(capped 500), glob, literal, choice, confidence, fallback, delegated, escaped}. Best-effort — every failure swallowed. LowConfidence rows DO carry the calibrated confidence (the fine-tune/calibration signal). Test helpers override log_path to distinct temp files so the real log is never touched.
- INVARIANT (do not regress): the escape hatch (bounded `DelegatedKey` set) short-circuits BEFORE the classifier is asked; a SYMBOL steer whose pattern yields no extractable name falls back to the advisory symbol nudge.
- codegraph.rs `symbol_delegation_block` is a PURE EMITTER (takes resolved names) — the graph side has NO independent delegation decision.
