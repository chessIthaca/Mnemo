(1) `memory_update` TARGETED REPAIR: pass `find` + `replace_with` (alone — no title/content; mixing errors "pass it alone") to replace EXACTLY ONE occurrence in a record body in place. Refusals: blank find; absent find ("not present"); >1 match ("occurs n times — widen it to a unique substring"); a result that would empty the body ("would empty the record body"); unknown id / unknown rel / non-record; superseded records (history is never edited). Body-only — front matter is never matched and is re-rendered identically. Reindexes after the write: knowledge file → targeted reindex; DB-only row → update_memory. Empty `replace_with` deletes. THIS IS THE in-tool repair path for `.coding/knowledge/**` (the file tools refuse those paths by design), so no shell fallback is needed. Code: `replace_unique`, `KnowledgeStore::replace_in_body` (src/memory/knowledge.rs), `MemoryUpdateTool::repair_by_id` (src/tool/memory/mod.rs).

(2) `memory_amend` STRIP RULE: a leading self-supplied heading on the paragraph's FIRST line is stripped before the tool prefixes its own dated stamp, so exactly one heading lands and the tool's date is authoritative (a supplied date is dropped). Recognized: `amended`/`amendment` (any case, word boundary) + a ≤120-char head that is a parenthesized group ("Amendment (…):") or a leading 4-digit year with a date-shaped tail ("2027-01-14", "2027-01-14 (plan x, backlog y)"). The head ends at the FIRST colon yielding that shape, so a colon inside the group is handled ("(review L1: the message was wrong)"); a plain heading line with NO colon is stripped whole (text taken from the next line); repeats collapse "Amended A: Amended B: text" → "text"; every other line is preserved; prose that merely opens with the word ("Amended the readme and the changelog: …") is returned verbatim; a bare heading strips to empty and amend errors "nothing to amend". The amend result appends "NOTE: stripped n self-supplied amendment heading(s) ('Amended …' / 'Amendment (…)') …" so a strip is never silent. Code: `KnowledgeStore::strip_self_headings` / `leading_self_heading` / `stamp_shaped`, amend wiring, `MemoryAmendTool::execute`.

INVARIANT TO PRESERVE: `replace_in_body` deliberately does NOT consult `looks_like_row_digest` — that guard (shorter candidate + a last line ending in a `.coding/knowledge/…md` pointer) would wrongly refuse a collapsing repair; safety comes from the exact-match rule instead ("cannot do so *silently* — the caller must spell out the exact text it removes"), and the guard stays in `update` only. Accepted residual: a time-like head ("Amended 2027-01-14 12:30: x") strips at the time colon, leaving "30: x" (pre-existing; cleanable with the repair mode).
