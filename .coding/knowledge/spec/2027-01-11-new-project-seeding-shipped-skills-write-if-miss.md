New-project seeding contract (plan 8ff77e5d, landed 3f286a2 on wt/mnemo; src/project/scaffold.rs + src/skill/mod.rs + src/project/mod.rs::seed_init_artifacts). Two seed paths run on BOTH Project::init branches (fresh scaffold AND the is_initialized self-heal path):
1. Shipped skills — SHIPPED_SKILLS (src/skill/mod.rs) embeds merge_to_main + create_skill as (name, include_str! TOML) pairs; crate::skill::seed_skills writes them into .coding/skills/ write-if-missing (deleted files self-heal, user-edited ones are never touched). create_skill's prompt step 4 is worded to read correctly OUTSIDE this repo (app repo: CARGO_MANIFEST_DIR repo-TOML test + docs + cargo test; other project: whatever guard its suite has). REPO_LOCAL_SKILLS declares new_release + post_merge_sync with reasons; the guard test every_repo_skill_is_shipped_or_declared_repo_local asserts each loaded .coding/skills/*.toml is on exactly one list (count equality also catches a declaration whose file was deleted/renamed) and that each repo-local reason is non-trivial.
2. Git hygiene — scaffold::seed_git_files(root) calls ensure_managed_entries(path, header, entries) for root/.gitignore (MANAGED_GITIGNORE_ENTRIES: .coding/memory.db, .coding/memory.db-*, .coding/codegraph.db, .coding/codegraph.db-*, .coding/logs/, .coding/backlog-images/, .coding/plans/stack.json, .coding/instance.json, .coding/tmp-shard/, .worktrees/) and root/.gitattributes (MANAGED_GITATTRIBUTES_ENTRIES: *.db -text, *.db-wal -text, *.db-shm -text — deliberately REPO-WIDE — and .coding/backlog.jsonl merge=union). Semantics: missing file -> header block + all entries (LF); existing file -> append ONLY uncovered entries (coverage = line trimmed with a leading '/' stripped; a commented-out line never counts) using the file's dominant EOL (CRLF detected), terminating an unterminated last line, never reordering/removing existing content; a fully covered file is a byte-identical no-op (returns Ok(false)); a non-UTF-8 file is skipped byte-untouched (returns Ok(false)) instead of failing init; writes go through a same-directory <name>.seed-tmp sibling + std::fs::rename (write_preserving; best-effort fallback to a direct write).
Tests: src/project/scaffold.rs test module (merge-without-clobber via byte-prefix asserts, leading-slash coverage, commented-out non-coverage, CRLF tail, unterminated last line, empty file, idempotence/byte-equality, self-heal of an entry and of the file, non-UTF-8 skip, no temp litter, dogfood repo_own_git_files_carry_every_managed_entry) + three init-level tests in src/project/mod.rs.
