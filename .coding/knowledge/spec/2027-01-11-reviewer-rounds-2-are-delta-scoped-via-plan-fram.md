ARCHITECTURE. (1) Round state on the plan frame: `PlanFile.reviews` (src/workflow/plan_file.rs) persisted as the "## Reviews" section, one "<round> <base>" line per successful spawn (base = `git rev-parse HEAD` at dispatch), mutated/read by `Workflow::record_review_round` / `review_rounds` (src/workflow/mod.rs). (2) The git reads: `head_commit_sha` / `changed_paths_since` (src/project/git_ops.rs, spawn_blocking over the fake-able GitRunner), with `validate_base_ref` refusing "-"-prefixed / whitespace / metacharacter bases before git is invoked (the stamp round-trips through a file, so it is untrusted). (3) Rendering: src/agent/review_scope.rs — `ReviewScoper` trait (+ `GitReviewScoper`), `ReviewScope`, `render_review_preamble` appends at the END of a reviewer spawn task the verdict contract + one-line constitution checks + delta scope + mechanically-derived changed-file set; round 1 gets the full-tree brief, rounds 2+ the delta brief. (4) Wiring: `SpawnAgentTool::with_review_scope` (src/tool/agent/spawn_agent.rs) appends the preamble in the reviewer branch and stamps only after a SUCCESSFUL spawn; `WriteReviewReportTool::with_review_scoper` appends a trailing provenance line; both wired in src/agent/factory.rs.

INVARIANTS to preserve: a missing, failed or unverifiable stamp only ever WIDENS the next round's scope — never narrows on a crashed reviewer (fail-safe); the mechanism is best-effort and degrades to a full-scope review when git is unavailable; the reviewer's read-only git surface is the SINGLE `git_read` tool (ops diff/log/show/status) — `git_diff`/`git_log`/`git_show` are not registered tools; agent.md carries the re-review contract (delta-scoped rounds, pre-flight self-check, step-boundary commits so `git diff <base>` is exactly the fix).

OPEN CAVEAT (round-5 LOW 3, not a defect): the mechanism was never observed live — this plan's own rounds 1-6 were hand-scoped by the parent because the running binary predated the then-uncommitted feature, and the plan frame never grew a "## Reviews" section. Post-landing verification is queued as backlog item 8ea77b61 "Verify review-round stamps fire live post-landing" (check stamps + an app-rendered preamble on a round-2 spawn after a rebuild).
