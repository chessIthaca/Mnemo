The right-panel (tools panel) width is a FRACTION of the window width, never absolute px (plan 38b0e2eb, commit 1e9f8d4 on wt/mnemo, landed 2027-01-16). Persistence: localStorage mh.rightPanelWidthFrac (null = default flex-grow width); the legacy mh.rightPanelWidth px key is read-only — readRightPanelWidthFrac() (frontend/src/hooks/appearance.ts) seeds the fraction from it against the current viewport, no migration write. Band: clampPanelFraction(frac, innerWidth) — min = max(300/innerWidth, 0.15), max = min(PANEL_MAX_FRAC 0.5, (innerWidth − CHAT_MIN_PX 480)/innerWidth); both constants exported and shared with the render. Render (frontend/src/components/layout/RightPanel.tsx): style width = min(pct%, 50%, calc(100% - 480px)) — the inline caps make the CSS layout engine re-clamp the band at EVERY viewport (no resize listener; the min-w-[300px] class covers the floor between renders). Drag (frontend/src/App.tsx ResizeHandle): px pointer deltas convert to fractions via clampPanelFraction — live in-memory during drag (setRightPanelWidthFracLive), persisted on drag-end (setRightPanelWidthFrac). Store: rightPanelWidthFrac (useAgentStore.ts). Regression test: frontend/src/components/layout/RightPanel.width.test.tsx (node-env SSR pattern — store seeded via fake localStorage + vi.hoisted window stub; renderToStaticMarkup reads initial state).
