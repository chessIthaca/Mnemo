SPEC (backlog c439dda0, plan 89bbd2a9, commits e86d1a2/016b97d/8dbe4ef/622cb1a on wt/mnemo; supersedes the b804012f auto-delegate SPEC — its walk-skip and old escape-line details are the contradicted parts, everything else carries forward). The search/search_read engine contract:

(1) ENGINE: literal:true single-line queries are served by the CodeGraph FTS content index (engine: index) — and since c439dda0 so are REGEX-mode alternations whose every top-level branch is an escape-only literal: split_alternation_literals (search.rs — split on unescaped `|`, 2..=8 non-empty branches, every `\` quotes a non-alphanumeric so \d/\w/\s/\n disqualify, no unescaped metachar remains; branches un-escape to the exact literal, `memory\.db|codegraph\.db` → memory.db + codegraph.db). try_index_alternation runs try_index per branch, merges + dedups hits by (path, line), VERIFIES each kept line against the compiled regex (FTS phantom rows dropped — B1 exactness), total = sum of branch totals (hedged by the '... and more' line). Any branch returning None or Stale falls the WHOLE query back to the walk (staleness logged + surfaced); literal:true with `|` stays ONE verbatim literal; a fallback-fired (broken) regex never splits.

(2) PRUNE: one shared rule — IGNORED_DIRS (component names: target, node_modules, .git, .worktrees, …) + the new path-scoped IGNORED_DIR_PATHS (search.rs: `.coding/logs`, `.coding/tmp` — session JSONL event streams + gitignored red-check scratch; NOT a blanket `.coding/` exclusion: knowledge/plans/reviews/backlog stay searchable and a project's own `logs/` dir still searches). Consumed by should_search (file filter), the tool walk's descend, codegraph walk.rs visit() (both walkers), and the watcher's is_indexable_path — index coverage, walk coverage, and watcher triggers cannot drift apart.

(3) DELEGATION: symbol-shaped queries (bare identifier, fn X, symbol-intent, memory hunts) still auto-delegate, but the block PREPENDS above the normal results in the SAME response (merged_note) — the walk / search+read is NEVER skipped, no identical re-issue needed. Escape hatch unchanged: the DelegatedKey (pattern+glob+literal) joins the bounded bypass set; the repeat is the plain search alone. Block texts keep the steering markers: 'AUTO-DELEGATED to the code graph — X is an indexed symbol (the plain file matches follow below; re-issue this exact search to drop the block):' (codegraph.rs ESCAPE) and the memory twin (search.rs) — SEARCH_NUDGE_MARK ('is an indexed symbol') and the 're-issue this exact search' phrase both survive for the steering metric and the frontend display filters.
