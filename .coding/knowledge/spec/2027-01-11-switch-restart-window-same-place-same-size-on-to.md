SPEC: Switch-restart window lifecycle — the relaunched window must reopen exactly like the one it closed: same place, same size (re-maximized when maximized), and in the foreground. Landed on wt/mnemo commit 0ea1f41 (bug plan 3f87686a, user report 2027-01-24; round-2 review PASS).

Mechanics: switch_project (src-tauri/src/ipc/projects.rs) writes the pending-project marker then tauri::process::restart (spawn + hard exit(0) — no beforeunload ever runs). The reload half: src-tauri/src/main.rs setup peeks the marker (config::peek_pending_project — a NON-consuming read; build_brain's take_pending_project still owns the consume) before WindowBuilder::new and calls window.set_focus() after .build() — tao force_window_active (SetForegroundWindow + ALT-key SendInput fallback) wins the foreground Windows handed to another app when the old window died. Frontend (App.tsx geometry effect): save persists {…lastNormalBounds, maximized: true} while maximized (snapshotBounds fallback when no normal bounds known); restore applies clamped normal bounds then win.maximize(); debouncedSave refreshes lastMaximized fire-and-forget on every move/resize so beforeunload (synchronous, can't await IPC) never writes a stale flag; the picker awaits flushWindowGeometry() (lib/windowGeometryFlush.ts registry, registered by the effect) right before switchProject in both handleOpen and handleCreate — closing the 400 ms debounce gap across the hard exit.

Invariants to preserve: (1) peek must never consume the marker — build_brain's resolution order depends on it; (2) tao set_outer_position/set_inner_size use SWP_NOZORDER|SWP_NOACTIVATE, so the frontend geometry restore cannot disturb the Rust-side foreground fix — keep it that way; (3) localStorage survives the restart because the old process releases the WebView2 UDF mutex within ms of the spawn (webview_udf.rs) — don't add startup work that reaches that arbitration sooner. Regression guards: switch_restart_focuses_the_restarted_window (main.rs source contract), pending_marker_peek_* (config tests), windowRestore/windowGeometryFlush source contracts.
