## ADDED Requirements

### Requirement: Settings has an About page
The Settings dialog SHALL have an About page that shows the running Mnemo2 version, its MIT license, a link to the source code, and the open-source projects Mnemo2 is built on with their licenses.

#### Scenario: Reading the version
- **WHEN** the user opens Settings and picks About
- **THEN** the page shows the version of the running app
- **AND** the page lists the open-source projects with their licenses
