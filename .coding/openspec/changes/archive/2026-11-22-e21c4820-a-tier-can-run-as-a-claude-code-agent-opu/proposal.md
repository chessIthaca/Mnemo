In Settings → Tiers the user can set a tier to run as a Claude Code agent with a chosen Claude model. When Claude Code leads and a dispatch lands on that tier, Mnemo prepares the worktree and branch and hands the step to the lead's own Agent (no approval prompt); review and merge stay the normal Mnemo flow.

WHY: the user leads Mnemo projects from Claude Code. In FactoryGame they keep high-risk steps on Claude Opus agents (and Blender work on Fable), outside Mnemo's worker flow, and each Claude Agent launch is prompted by the Mnemo plugin's gate-agent hook even in bypass mode. They asked for the option in the Tiers dialog so a tier can say "this runs on a Claude Code agent", while everything else (plan board, review, audit, merge) stays Mnemo. Claude models cannot be Mnemo endpoints through the subscription (user ruled that out for ToS reasons), so the agent is run BY the Claude Code lead with its own Agent tool; Mnemo only prepares, gates and tracks it.
