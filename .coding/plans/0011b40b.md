# Plan: create_plan probe-evidence gate: reachability claims need an evidence marker (backlog 5b232b8d)

## Goal
The plan gate rejects — and the create_plan schema teaches — unevidenced reachability claims: a context line asserting a symbol is callable/reachable must carry an evidence marker (`verified:` / probe vocabulary) or be explicitly labelled as an assumption, so plans stop encoding assumptions as findings. Acceptance: (a) the schema/description distinguishes assumption from verified-with-evidence; (b) unit + tool-level tests in src/tool/workflow/plan.rs prove the gate flags an unevidenced reachability claim and accepts an evidenced one; (c) all existing resumability-gate tests stay green (the path-naming gate is not weakened); (d) the schema-doc budget baselines in src/agent/factory.rs are updated in the same commit.
