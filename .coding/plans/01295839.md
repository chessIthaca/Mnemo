# Plan: Flaky test: idle-compaction savings row waited for with a fixed yield count

## Goal
The idle-compaction tests wait for the savings row with a real-time bound, so a loaded CI runner can no longer fail them while the row is still being written.

## Kind
bug_fixing

## Context
ROOT CAUSE: `AgentLoop::record_savings_event` (src/agent/turn.rs about line 4551) writes the ledger row from a `tokio::spawn`ed task that awaits `MemoryStore::record_savings_event` (src/memory/mod.rs about line 2592), which runs the INSERT on `tokio::task::spawn_blocking` — a real OS thread. The tests run under `#[tokio::test(start_paused = true)]` and then poll `store.savings_events_rows(None)` at most 100 times with `tokio::task::yield_now()` between polls. That bound is a count, not a time: when the blocking pool is slow (a loaded Windows CI runner running the whole suite), 100 polls finish before the INSERT lands and the assertion fails. Two tests share the pattern: `idle_compaction_uses_the_measured_lifetime_and_records_the_row` (the loop at about lines 8225-8241) and the helper `committed_cut_scenario` (about lines 8012-8026, used by the committed-cut tests).

FIX (tests only, src/runtime/agent.rs `tests` module): one new helper that polls until the row appears or a REAL 10 s deadline (`std::time::Instant`) passes, and both call sites use it. Under paused tokio time a `tokio::time::sleep` would not wait in real time, so the bound must be `std::time::Instant`; each poll awaits a `spawn_blocking` read, so the loop is not a hot spin. No product code changes.

REGRESSION TEST: the failing test itself, `idle_compaction_uses_the_measured_lifetime_and_records_the_row` (src/runtime/agent.rs tests module), plus the committed-cut tests through `committed_cut_scenario`. The flake cannot be forced deterministically; the red evidence is CI run 43632496108. The fix is proven by the tests passing repeatedly under load: run the module's idle tests 5 times in a row.

VERIFY: `cargo test -p mnemo --lib runtime::agent::tests::idle_compaction` 5 times (all pass); `cargo test -p mnemo --lib runtime::agent::tests::committed` (or the committed-cut tests by name) passes; `cargo clippy -p mnemo --all-targets` clean; `cargo test --workspace --no-fail-fast` passes. `#![deny(warnings)]` applies.
