# Plan: Endpoints tab: fix scrolling + collapsible endpoint cards

## Goal
Make the Endpoints tab in the Settings dialog scroll properly (currently content gets clipped because the flex chain lacks min-h-0), and make each endpoint card collapsible — collapsed by default — with an expand/collapse chevron and a compact summary row, auto-expanding newly added endpoints.

## Context
ConfigDialog.tsx (frontend/src/components/layout/ConfigDialog.tsx): the dialog is `flex max-h-[90vh] flex-col overflow-hidden`; the body div is `flex-1 overflow-hidden` and the TabsContent is `flex-1 overflow-y-auto`. Neither has `min-h-0`, so a flex item's min-height:auto resolves to its content height: tall endpoint lists make the body grow past 90vh and the outer overflow-hidden clips the content — the inner overflow-y-auto never engages, so no scrollbar appears. Fix: add `min-h-0` to the body div and to both TabsContent panels. EndpointCard currently always renders all fields (name, kind, base_url, api key, effort, multimodal, models list, default toggle). Collapsible design: header row (chevron + name input + Default badge + delete) always visible; collapsed state shows a compact summary line (kind, base_url, model count); expanded shows the rest. State lifted to EndpointsTab as a Set of expanded uids so 'Add endpoint' can auto-expand the new card and 'Reset/load' returns everything to collapsed. lucide-react is already a dependency (ChevronDown needed). Frontend only; verify with `npm run build` (tsc + vite) and `cargo test` per the standard closing sequence. Current branch: feat/bookkeeping-tools-autorun (working tree clean except a leftover plan-file modification).
