# Plan: Backlog items must have a headline and a body — enforce the shape in backlog_add

## Goal
Every NEW backlog item carries the headline+body shape the Backlog tab renders (backlog 40763a24): first line a short headline (≤100 chars), then the body. Enforced at both write paths — the agent-facing backlog_add tool (rewritten text-param description + hard validation with an actionable, retry-in-one-shot error) and the UI's IPC backlog_add command (same shared validator in src/backlog.rs) — with the frontend surfacing the rejection instead of swallowing it. Existing items are grandfathered: no migration, the store's add stays unvalidated.
