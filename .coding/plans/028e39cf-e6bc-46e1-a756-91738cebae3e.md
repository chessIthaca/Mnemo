# Plan: LLM tool-error handling: no strike-out on bad JSON, separate error/success cards, error descriptions

## Goal
Three coupled changes to how LLM/tool errors are handled and displayed: (1) stop counting LLM-produced malformed tool-call arguments (bad JSON) toward the 3-strike turn abort — the model can recover by emitting valid JSON, so it gets a separate, higher cap; (2) stop merging errored tool calls into the same ToolCard as successful ones; (3) show a simple one-line error description for errored tool calls in the ToolCard.

## Kind
implementation
