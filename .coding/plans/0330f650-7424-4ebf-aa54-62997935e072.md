# Plan: git_diff output must never be truncated (review-critical exception)

## Goal
Make the git_diff tool exempt from cap_tool_output so a reviewer subagent always sees the FULL uncommitted diff — a truncated diff can hide part of the changes under review. This is the user-mandated exception to the 100 KiB tool-output cap: git_diff passes its combined output through uncapped, with a regression test proving a >100 KiB diff is not truncated.
