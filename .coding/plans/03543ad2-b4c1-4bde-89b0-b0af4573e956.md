# Plan: Suppress webview context menu in Mnemo UI (except editable fields + Browser tab)

## Goal
Suppress the webview's native right-click (context) menu across the entire Mnemo UI, except inside editable text fields (input/textarea/contenteditable) where Copy/Cut/Paste stays useful. The Browser tab is a separate native child WebView2, so it keeps its full context menu with no special handling.

## Kind
implementation

(1) `export function isEditableContext(tag: string | undefined, contentEditableAttr: string | null): boolean` — a pure, DOM-free decision: returns true when `tag` is `"INPUT"` or `"TEXTAREA"`, OR when `contentEditableAttr` is `""`, `"true"`, or `"plaintext-only"` (the values that make a host editable; `"false"`/`"inherit"`/null are not). Add a doc comment explaining the attribute-value semantics. (2) `export function isEditableTarget(target: EventTarget | null): boolean` — DOM-facing glue: resolve `target` to an Element (if `target instanceof Element` use it; if `target instanceof Text` use `target.parentElement` so a right-click on selected text inside a contenteditable still counts; else null), then if `el.tagName` is INPUT/TEXTAREA return true, else find `el.closest("[contenteditable]")` and delegate to `isEditableContext(el.tagName, host?.getAttribute("contenteditable") ?? null)`.
