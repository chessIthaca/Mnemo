# Plan: Memory debug tab (mirrors Trace)

## Goal
Add a right-panel "Memory" debug tab that surfaces the memory system's internals: embedder status + model, stored vector fingerprints (mismatch detection), per-tier counts, a recall test box, and a browsable memory list with detail — mirroring the Trace tab's architecture.

## Kind
implementation

## Context
The user wants to debug the memory system (storing, receiving, model failures/successes) the way the Trace tab debugs LLM requests. The Trace tab pattern: a shared log in IpcState, a small IPC module (ipc/trace.rs) with list/get/clear commands, and a polling view component (LlmTraceView.tsx). The memory system already has the store-side methods (MemoryStoreTrait: list_by_tier, recall, stored_model_fingerprints; MemoryStore: embedder_handle which gives model_id + dim) and IpcState.runtime.memory_store: Option<Arc<MemoryStore>> + embedder_status: Arc<RwLock<EmbedderStatus>> are already wired. The gap is purely IPC exposure + a frontend view. Tab registry: RightPanelTab union + ALL_RIGHT_PANEL_TABS in frontend/src/hooks/agentState.ts:198-222; RIGHT_PANEL_VIEWS in frontend/src/hooks/rightPanelViews.tsx:50-61 (rightPanelViews.test.ts asserts parity). IPC modules registered in src-tauri/src/ipc/mod.rs:15-33 + invoke_handler in src-tauri/src/main.rs:382-397. Windows PowerShell; cargo test unpiped; zero warnings under #![deny(warnings)]; CRLF for existing files.

## Steps
- [x] 1. **Backend: add `memory_debug.rs` IPC module** — Create `src-tauri/src/ipc/memory_debug.rs`. Add wire types (all with doc comments): `MemoryDebugWire { id, tier: String, title, content: String (truncated to 500 chars in the mapping), strength: f64, access_count: u32, created_at: i64, last_accessed_at: i64, source_session_ids: Vec<String>, data: serde_json::Value }`, `ScoredMemoryDebugWire { memory: MemoryDebugWire (flatten), score: f64 }`, `MemoryCounts { working, episodic, semantic, procedural, total: usize }`, `MemoryDebugOverview { status: String, model_id: String, dim: usize, configured_model: Option<String>, fingerprints: Vec<(String, usize)>, fingerprint_matches: bool, counts: MemoryCounts }`. Add 3 `#[tauri::command]` async fns: `memory_debug_overview(state) -> Result<MemoryDebugOverview, IpcError>` — reads embedder_status; if memory_store is Some, gets embedder_handle().model_id() + .dim(), calls stored_model_fingerprints() + list_by_tier for each of the 4 tiers (count lengths); reads config.general.general.bundled_embedding_model; computes fingerprint_matches (fingerprints contains (model_id, dim)); if memory_store is None, returns zeroed counts + empty fingerprints + model_id "<none>". `memory_debug_list(state, tier: Option<String>, limit: Option<usize>) -> Result<Vec<MemoryDebugWire>, IpcError>` — parses tier string via MemoryTier::from_str, calls list_by_tier (or all 4 tiers if None), truncates content to 500 chars, applies limit. `memory_debug_recall(state, query: String, limit: Option<usize>) -> Result<Vec<ScoredMemoryDebugWire>, IpcError>` — calls store.recall(query, &MemoryFilter::new().limit(n).include_working()), maps ScoredMemory to wire. All commands return Err(IpcError::msg("memory store unavailable")) when memory_store is None.
