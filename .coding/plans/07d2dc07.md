# Plan: Per-endpoint tok/s breakdown — one stats row per (model, endpoint)

## Goal
The Stats view's per-model breakdown distinguishes endpoints serving the same model id: request_stats records the serving endpoint (provider_name at the Usage event), the breakdown groups by (model, endpoint), and ModelTable shows an Endpoint column — so two GLM5.3 endpoints (A100 vs B200) render as two rows with their own Out tok/s. Old rows (NULL endpoint) group into one row per model, keeping the existing per-model view working.

implementation
