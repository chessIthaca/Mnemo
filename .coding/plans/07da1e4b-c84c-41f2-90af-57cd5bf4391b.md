# Plan: Memory system overhaul: stop working-tier noise, fix ranking, auto-consolidate

## Goal
Transform memory recall from "stale working-tier tool snapshots" to "distilled facts" by (A) excluding working-tier from recall by default, (B) making record_tool_event selective, (C) adding tier weighting to the score, (D) down-weighting the noise-dominated sim term, (E) auto-consolidating at session end (not just Cancel), and (F) capping working-tier content.

## Kind
implementation

## Context
The memory system is not working well. Live proof: every memory_recall hit in this very session is a stale `working`-tier raw tool snapshot (`tool: search` → "100 matches in 34 files", `tool: user_correction`, `tool: read_files`) — not a distilled fact. Root causes (verified by reading src/memory/{mod,strength,types,embedder,schema}.rs + call sites):

1. WORKING-TIER POLLUTION (dominant): `record_tool_event` (src/memory/mod.rs:700) writes EVERY tool call as a working-tier memory — title `"tool: search"`, content = full raw tool output, strength 1.0. A session writes dozens. They match common FTS keywords (file contents are full of words like "review", "memory", "search"), earn +0.2 keyword boost, and with fresh last_accessed_at their decayed strength is ~1.0 → score ~0.5 → crowd out everything.

2. NO TIER PREFERENCE IN SCORE: formula `sim*0.7 + decayed_strength*0.3 + keyword_boost` (mod.rs:592) treats all four tiers identically. A distilled semantic fact and a raw snapshot compete on equal footing.

3. HASHEMBEDDER MAKES sim NOISE: `hash_embedding` (embedder.rs:55) is a random hash projection measuring token overlap, not meaning. So `sim*0.7` (70% of score!) is a worse version of the keyword boost. The "semantic" component is broken by design.

4. CONSOLIDATION RARELY RUNS: `delete_working_for_session` only fires inside `consolidate_session`, which the agent almost never calls spontaneously. Auto-consolidation exists ONLY on Cancel (src/runtime/agent.rs:316-329), not on normal session end. So working memories accumulate across sessions forever.

5. AUTO-RECALL EVERY TURN: turn.rs:251 `MemoryFilter::new().limit(5)` — no tier filter, loads ALL tiers including working, injects noise into the system prompt each iteration.
