# Plan: Friendly non-git error + "Initialize repository" button in Diff tab

## Goal
When the Diff tab's "vs Git" mode runs in a directory that isn't a git repository, show a clean, friendly message (not git's giant usage dump) with a button to initialize a git repository in place. Also handle the "no commits yet" case that arises immediately after init.

## Kind
implementation
