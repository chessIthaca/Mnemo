# Plan: Fix plan: consolidated review findings

## Goal
Address all actionable findings from the four-perspective code review (architecture, quality, PRD, performance) in priority order. Each fix is scoped to be independently shippable with tests.

## Context
Four review documents were produced in reviews/01-04. The user approved them and asked for a fix plan covering ALL findings. Findings range from performance bottlenecks (frontend re-render, reqwest client reuse, memory recall scaling) to correctness gaps (no tool-result truncation, FTS5 unused, constitution not re-read) to quality issues (dead code, test gaps, interrupt during summarization). The plan must be ordered by priority: high-impact user-facing fixes first, then scaling/correctness, then cleanup. Each step should be independently testable. The project constitution requires: Windows paths, cargo test before marking complete, never commit to main.

## Steps
- [x] 1. 1. Reuse reqwest::Client in OpenAiClient — store a single Client in the struct instead of creating one per complete() call. Add a 120s request timeout via Client::builder(). This eliminates TLS overhead on every LLM request and prevents hung connections. Test: verify the client is reused (same instance) across multiple complete() calls.
- [x] 2. 2. Frontend streaming throttle — batch text_delta events with requestAnimationFrame so the Zustand store updates once per frame (~60fps) instead of per-token. Throttle scrollIntoView to once per 100ms. This is the primary user-visible performance fix.
- [x] 3. 3. Memoize Message component + skip markdown during streaming — wrap Message in React.memo with a custom comparator. During active streaming (streamingText is non-empty), render the streaming tail as plain text; parse markdown only on finished. Reduces per-delta cost from O(text_length) markdown parse to O(1) string append.
- [x] 4. 4. Add tool-result truncation — cap file_read output (default 100KB / 2000 lines) and search results (default 100 matches) with a truncation note. Prevents unbounded conversation bloat. Update the agent loop or tool implementations to truncate before pushing to messages.
- [x] 5. 5. Wire up FTS5 for keyword pre-filtering in memory recall — use the existing memories_fts table to pre-filter candidates by keyword match, then cosine-rank only the top candidates. Reduces recall from O(N) full scan to O(K) where K << N. Falls back to full scan if FTS5 unavailable.
- [x] 6. 6. Clean up working memory after consolidation — delete or archive working-tier events for a session once an episodic summary is created. Prevents unbounded working-memory growth that slows every recall. Add a cleanup step in consolidate_session.
- [x] 7. 7. Batch access() updates in recall — replace the per-result access() loop with a single UPDATE ... WHERE id IN (...) query. Reduces K lock+query cycles to 1.
- [x] 8. 8. Re-read constitution from disk each turn — change AgentLoop to re-load the agent.md files on every turn (or cache with mtime check) so edits to agent.md take effect without restart. Matches the PLAN.md spec.
- [x] 9. 9. Handle interrupts during context summarization — add a select! on cmd_rx in the summarization stream loop so Interrupt/Cancel are honored during the summarization LLM call.
- [x] 10. 10. Cache token count per loop iteration — compute count_tokens once and reuse for both should_summarize and ContextUsage event. Eliminates redundant double-counting.
- [x] 11. 11. Fix SSE buffer copy — replace buffer = buffer[pos+1..].to_string() with String::drain() to avoid O(n²) copying on multi-line chunks.
- [x] 12. 12. Remove dead code in openai.rs — delete build_request, map_chunk, convert_finish_reason, reassemble_tool_calls, extract_reasoning_delta (all #[allow(dead_code)]). Keep only the raw-JSON path (build_request_json, parse_sse_chunk).
- [x] 13. 13. Track agent running state + cleanup dead agents — add a running flag to AgentHandle, set it on Started/Finished events, and remove dead agents from the manager. Fix list_agents to return real running state.
- [x] 14. 14. Clean up stale pending approvals — add a cleanup method to PendingApprovals that drops senders for agents that have exited. Call it on agent removal.
- [x] 15. 15. Add tests for context summarization, SSE parsing, and consolidation-with-LLM — the three biggest test coverage gaps. Use mock providers for summarization and consolidation; use canned SSE JSON for parse_sse_chunk unit tests.
- [x] 16. 16. Fix error handling: replace unreachable!() in complete_with_retry with a return Err fallback; replace string-matching retry detection (event.error.includes('retrying')) with a dedicated AgentEvent::Retry variant or boolean field.
