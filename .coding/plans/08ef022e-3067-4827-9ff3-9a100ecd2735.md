(4) `list_filtered(filter: &MemoryFilter) -> Result<Vec<Memory>>` — tier + record_type + superseded filtering with LIMIT, backed by the new indexes. (5) recall(): exclude superseded rows by default (WHERE superseded_by IS NULL unless filter.include_superseded), apply record_type filter when set; when superseded rows are explicitly included, annotate their output lines with '[superseded]'. (6) write(): derive record_type via MemoryRecordType::from_title — title prefix wins over caller-passed value. (7) Row-to-Memory mapping reads the three new columns (may already be done in the previous step for compilation). Tests: update roundtrip + FTS reflects new content; supersede hides old from default recall but include_superseded returns it annotated; supersede of missing/already-superseded id errors; delete removes from recall+list; list_filtered filters by tier/record_type; recall exclusion default. Keep MemoryStoreTrait object-safe (async_trait pattern as existing).
