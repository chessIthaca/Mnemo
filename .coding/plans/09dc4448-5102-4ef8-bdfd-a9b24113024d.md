# Plan: Multiline aligned tooltips for the Trace tab graphs

## Goal
Replace the Trace tab graphs' single-line native tooltips with multiline, aligned, color-coded HTML tooltips (portal-rendered so chart overflow can't clip them), with the formatting logic in pure unit-tested functions.

## Kind
implementation

## Context
User request (backlog, unattended): "the tooltips for the graphs in trace, can they please be multiline for readability? Also do use some formatting and tabs to make it easy to read." Same branch as the rest of the batch (fix/compact-bugs).

Current state found:
- frontend/src/components/views/TraceStats.tsx renders the Trace tab's three column charts; every chart column carries a NATIVE single-line `title` tooltip via the `Column` component (line 103): PhaseChart (line 160, `·`-separated 8-segment phase values), TokenChart (line 207, token counts), CacheChart (line 261, hit %). Long, unreadable, unaligned.
- Row data types live in frontend/src/lib/traceStats.ts: PhaseSeriesRow (id/label/prepMs/compactMs/sendMs/waitMs/genMs/reasoningMs/answerMs/toolsMs/totalMs), TokenSeriesRow (id/label/prompt/cached/completion/reasoning), CacheHitRow (id/label/hitPct|null). fmtPhase/fmtInt are LOCAL to TraceStats.tsx (lines 38-48); fmtDuration lives in lib/format.
- vitest runs in node env with an EXPLICIT per-file include list in frontend/vitest.config.ts (new test files must be registered there; learned the hard way in the previous task).
- createPortal precedent: frontend/src/components/views/BacklogView.tsx:6,597.

Decisions (documented for review): (a) custom HTML tooltip instead of native title — native tooltips support \n but no column alignment/styling, and the user explicitly asked for formatting + tabular layout; (b) portal-rendered fixed-position tooltip (BacklogView precedent) because the chart containers clip overflow (overflow-x-auto / overflow-hidden) and would cut an in-tree absolute tooltip; (c) tooltip content built by pure row-builder functions in lib/traceStats.ts so the formatting is unit-testable in the node test env; (d) tabular alignment via flex rows (dot + label left, mono value right) — real tab chars don't render in HTML tooltips.
