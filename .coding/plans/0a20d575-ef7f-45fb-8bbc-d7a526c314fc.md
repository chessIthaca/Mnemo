# Plan: Make font size apply to markdown, plan, output, diff & safety views

## Goal
The user's chosen font size (set in ConfigDialog, stored as --app-font-size) is ignored in the right-panel tabs: Markdown, Plan, Output, Diff, and Safety. Make these views respect the font size like the chat already does.

## Context
The chat (Conversation.tsx + Message.tsx) already respects --app-font-size: it sets the font vars on its container and uses em-based arbitrary values (text-[0.875em]) that scale with the inherited base. The 5 right-panel views were never converted — they use rem-based Tailwind utilities (text-xs, text-sm, text-[10px]) which are relative to the <html> root (16px), not to --app-font-size, and none set the font vars on their containers.

Fix: (1) Apply the font vars on the shared RightPanel content container so all views inherit the base size. (2) Convert rem-based text utilities in each view to em-based arbitrary values. (3) Fix the shared DiffView.tsx and the .hljs hardcoded font-size in globals.css. (4) Override prose-sm's own font-size so markdown inherits the base.
