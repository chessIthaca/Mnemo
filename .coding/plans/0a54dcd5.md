# Plan: Skip LlmTraceView detail re-fetch when version unchanged

## Goal
Stop re-fetching the full (up to ~2MiB) trace detail every 1.5s while the selected record is unchanged: add a mutation `version` integer to the trace record (bumped on every mutation and payload eviction), expose it in the list/summary payload, and have LlmTraceView's detail/compare polls skip the fetch when the selected record's version is unchanged since the last fetch.

## Kind
implementation
