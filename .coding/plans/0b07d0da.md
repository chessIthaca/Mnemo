# Plan: Dedicated summarization model slot ([models.summarize])

## Goal
Add a dedicated [models.summarize] slot so users can route compaction summaries (auto-compaction + the run-all between-items compact) to a cheaper model instead of the turn's (often premium) model. Unset inherits today's behavior exactly (the turn's provider). Full plumbing: config slot + resolver method + routing at all three summary call sites + Settings UI row + persistence + docs + tests.

## Kind
implementation
