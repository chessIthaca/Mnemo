# Plan: Per-agent model switching + live streaming reasoning panel

## Goal
Fix two user-reported bugs: (1) the toolbar model picker switches EVERY agent's model instead of only the active agent (models are agent-specific); (2) the reasoning box only shows the reasoning at the end instead of streaming visibly as pieces arrive.

## Kind
implementation

## Context
Backlog #83 (toolbar model bug, user chose "Only the active agent switches") + #84 (reasoning streaming display). Current mechanics verified by reading: `set_model` (src-tauri/src/ipc/agent.rs:416) calls `config_io::swap_live_provider` which swaps the provider into the factory + EVERY live agent loop and emits `ModelChanged { model }` for EVERY agent; frontend StatusBar.selectModel also writes the global `model`/`provider` stores, so every agent's label/tab shows the switched model. The label already reads `agentModels[activeAgent] ?? model` (StatusBar.tsx:82), and `model_changed` reducer stamps per-agent correctly — the bug is the global swap + per-agent event fan-out + global store writes. Reasoning streaming: backend streams ReasoningDelta per chunk (turn.rs:807-823) and the frontend appends them to the activityLog per rAF flush (useAgentEvents.ts + useAgentStore.appendStreamingReasoning) — that path works, but the InflightBar reasoning panel is collapsed by default (`useState(false)`, InflightBar.tsx:66), so nothing is visible until the user opens it after the turn. Previously the panel was effectively always open (2026-08-12 review "Fix stuck-open reasoning panel"). Plan: make set_model per-agent (agent_id param; Some = swap only that loop + emit only for it, None = legacy global for back-compat), rewire the StatusBar picker/effort dropdown to the active agent's model + endpoint (new endpointForModel helper), and auto-expand the reasoning panel once per reasoning block (new pure helper for testability). save_endpoints (config default change) stays global — a config save resets all agents to the new default (documented). The console /model REPL stays global (single-agent surface; update its stale "mirrors set_model" comment). Windows/PowerShell; cargo test unpiped at root AND in src-tauri; npm run build + npm test from frontend/; zero warnings under #![deny(warnings)]; every defect gets a regression test. Branch from main.
