# Plan: Graph tab finds every indexed symbol; call edges stop matching by bare name across languages

## Goal
Every symbol the Graph tab lists can be opened, and call edges only link a call to a definition that can plausibly be its target, so helper names like `join` stop collecting every `.join(` call in the repository.

## Kind
bug_fixing

## Context
Why: the user clicked `join` in the Graph tab and got the unknown-symbol error above.

Verified facts:
- verified: the symbol exists — `src/tool/agent/shell_filter.rs` lines 683-685 are `fn join(lines: &[&str]) -> String { lines.join("\n") }` inside the file's test module, and Mnemo's MCP `graph_search {"query":"join"}` returns id `src/tool/agent/shell_filter.rs::join::683`.
- verified: MCP `graph_context` on that id returns found=true with `incoming_total: 1489` callers and `outgoing_total: 0`; the callers include Python files (`.coding/analysis/cache-hit-5-extract.py`), TypeScript/TSX (`frontend/src/components/views/GitView.tsx`, `frontend/src/lib/toolCardPaths.ts`), `.mjs` scripts and `examples/second_consumer.rs` — every `.join(` method call in every language was resolved by bare name to this one Rust test helper.
- verified: the Graph tab's commands live in `src-tauri/src/mnemo2/graph.rs` (`graph_neighbourhood` → `neighbourhood_in` → `neighbourhood_capped`, `graph_context` → `context_in`, `graph_impact` → `impact_in`), each loading `CodeGraph::view()` (`src/codegraph/mod.rs` line 389 → `GraphView::load(&self.store())`) and returning `unknown_symbol(id)` when the query gives `None`. `GraphView::slice` (`src/codegraph/query.rs` line 382) returns `None` only when `by_id.get(root)` misses, so the app's loaded view lacked the id while the MCP path (`src-tauri/src/mnemo2/mcp_server.rs` `graph_context`, around line 2209) found it.

Part 1 — the unknown-symbol error. Reproduce first: load the real index the app uses and call the same core functions the commands call (`neighbourhood_in`, `context_in`, `impact_in`) with this id; compare with how the MCP `graph_context` resolves ids. Candidate causes to check (assumptions, not findings): the app and the MCP path read different stores or snapshots (a cached or stale view, a different project root or worktree index); the frontend passes a different id than it received (encoding, trimming, a ring node the view drops); `GraphView::load` dropping symbols (e.g. test-module symbols) that the MCP path keeps. Fix the real cause, and make the error honest: if the index really changed, refresh once automatically and retry before showing an error.

Part 2 — bare-name call resolution. assumption: the call-edge resolver lives under `src/codegraph/` (locate it first). Stop linking a call to a definition by name alone when the call cannot target it: at minimum never across languages (a Python or JS `.join(` must not resolve to a Rust fn), and for method-call syntax (`x.join(...)`) do not resolve to a free function. Leave an unresolved call unresolved rather than guessing. Keep same-language resolution working (existing codegraph tests stay green); add tests for the cross-language and method-call cases.

Regression test: `graph_tab_opens_every_listed_symbol` in the `#[cfg(test)]` module of `src-tauri/src/mnemo2/graph.rs`: build a fixture graph (or index a small temp project) where the failing condition you reproduced holds, list symbols the way the tab lists them (search/top), and assert `neighbourhood_in`, `context_in` and `impact_in` all return Some for each. Without the fix it fails on the symbol that reproduced the bug. Add a second test for Part 2 in `src/codegraph/` (e.g. `method_call_in_another_language_does_not_resolve_to_a_rust_fn`).

Verification: `cargo test --lib codegraph` (root crate), `cargo test --manifest-path src-tauri/Cargo.toml --features mnemo2 --lib mnemo2::graph`, and both clippy runs (`cargo clippy --lib --tests -- -D warnings`; `cargo clippy --manifest-path src-tauri/Cargo.toml --features mnemo2 --lib --tests --bins -- -D warnings`). Never start a dev server or any command that does not exit on its own.

## Acceptance scenarios

- Same-language calls to real functions keep their caller/callee edges (existing codegraph tests stay green).
