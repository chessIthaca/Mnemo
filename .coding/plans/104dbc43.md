# Plan: Bug-fixing model + reasoning-effort slot (per-plan-kind override)

## Goal
Add a `[models] bug_fixing` slot — a Settings → Models row (model picker + effort dropdown, persisted like the other ModelRef slots) that takes effect when the active plan's kind is bug_fixing: a bug-fixing session resolves the bug-fixing slot's model/effort (e.g. max reasoning) while implementation plans keep the executing slot; an unset or dangling slot inherits today's executing/context chain. Honored on every spawn path via the agent loop's per-iteration resolution (in-app plan creation and run-all item dispatch both flow through it).

implementation
