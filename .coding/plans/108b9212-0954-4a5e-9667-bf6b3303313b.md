# Plan: Auto-show/hide tools panel on toggle

## Goal
When toggling a tool on via the sidebar, open the tools panel. When toggling off the last enabled tool, hide the empty panel and disable the show/hide collapse toggle.

## Context
Sidebar.tsx `handleToggleTool` calls store `toggleTab` (store owns disabledTabs + rightPanelTab). Panel visibility is `rightPanelVisible` in App.tsx. Store also has `toggleRightPanel`. Need a store action that both toggles the tab and shows the panel when enabling, hides the panel when the last tool is disabled. Sidebar's PanelRight toggle should be disabled when no tools are enabled.

## Steps
- [x] 1. Add a `toggleTabAndReveal` store action (or extend toggleTab) that shows the right panel when a tool is enabled and hides it when the last tool is disabled
- [x] 2. Update Sidebar `handleToggleTool` to use the new store action
- [x] 3. Disable the PanelRight show/hide button when no tools are enabled
- [ ] 4. Run cargo test / frontend build to verify
