# Plan: Per-context reasoning-effort overrides in the Models tab

## Goal
Each [models] context slot (planning/executing/reviewing/complete/subagent/per-skill) carries an optional reasoning_effort alongside endpoint+model — ModelRef.reasoning_effort in config.toml, applied when the resolver builds the context's turn provider (context effort > per-model default > endpoint > "max"), editable via an effort dropdown on each Models-tab row (unset = the model's own default). Anthropic-kind endpoints: field ignored + dropdown hidden.
