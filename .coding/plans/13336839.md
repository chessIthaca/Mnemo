# Plan: Slash commands in Mnemo2's lead composer

## Goal
Typing /new (or /clear), /compact, /model <name> [effort], /stop or /help in the lead's message box runs that command instead of sending text, and a small menu suggests the commands while you type a slash.

## Kind
implementation

## Context
WHY: On 2026-11-11 the user decided to retire Mnemo1 (frontend/ + src-tauri/src/ipc/) as is. The one Mnemo1 feature that still moves to Mnemo2 is the chat slash commands of Mnemo1's InputBar (frontend/src/lib/slash.ts). A separate plan deletes frontend/ — so this plan must NEVER import from frontend/; copy ideas, not modules.

WHAT CARRIES OVER (Mnemo1 → Mnemo2):
- /new and /clear → start a fresh lead conversation (both names, one action). Mnemo2 has no host command for this yet; step 1 adds `lead_new`.
- /compact → the existing compactLead store action (lead_compact).
- /model <name> [effort] → the existing setLeadModel store action (lead_set_model). Mnemo2 model specs are `endpoint/model`, so Mnemo1's /provider is folded into /model.
- /help → a sheet listing the commands.
- NEW in Mnemo2: /stop → the existing Stop button's action (interruptLead).
- NOT carried over: /save and /load (the user skipped them), /provider (covered by /model), /panel (Mnemo2 has no right-panel toggle).

RULES (both steps):
- Only the lead composer (mnemo2/src/components/Composer.svelte) gets commands; worker reply boxes (WorkerThread.svelte) do not.
- A draft is a command only when its first token is "/" + a known command name (case-insensitive). Anything else, e.g. "/usr/bin is missing", is sent as a normal message.
- Commands never send a prompt or a steer, and the "Claude Code is leading" send confirmation does not apply to them.
- Commands work while the lead is busy or waiting on an approval/question. /new and /model need an idle lead (the host refuses otherwise); /stop needs a busy lead.
- ComposerBox.svelte stays store-free: it only gains an optional key hook.

HOST FACTS (verified 2026-11-11): LeadRuntime in src-tauri/src/mnemo2/runtime.rs has `set_model` (≈line 805), which snapshots the live session, spawns a fresh one with `spawn_live(generation, selected_model, spawn_model, reasoning_effort, transcript)`, saves `LeadPersistence` (state_dir/lead.json: model, reasoning_effort, transcript), bumps `generation` and aborts the old session. `lead_new` reuses this path with an EMPTY transcript and the current model. The headless engine also has SessionCommand::Clear, but it would leave the persisted transcript and the UI transcript stale, so do NOT use it.

FRONTEND FACTS: LeadTransport + createTauriLeadTransport live in mnemo2/src/lib/leadEngine.ts. Store actions live in mnemo2/src/lib/store/lead.ts (setLeadModel ≈line 413 is the pattern for applying a returned snapshot: leadStream.flush(); app.update(current => applyLeadSnapshot(current, snapshot))). Actions are re-exported through mnemo2/src/lib/store.ts (both the import list ≈line 64 and the `actions` object ≈line 203). The models the picker offers are `$app.leadRuntime.models` (LeadModel: endpoint, model, spec, is_default, reasoning_efforts?, default_effort?).

GUARD: src-tauri/src/mnemo2/mod.rs test `every_frontend_invoke_string_is_a_registered_command` fails when the frontend invokes a command that is not registered — step 2 may only merge after step 1.

VERIFY: cargo test -p mnemo-app --features mnemo2 --lib; cargo clippy -p mnemo-app --all-targets --features mnemo2 (must be warning-free: #![deny(warnings)]); npm test --workspace mnemo2; npm run check --workspace mnemo2; npm run build:mnemo2.

## Acceptance scenarios
- Typing /compact in the lead composer and pressing Enter calls the lead_compact command and sends no prompt; the draft is cleared.
- Typing /new (or /clear) on an idle lead calls lead_new; the transcript in the UI empties, the model stays the same, and state_dir/lead.json holds an empty transcript.
- Typing /new while the lead is working shows a toast asking to stop the turn first and keeps the draft.
- Typing /model glm on a setup with exactly one model spec containing 'glm' switches the lead to that model; an ambiguous or unknown name shows a toast listing the models and keeps the draft.
- Typing /c shows a menu with /clear and /compact; ArrowDown + Enter runs the highlighted command.
- Typing '/usr/bin is missing' sends that text to the lead as a normal message.
- /help opens a sheet that lists every command with its usage.
