# Plan: Release 2.0.0: fold in the open GitHub security fixes and bump the version

## Goal
Every open Dependabot security alert that has a fixed version is resolved on wt/mnemo (zip, rustls, vite/launch-editor, @vitest/mocker, source-map-js, postcss-selector-parser), and every Mnemo and Mnemo2 manifest says 2.0.0, so the branch can go to main as the 2.0 release.

## Kind
implementation

## Context
Why: the user wants a 2.0 release on GitHub (PR wt/mnemo -> main, merge, tag v2.0.0, which triggers .github/workflows/build.yml to build installers and publish the release). They asked to fold in any security fixes GitHub reports first. Open Dependabot alerts on chessIthaca/Mnemo (2026-11-05):
- Rust `zip` (Cargo.toml and src-tauri/Cargo.toml both declare `zip = "8"`, lock has 8.6.0): 1 critical (zip cloaking, fixed 9.0.5), 3 high + 1 medium (fixed 9.0.0). Target zip 9.0.5 or newer 9.x. Only user of the crate API: src/host/laya.rs (search `zip::`). Major-version bump: fix any API change there, keep behaviour identical.
- Rust `rustls` (lock only, via reqwest rustls-tls): alerts fixed in 0.23.45/0.23.46. Target >= 0.23.46 via `cargo update -p rustls`.
- npm `vite` (frontend/package.json and mnemo2/package.json `^8.3.1`): 7 alerts incl. launch-editor, fixed in 8.3.3. Target `^8.3.5`.
- npm `@vitest/mocker` (via vitest 5.0.2): 2 alerts fixed in 5.0.3. Target vitest `^5.0.3` (or newer 5.x) in both package.json files so the mocker resolves >= 5.0.3.
- npm `source-map-js` 1.2.1 (via postcss, @tailwindcss/node, css-tree): fixed 1.2.2.
- npm `postcss-selector-parser` 6.0.10 (via @tailwindcss/typography): fixed 6.1.5.
- npm `deepmerge` 4.3.1 (via @sveltejs/vite-plugin-svelte): low, no patched version exists -> leave it, mention it in the report.
Do not take the unrelated grouped Dependabot bumps (PRs 95/96, GitHub Actions bumps); security only.

Constraints:
- The workspace has vendored tauri/wry patches ([patch.crates-io] in Cargo.toml, vendor/wry). Cargo.lock must keep them: no `[[patch.unused]]` and the `wry` package entry without a crates.io `source` (guard test tests/integration/ci_workflow.rs `cargo_lock_keeps_the_vendored_patches`). Use targeted `cargo update -p <crate>` only, never a blanket `cargo update`.
- npm: use targeted updates (`npm install vite@^8.3.5 vitest@^5.0.3 -w frontend -w mnemo2 --save-dev`, `npm update source-map-js postcss-selector-parser`, or an `overrides` entry in the root package.json if a transitive pin blocks it). Never a blanket `npm update`.
- Version 2.0.0 everywhere the app version is asserted: Cargo.toml, src-tauri/Cargo.toml, src-tauri/tauri.conf.json, package.json, frontend/package.json, the About fallback in frontend/src/components/about/AboutDialog.tsx (`useState<string>("1.3.0")`), plus Mnemo2's own mnemo2/package.json, src-tauri/mnemo2-app/tauri.conf.json and mnemo2/plugin/.claude-plugin/plugin.json (now 0.1.0). Lock files follow (`cargo update -w` style workspace-only refresh, or let `cargo check` rewrite the mnemo/mnemo-app entries; `npm install --package-lock-only`). Leave the historical `v1.3.0` mentions in src/shell_path.rs comments and the preview fixture text alone.

Verification (each step runs the ones for its files and reports counts):
- Rust: `cargo test --lib` (root crate), `cargo test --test ci_workflow` if it exists (else `cargo test --tests ci_workflow`), `cargo test -p mnemo-app --features mnemo2 --lib`, `cargo clippy --all-targets -- -D warnings`, `cargo clippy -p mnemo-app --all-targets --features mnemo2 -- -D warnings` and without the feature; `cargo tree -i zip` shows 9.x only; `cargo tree -i rustls` shows >= 0.23.46.
- npm: `npm test --workspace mnemo2`, `npm test --workspace frontend`, `npx svelte-check --tsconfig ./tsconfig.json` in mnemo2/, `npm run build --workspace frontend`, `npm run build --workspace mnemo2`; `npm ls vite @vitest/mocker source-map-js postcss-selector-parser` shows only fixed versions.

## Acceptance scenarios
- cargo tree -i zip lists only zip 9.0.5 or newer and cargo tree -i rustls only 0.23.46 or newer; Cargo.lock still has no [[patch.unused]]
- npm ls shows vite >= 8.3.5, @vitest/mocker >= 5.0.3, source-map-js >= 1.2.2, postcss-selector-parser >= 6.1.5
- Every Mnemo and Mnemo2 manifest and the About dialog fallback say 2.0.0
- Root, mnemo-app (with and without mnemo2) and both frontends test, lint and build green
