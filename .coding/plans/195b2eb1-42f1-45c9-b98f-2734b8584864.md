# Plan: Trace stats: legend chips as per-chart series toggles

## Goal
Make every legend chip in the Trace tab's two stacked charts a click-toggle that shows/hides that series (per chart, persisted across sessions), with column maxima recomputed over visible series only so hidden segments yield higher resolution for the rest.

## Kind
implementation

## Context
User request: the Trace-tab stacked charts' legends (frontend/src/components/views/TraceStats.tsx) should become toggles — clicking a legend chip hides that series so the remaining segments get more resolution (especially in Relative scale mode, where the max recomputes over visible series only). Findings: Legend (TraceStats.tsx:43) renders {label, cls} chips; PhaseChart stacks from PHASE_SEGMENTS (traceStats.ts:225, 7 segments: prep/compact/send/wait/reason/generate/tools) via an inline msByKey map that duplicates phaseTipRows' internal map (review finding 2026-08-22 #4: should share one exported extractor); TokenChart hardcodes 4 legend entries (prompt sky / cached emerald overlay / completion violet / reasoning purple) where `cached` is a dithered OVERLAY inside the prompt segment (hiding it removes only the hatch, prompt stays); scale via columnHeightPct(total, max, mode); Fill/Relative toggle persists to localStorage 'tracestats.scaleMode'. Tests are node-env pure-function only (vitest.config.ts include list already has src/lib/traceStats.test.ts and src/components/views/TraceStats.tooltip.test.ts); no DOM tests possible. No README/PLAN.md references to these charts — doc sync = module doc comments only. Frontend-only change: no Rust files touched.
