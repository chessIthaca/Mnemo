# Plan: Fix B4: stale-while-revalidate model picker refresh

## Goal
Eliminate the model-picker refresh flicker (B4) via stale-while-revalidate: keep the previous model list visible during a refetch instead of clearing it, so the dropdown doesn't flash to "Fetching models…".

## Context
B4 from .coding/reviews/2026-04-04-endpoints-model-picker-review.md: clicking Refresh in the model picker clears modelsCache/modelsCacheKey BEFORE the forced refetch, so the dropdown empties and shows "Fetching models…" until the new list arrives — a visible flicker. The clears are unnecessary because fetchServerModels(force=true) already bypasses the cache guard. Fix is stale-while-revalidate: keep the old list rendered during loading (the spinning RefreshCw icon already signals activity), only show "Fetching models…" when there is no prior list. Three files: ModelPickerDropdown.tsx (rendering), EndpointCard.tsx (two onRefresh handlers at ~478 and ~544), VisionSection.tsx (onRefresh at ~280). No component-test infra (no @testing-library); frontend verified via npm run build (tsc) + vitest, backend via cargo test.
