# Plan: Memory system: learn from the plan/review corpus + convergent distillation

## Goal
Make the memory system actually learn from the plans and reviews we write: feed the plan/review corpus into distillation, merge instead of duplicate so recurring knowledge compounds, fix recall quality (embedder default) and diagnosability (consolidation logging).

## Kind
implementation

## Context
Verified defects: (a) consolidation only sees current-session tool events (tool_output truncated at 200 chars, consolidation.rs:150); plans/reviews corpus on disk never read; (b) store.write (memory/mod.rs:623) is blind INSERT OR REPLACE with fresh UUIDs — no dedup, and ProceduralData.frequency never increments, so recurring workflows/problems never gain strength; (c) write_review_report not in is_durable_tool (turn.rs:1368); (d) M1: default embedder is Hash (bundled_embedding_model: Option<String>, config/general.rs:73, default None) so paraphrase recall silently misses; (e) M3: spawn_consolidation (agent.rs:444-456) discards errors silently. Existing machinery to reuse: reembed_all + fingerprint check at main.rs:661, rewire.rs set_embedder path, is_model_installed/embedder_cache_dir in ipc/embeddings.rs, MockLlm::sequence in consolidation tests, download_bundled_model IPC. Commit on a new branch off current HEAD (feat/backlog-draft-llm-error-context is unmerged).
