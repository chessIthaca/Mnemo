# Plan: Trace tab: vertical charts on top, resizable split, provider in rows

## Goal
Rework the Trace tab (frontend/src/components/views/LlmTraceView.tsx + TraceStats.tsx): move the stats/graphs section to the top with a draggable resize splitter between graphs and the request log; convert all three charts (phase time, tokens, cache hit) from horizontal rows to vertical column charts with newest values rightmost; add a Fill/Relative scale toggle (default Relative — a 2-min request's column is 4× taller than a 30s one); and show the provider (endpoint name) next to the model in the trace log rows, which requires threading the endpoint name through the Rust trace record.

implementation
