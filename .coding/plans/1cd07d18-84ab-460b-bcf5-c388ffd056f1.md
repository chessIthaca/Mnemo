# Plan: Fix ollama/qwen "system message must be at the beginning"

## Goal
Make local (Ollama/vLLM/LM Studio — ProviderKind::Local) endpoints work with the agent loop by not appending the volatile tail + CONTEXT_FOOTER as trailing system messages after the user message. For OpenAI-kind providers, keep the trailing placement (preserves the R5 prompt-cache prefix reuse). For Local-kind providers, fold the volatile tail into the leading system message (messages[0], where Ollama requires it) and drop the footer. This removes the 9× HTTP 500 failures against qwen3.8:27b @ localhost:11434 recorded in .coding/logs/provider-errors.jsonl.

## Context
Root cause: turn.rs appends the volatile tail (workflow state + memories) and the byte-stable CONTEXT_FOOTER as trailing Role::System messages after the conversation history (turn.rs:430-443). DeepSeek tolerates non-leading system messages; Ollama rejects them with HTTP 500 "system message must be at the beginning". Key facts (verified): the assembly happens in AgentLoop::run_turn in src/agent/turn.rs; `provider.kind()` (ProviderKind::OpenAI/Local, src/provider/mod.rs:81) is available in scope; the tail is built via prompt::build_volatile_tail and the head via prompt::build_stable_head (head includes preamble + constitution + session primer). The two messages are transient — pushed before complete_with_retry and popped immediately after (before the `?`), so the pops must mirror the pushes conditionally. Test harness: CapturingProvider in src/agent/tests.rs (:1025-1080 + new_with_tails :1201) records the captured system prompt and, via new_with_tails, the last message content of every complete() call. Existing test volatile_tail_then_stable_footer_appended_and_popped (:1183) asserts the OpenAI trailing placement and must stay green. Local kind: capabilities local() (provider/mod.rs:60) has no cache-reuse benefit, so folding into the head costs nothing and the footer is unnecessary. The CapturingProvider's kind() must be settable (currently returns OpenAI — check its impl) to drive the Local branch in a test.
