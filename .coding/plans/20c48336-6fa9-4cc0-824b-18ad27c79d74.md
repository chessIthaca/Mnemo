# Plan: Configurable code block colors + code preview

## Goal
Make code block (syntax highlighting) text colors configurable in the Settings dialog alongside the existing colors, and add a small syntax-highlighted code block to the live preview.

## Context
The code block text colors are the .hljs-* rules in frontend/src/styles/globals.css (lines 106-117), applied by rehype-highlight in Message.tsx/MdViewer.tsx. They are hardcoded hexes (github-dark subset), unlike the 4 configurable colors (accent/border/text-primary/text-muted) which flow through CSS variables set by applyColors() in useAgentStore.ts and are edited via ColorRow pickers in ConfigDialog.tsx. The ConfigDialog preview currently shows only a sentence, no code block.

Design: map the ~10 .hljs token rules onto 7 curated CSS variables (--code-text, --code-comment, --code-keyword, --code-string, --code-number, --code-title, --code-variable), defaulting to the current hexes. .hljs-meta reuses comment; .hljs-attribute reuses number. .hljs-deletion/.hljs-addition keep their hardcoded diff colors (diff semantics, not code text). Light theme is unchanged (existing behavior: hljs colors are theme-independent). Store gets 7 new fields + an applyCodeColors() helper + setters + reset support; App.tsx applies them on mount; ConfigDialog gets a "Code" subsection and a highlighted code block in the preview. Modal needs max-h/overflow since it grows taller.

## Steps
- [x] 1. In frontend/src/styles/globals.css: define --code-text/--code-comment/--code-keyword/--code-string/--code-number/--code-title/--code-variable defaults in :root and replace the hardcoded hexes in the .hljs-* rules with var() references; give .hljs a base color: var(--code-text).
- [x] 2. In frontend/src/hooks/useAgentStore.ts: add 7 code color state fields with localStorage keys + defaults, an applyCodeColors() helper that writes the --code-* variables, individual setters, and extend resetColors to restore them.
- [x] 3. In frontend/src/App.tsx: restore/apply the code colors on mount alongside the existing applyColors call.
- [x] 4. In frontend/src/components/layout/ConfigDialog.tsx: add a 'Code' subsection under Colors with 7 ColorRows, add a small syntax-highlighted code block (using hljs classes) to the live preview, and make the modal scrollable (max-h + overflow) since it grows taller.
- [x] 5. Verify: run the frontend typecheck/build (npm run build) and cargo test; confirm no regressions.
