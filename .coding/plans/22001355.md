# Plan: web_fetch URL chip clickable — open the fetched page in the system browser

## Goal
The URL a web_fetch ToolCard already shows in its header (webFetchLabel, backlog 69cf7e9c) becomes a clickable link that opens the FULL fetched URL in the user's default browser via the Tauri shell plugin (the AboutDialog openExternal pattern — production CSP blocks plain anchor navigation), so the user can look at the page the agent fetched. Only http(s) URLs are openable; the click opens the full URL even though the chip text is truncated to 60 chars. Frontend-only: no Rust changes, no capability changes (shell:allow-open already granted).
