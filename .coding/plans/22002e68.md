# Plan: Release build: declare the Tauri CLI that build.yml runs

## Goal
`npx tauri build` works again in .github/workflows/build.yml: @tauri-apps/cli is declared as a devDependency of the mnemo2 workspace and locked in package-lock.json, and a regression test fails whenever build.yml calls `npx tauri` without that declaration.

## Kind
bug_fixing

## Context
WHY: Retiring Mnemo1 (commit 674702df, PR #120) deleted frontend/, and frontend/package.json was the only package that declared `"@tauri-apps/cli": "^2.12.4"` (devDependencies). npm workspaces hoisted it to the root node_modules/.bin, which is how `npx tauri build` (run with working-directory src-tauri/mnemo2-app in build.yml, windows job line ~79 and macos job line ~218) found it. After #120 no package.json declares it and package-lock.json has no `node_modules/@tauri-apps/cli` entry, so `npm ci` installs no `tauri` bin and npx gives up. PR CI (ci.yml) and the local `npm run rebuild:mnemo2` never call the Tauri CLI (they use `cargo build -p mnemo2-app --features custom-protocol`), so nothing caught it before the tag.

DECISIONS (already taken, do not revisit):
- Declare it in mnemo2/package.json devDependencies (the Mnemo2 app's package, which already holds `@tauri-apps/api` ^2.12.4), NOT in the root package.json. Version range `^2.12.4`: v2.2.0 shipped with it, npm latest is 2.12.4, and it matches the tauri crate 2.12 line and @tauri-apps/api 2.12.
- Do not change .github/workflows/build.yml, ci.yml, the root package.json, any Cargo file, or vendor/.
- The guard is a Rust integration test in tests/integration/ci_workflow.rs, next to the other build.yml hygiene tests (it already parses files via std::fs; serde_json is a normal dependency of the root crate and usable from the integration tests, see tests/integration/contract_fixtures.rs).

REGRESSION TEST: `build_workflow_tauri_cli_is_declared_and_locked` in tests/integration/ci_workflow.rs. Without the fix (current main) it fails because neither package.json nor any workspace package.json declares @tauri-apps/cli and package-lock.json has no `node_modules/@tauri-apps/cli` entry.

VERIFY:
- `cargo test --test integration ci_workflow` (all ci_workflow tests pass, including the new one)
- `npm ci` at the repo root exits 0
- `cd src-tauri/mnemo2-app && npx --no-install tauri --version` prints `tauri-cli 2.12.4`
- `cargo clippy --workspace --all-targets -- -D warnings` exits 0

## Acceptance scenarios
- `cargo test --test integration build_workflow_tauri_cli_is_declared_and_locked` fails on the pre-fix tree (no package declares @tauri-apps/cli) and passes after the fix.
- After `npm ci` at the repo root, running `npx --no-install tauri --version` from src-tauri/mnemo2-app prints `tauri-cli 2.12.4`.
- The package-lock.json diff only adds @tauri-apps/cli and @tauri-apps/cli-* entries plus the mnemo2 devDependency line; no other package's resolved version changes.
