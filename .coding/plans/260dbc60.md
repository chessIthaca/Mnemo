# Plan: README Quickstart: how to lead with Claude Code

## Goal
The README's Quickstart tells a reader how to use Claude Code as Mnemo2's lead (build, register the project, install the plugin, start Claude Code) and says plainly that this needs a source build for now.

## Kind
implementation

## Context
WHY: the user asked (2026-11-14) that at least the Quickstart mention how to use Mnemo with Claude. Today the README only links to mnemo2/plugin/README.md (intro line 16, the sentence at the end of Build from source, and the docs list). The release installers do NOT contain the plugin's `mnemo2-mcp` helper: src-tauri/mnemo2-app/tauri.conf.json bundles only a Laya data file as a resource, `.github/workflows/build.yml` never builds or copies the helper, and the plugin's `bin/` is not checked in. So the Claude Code lead works only after cloning and building (`npm run rebuild:mnemo2`, which runs `build:mnemo2:native`; scripts/install-mnemo2-mcp.mjs copies the helper into `mnemo2/plugin/bin/` and `~/.mnemo/bin/`). The README must say this, not imply the installer path works.

FACTS from mnemo2/plugin/README.md (verified 2026-11-14): Claude Code (the CLI or the Claude Desktop Code tab) leads in place of the built-in lead chat and plans, dispatches, reviews and merges through Mnemo2's team tools; workers still run on your own endpoints and tiers; only the lead uses your Claude subscription. Requirements: Mnemo2 built from the repo; the project registered in Mnemo2 (open it there once). Install: the repository root is the marketplace (`.claude-plugin/marketplace.json`). Claude Desktop: Code tab, + then Add plugins, add a marketplace from the local repository path, install `mnemo`. CLI: `claude plugin marketplace add <path to this repository>` then `claude plugin install mnemo@mnemo`; build first, install second. Use: start Claude Code in the project folder (or any folder inside it); the helper starts a hidden Mnemo2 in the tray if none serves the project; mission control shows "Lead: Claude Code (external)". On first use Claude offers to allow the Mnemo tools so the lead does not stall on permission prompts.

A follow-up (bundling the helper in the installers) is out of scope here.

VERIFY: `git diff --check` clean; every relative link resolves; README.md is the only changed file.
