# Plan: Fix the macOS build behind a manual-dispatch gate

## Goal
Fix the macOS CI leg so it can be diagnosed and repaired — WITHOUT letting it run on ordinary submits. Replace the blanket `if: false` in .github/workflows/build.yml with a manual-dispatch-only gate (the job is skipped on every tag push and every ordinary dispatch, and runs only when a `run_macos` input is explicitly set), add a diagnostic capture step so the next run yields the real failure (the API log endpoint is admin-only, so the workflow itself must surface it), then run that diagnostic dispatch once, root-cause the failure, fix it, and only then restore macOS to the normal tag-push path.

Landed design — the macOS CI failure was a REAL BUG, not a flake or platform issue, and it is now FIXED + VERIFIED.

Root cause: `is_adoptable_path` (src-tauri/src/main.rs:118, `#[cfg(unix)]`) checked only `!value.is_empty()`, so a whitespace-only captured login-shell PATH value (`"   "`) was adopted. The guarding test `adoptable_path_rejects_empty_and_control_characters` (src-tauri/src/main.rs:1878) lives in a `#[cfg(all(test, unix))]` module — it NEVER COMPILES ON WINDOWS, which is precisely why the defect was invisible on the dev box and only the macOS leg caught it. This was the distinct sixth failure; the earlier five fixes (plan 5cff52cf) were correct.

Fix: `!value.trim().is_empty() && !value.chars().any(|c| c.is_control())` — rejects whitespace-only while KEEPING real paths with internal spaces adoptable (`/Applications/Some App/bin`, the review-F5 case guarded by `adoptable_path_allows_spaces`). Added `adoptable_path_keeps_internal_spaces` plus tab/newline reject cases to the existing test.

Evidence method that worked (the job-logs API is 403/admin-only — the original blocker): the workflow's own diagnostic capture — `cargo test --workspace --no-fail-fast 2>&1 | tee macos-test-output.txt` + `actions/upload-artifact@v4` (if: always()) — read back with `gh run download <run-id> --name macos-test-output`. This step STAYS in the macOS job as the evidence path for any future macOS-only failure. The macOS job is restored to the normal path: gate removed, `needs: [windows, macos]`, macos artifact download + `dist/macos` globs back, `run_macos` dispatch input dropped, scratch artifacts removed.
