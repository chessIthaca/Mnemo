# Plan: Startup project picker + project switching

## Goal
Add a startup project-picker dialog (choose an existing registered project, or create one by picking a directory → scaffold .coding/ + agent.md → register). Skip the dialog when the cwd is already a project. Add a UI control to switch projects at runtime (restarts into the chosen project). The project list already lives in projects.toml alongside keys.toml/endpoints.toml.

## Kind
implementation

## Context
projects.toml + ProjectRegistry already exist in ~/.myharness/ (loaded into Config.projects, serialized in get_settings().projects). Project::init(dir) already scaffolds .coding/ + agent.md. build_brain() in src-tauri/src/main.rs builds the brain once at startup with Arc-shared deps tied to the project root — switching projects restarts the app via tauri::process::restart() + a one-shot marker file (restart reuses argv, so a marker side-channel signals the chosen project). tauri-plugin-dialog is already registered (Cargo + capabilities dialog:default); the folder picker will be a Rust command using DialogExt to avoid adding an npm dep. Startup-error screen pattern (get_startup_error → error UI in App.tsx) is the template for a needs-project state.
