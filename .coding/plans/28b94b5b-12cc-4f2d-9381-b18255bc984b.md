## Context
Investigated all five. Findings: (1) RightPanel.tsx:114-120 mounts the active view by conditional render (`<Body/>`), so switching tabs UNMOUNTS BacklogView and destroys BacklogInput's useState text — root cause confirmed. Mid-stream partial-output errors are swallowed; terminal errors return Err without recording in-context. (3) `create_plan`/`update_plan` `steps` is ALREADY a JSON array of strings (plan.rs:104,194) backed by Vec<String> — no change needed; the user's symptom was likely the model emitting a newline-joined string. (4) Memory chat display ALREADY exists end-to-end behind `show_memory_activity` config (general.rs:226, AppearanceSection checkbox "Show memory activity in chat", agentEventReducer memory-kind rendering) — DEFAULT OFF, which is why it's invisible. So the real work is #1 and #2, plus a focused memory-system review (#5).
