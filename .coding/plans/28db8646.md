# Plan: Repository paths are clickable everywhere Mnemo2 shows Markdown

## Goal
A project file path in a worker brief, plan goal or detail, worker inbox message, lead chat entry or pending prompt (e.g. `.coding/design/unified-tiers.md` or `src/x.rs:42`) is a link that opens the file in the Workbench Files tab at the line, or the plan document for `.coding/plans/<id>.md`, exactly as the Memory view already does.

## Kind
implementation

## Context
The user saw `.coding/design/unified-tiers.md` in a worker brief in mission control and could not click it.

Existing pieces (verified; built by plan 7da65f3c for the Memory tab):
- `mnemo2/src/components/Markdown.svelte` takes `onOpenPath?: (ref: RepoPathRef) => void`; when given, it walks the rendered text nodes and turns repository paths into clickable elements (uses `mnemo2/src/lib/repoPaths.ts` `parseRepoPath`: project-relative paths with a file extension and optional `:line`; URLs and absolute paths stay text).
- `mnemo2/src/components/MemoryView.svelte` (~88) has `openRepoPath(ref)`: a plan ref → `actions.openPlanDocument(ref.planId)`, else `actions.openFileInWorkbench(ref.path, ref.line)`; it is the only caller passing `onOpenPath` (~525).
- Callers that pass only `onOpenLink`: `WorkerDetail.svelte` ~203 (the brief, `worker.task`), `WorkerInbox.svelte` ~45, `PlanTab.svelte` ~143 (goal) and ~175 (detail), `LeadChat.svelte` ~137/165/195, `PendingPrompt.svelte` ~39.

Change:
1. Move `openRepoPath` into one shared place (an exported `openRepoPath` action in `mnemo2/src/lib/store.ts` next to `openFileInWorkbench`) and use it in MemoryView.
2. Pass `onOpenPath={actions.openRepoPath}` (keeping `onOpenLink`) in every caller listed above.
3. Make sure paths inside inline code spans are recognised too, since briefs and plans usually write paths that way. If Markdown.svelte's tree walker skips `<code>` text, include inline code (not fenced code blocks, which stay plain).
4. Do not change `parseRepoPath`'s rules.

Verification (in mnemo2/): `npm run check`, `npx vitest run src/lib src/components`.

## Acceptance scenarios
- In mission control, clicking `.coding/design/unified-tiers.md` in a worker's brief opens that file in the Workbench Files tab.
- Clicking `.coding/plans/87932c46.md` in a plan or chat entry opens the plan document.
- A path inside a fenced code block stays plain text.
