# Plan: Release v2.3.0: version bump and changelog

## Goal
Every version-carrying manifest says 2.3.0, the lockfiles agree, and CHANGELOG.md has a 2.3.0 section, so main can be tagged v2.3.0 and CI builds the Mnemo2 installers and publishes the release.

## Kind
implementation

## Context
WHY: the user asked to cut Mnemo 2.3 (installers + GitHub release). 2.3.0 is the first Mnemo2-only release: Mnemo1 was retired in #120-#123. CI owns the release: pushing an annotated v2.3.0 tag on merged main runs .github/workflows/build.yml, which builds the Windows .msi/.exe and the macOS .dmg/mnemo2.app.zip, drafts the release, uploads, then publishes. The lead does the tag; this plan only prepares the tree.

CONSTRAINTS:
- Change ONLY these files: Cargo.toml, src-tauri/Cargo.toml, src-tauri/mnemo2-app/Cargo.toml, src-tauri/tauri.conf.json, src-tauri/mnemo2-app/tauri.conf.json, package.json, mnemo2/package.json, mnemo2/plugin/.claude-plugin/plugin.json, Cargo.lock, package-lock.json, CHANGELOG.md.
- Every manifest moves together (a half-bumped tree ships installers whose version disagrees with the tag). Precedent: commit 9396126b "release: v2.2.0" changed the same manifests (plus the since-deleted frontend files).
- Lockfiles change ONLY the version fields of the workspace's own packages. v2.2.0's bump changed Cargo.lock in exactly 3 packages (mnemo, mnemo-app, mnemo2-app) and package-lock.json only in the root and mnemo2 workspace version fields. Any other lockfile change (a dependency version, a resolved URL, an integrity hash) is wrong: undo it and report.
- Cargo.lock must keep no [[patch.unused]] entries (the workspace vendors tauri/wry via [patch.crates-io]).
- No other edits: no code, no tests, no workflow files, no .coding records.

VERIFY (all must pass):
- `git grep -n "2\.2\.0" -- Cargo.toml src-tauri/Cargo.toml src-tauri/mnemo2-app/Cargo.toml src-tauri/tauri.conf.json src-tauri/mnemo2-app/tauri.conf.json package.json mnemo2/package.json mnemo2/plugin/.claude-plugin/plugin.json` prints nothing (exit 1).
- `git diff --stat main` lists only the eleven files above.
- `cargo check -p mnemo2-app` exits 0.
- `cargo test --test integration cargo_lock_keeps` exits 0.
- `npm run build:mnemo2` exits 0.
