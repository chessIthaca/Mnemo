# Plan: Fix slash-command mid-run asymmetry — commands execute in every agent state

## Goal
Mid-run (agent running), Enter/Send on a slash command must execute the command — never send it to the model as a steer suggestion — regardless of slash-menu state. Today the menu-open path runs argument-less commands directly (completeSlashCommand → handleSlashCommand, bypassing steer by design) while every menu-closed path (Esc-dismissed Enter, Send button) routes through handleSend's steerMode branch and steers the command text instead.
