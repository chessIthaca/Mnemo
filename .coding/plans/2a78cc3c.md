# Plan: search: reliable .coding/ file location — sticky delegation bypass, empty-index walk fallback, read_files directory listing

## Goal
Make locating files under .coding/ (reviews/knowledge) reliable: (a) the auto-delegation escape becomes sticky per exact query — a bounded set of bypassed keys in SearchTool, so interleaved delegating queries never break an earlier escape and an identical re-issue never re-delegates in-session; (b) an empty FTS fetch is no longer treated as authoritative — it falls through to the walk (the documented authoritative engine), fixing the stale-index false negative for newly written .coding/ files (and any new file during the watcher's lag window); (c) read_files accepts a directory path and returns a sorted listing (name/type/size/mtime), so "what files are in this dir" no longer requires search gymnastics — plus a pin that the 100-match cap never permanently hides tail files (a narrower re-issue returns them).
