Live data point: in THIS session a 5-call emission block was rejected wholesale as "arguments JSON malformed or truncated" including two phantom backlog_status fragments never intended — harness validation caught what the incident session's harness let leak. User steer: root cause only — no fix implementation, no regression tests.
