# Plan: Add-agent button with read-only review option

## Goal
Let the user spawn a new agent from the Mnemo1 agent tab bar, optionally as a read-only review agent that gets exactly the strict reviewer tool surface.

## Kind
implementation

## Context
Why: old plan 9275932b (replaced by the completed plan 4340d6d5) planned a "Read-only review agent" option for agents created from the UI. That option was never built, and there is no add-agent button: frontend/src/lib/tauri.ts::spawnAgent(name) exists but nothing calls it. The user chose to build both.

Security finding (verified): src/host/runtime.rs::compute_subagent_allowlist starts with `let parent_id = parent_id?;`. A parentless spawn therefore returns None, which means NO allow-list (unrestricted). The UI command src-tauri/src/ipc/spawn.rs::spawn_agent always spawns parentless (parent None, role None). Passing role "reviewer" from the UI without a backend change would therefore create a fully privileged agent labelled reviewer. That must never happen.

Decisions:
- A parentless reviewer gets exactly REVIEWER_BASE_TOOLS (src/host/runtime.rs). There is no parent to intersect with, so the full strict list is used, applied through the existing set_role_allowlist(true, list) / ToolFilter::Reviewer path. A parentless agent with no role keeps today's behaviour (None, unrestricted). Unknown roles stay fail-closed.
- IPC: `spawn_agent(name: String, review_only: Option<bool>)`. When true, set SessionOptions.role to Some("reviewer"); everything else stays as today (own_plans_dir true, no worktree, no host tools). The frontend passes `{ name, reviewOnly }` (Tauri camelCase mapping). Legacy callers that omit it get an unrestricted agent, exactly as before.
- UI: a "+" button at the end of the TabsList in frontend/src/components/layout/MainPanel.tsx opens a small inline form: a name input (default "agent"), a "Read-only review agent" checkbox (default off), Create and Cancel. On success, activate the new agent's tab. On error, show the message inline and keep the form open. Follow how useAgentEvents registers runtime-spawned agents; do not invent a parallel registry.
- Docs: one line in docs/FEATURES.md (and the reviewer section of agent.md if it lists spawn entry points) saying review agents can also be created from the UI.

Verification: `cargo test --workspace` unpiped (deny(warnings) means a green run is warning-free); frontend `npm test` and `npm run build` in frontend/.

\## Acceptance scenarios
- A parentless spawn with role "reviewer" (the review_only path) yields an allow-list equal to REVIEWER_BASE_TOOLS. It must not include file_write, file_edit, shell, git, spawn_agent, memory_write, backlog_add, ask_user, create_plan, or finish. This is asserted by a Rust test that fails on the current `parent_id?` early return.
- A parentless spawn with no role is still unrestricted (None), so existing UI and worktree agents are unchanged.
- The `spawn_agent` IPC with review_only true creates an agent whose workflow filter is ToolFilter::Reviewer.
- In the UI, the "+" button opens the form. Checking "Read-only review agent" and pressing Create calls invoke("spawn_agent", { name, reviewOnly: true }). Unchecked sends reviewOnly false. A vitest test asserts both payloads and that the new tab becomes active.

## Steps
- [ ] 1. **Backend: parentless reviewer gets the strict surface + review_only IPC flag** — src/host/runtime.rs (compute_subagent_allowlist: parentless + role reviewer => Some(REVIEWER_BASE_TOOLS); parentless + no role => None unchanged), src-tauri/src/ipc/spawn.rs (spawn_agent gains review_only: Option<bool> -> SessionOptions.role Some("reviewer")), tests in those files, docs/FEATURES.md line.
- [ ] 2. **Frontend: add-agent button with Read-only review checkbox** — frontend/src/lib/tauri.ts (spawnAgent(name, reviewOnly)), frontend/src/components/layout/MainPanel.tsx (+ button, inline form, activate new tab), new vitest test next to it.
- [ ] 3. **Integration check** — run the combined result (build, tests, or launching the entry point) and verify the parallel steps fit together; fix any seam breakage.
