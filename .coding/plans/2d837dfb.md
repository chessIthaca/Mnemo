# Plan: Memory defaults: 20-day decay half-life, derived per-class cap 10

## Goal
The compiled-in `[memory]` defaults become `decay_half_life_days = 20.0` and `derived_per_class_cap = 10` (were 7.0 and 5). Configs that set the keys explicitly are unaffected.

## Kind
implementation

## Context
WHY: the user has run with decay_half_life_days = 20.0 and derived_per_class_cap = 10 in ~/.mnemo/config.toml and wants those as the defaults (decided 2026-11-11 while settling the Mnemo1-only settings). Both apps share the engine, so the default lives in one place: `MemorySearchConfig::default()` in src/memory/types.rs (~line 534). `clamped()` (~567) also hard-codes 7.0 as the fallback for a non-finite half-life.

DECISIONS:
- Introduce `pub const DEFAULT_DECAY_HALF_LIFE_DAYS: f64 = 20.0;` and `pub const DEFAULT_DERIVED_PER_CLASS_CAP: usize = 10;`. Use them in `default()` and in the `clamped()` fallback, so the default and the fallback can't drift.
- src/memory/strength.rs keeps its historical 7-day `decay` constant. It is the explicit-tau form for callers that carry no config. Do NOT change it.
- No UI work. Mnemo1's Settings → Memory shows the live values, and Mnemo2 does not expose these keys.

TESTS THAT ENCODE THE OLD DEFAULT, which must keep their intent:
- src/config/general.rs ~1501/1503 assert the defaults: change them to 20.0 and 10.
- src/memory/tests.rs ~965: the second half of the tau test uses `MemorySearchConfig::default()` as "the default 7-day tau". Change that to an explicit `MemorySearchConfig { decay_half_life_days: 7.0, ..MemorySearchConfig::default() }` and reword the comment, so the test still proves a short tau sinks the aged record.
- Any other test that relied on 7.0 or 5 through `default()`: pin the explicit old value in that test rather than changing its assertions.

VERIFY:
- `cargo test --lib memory`
- `cargo test --lib config`
- `cargo test --workspace --no-fail-fast`
- `cargo +1.99.1 clippy --workspace --all-targets`
- `cargo +1.99.1 clippy -p mnemo-app --all-targets --features mnemo2`
Rust 1.99.1 is installed next to the default toolchain. Run it as `cargo +1.99.1`.

## Acceptance scenarios
- `toml::from_str::<GeneralConfig>("")` yields memory.decay_half_life_days == 20.0 and memory.derived_per_class_cap == 10
- `MemorySearchConfig { decay_half_life_days: f64::NAN, ..Default::default() }.clamped().decay_half_life_days == 20.0`
- A config.toml with explicit `decay_half_life_days = 14.0` / `derived_per_class_cap = 3` still loads 14.0 / 3
- `cargo test --workspace --no-fail-fast` and both `cargo +1.99.1 clippy` runs exit 0
