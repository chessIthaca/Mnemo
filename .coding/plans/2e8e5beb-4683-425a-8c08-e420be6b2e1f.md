# Plan: Split the "sending" black box: prep/compact checkpoints, retry visibility, trace + graph

## Goal
Split the inflight bar's "sending" black box into observable sub-phases so API slowness is attributable: time local prep (token counting/recall/prompt build), expose auto-compaction as its own live phase + trace checkpoint, and make retry attempts visible live. Surface the new prep_ms/compact_ms buckets in the Trace page phase line and the TraceStats stacked-bar graph.

## Kind
implementation

## Context
User reports the API send/process path still feels slow and asked what flips the inflight bar from "sending" to "waiting". Answer (verified in code): the Waiting phase fires at turn.rs:706-713 right after `stream_result?` (turn.rs:703) — i.e. once provider.complete() returns the stream, meaning the POST's response headers (200) arrived; "waiting" is pure TTFT. The "sending" bucket is a black box containing: model resolution, BPE token accounting, auto-recall embedding search, prompt build, a full hidden auto-compaction LLM call (turn.rs:218, summarize_with_interrupt), and complete_with_retry's up-to-3 POST attempts with 1s/2s backoff sleeps (src/agent/dispatch.rs:486-514) with no per-attempt event. Trace (src/provider/trace.rs) currently has only send_ms/ttft_ms/generation_ms/tools_ms. Existing attribution mechanism to mirror: set_tools_ms (trace.rs:447) called by providers via last_record_id Mutex (openai.rs:544-554,603-605; anthropic.rs:695-705,747-749). NOTE: prep/compact timings must be stored as PENDING values on the provider and stamped onto the NEXT created record, because the target record does not exist yet when prep/compaction run (last_record_id still points at the previous request). Frontend: TurnPhaseKind union at frontend/src/lib/types.ts:64; phaseLabel at InflightBar.tsx:30-49; PhaseTimes/UsageCard at LlmTraceView.tsx:46-75,171-220; stacked bars at TraceStats.tsx:60. Phase serde test at channels.rs:1057-1063; phase-sequence tests at src/agent/tests.rs:721-791; contract fixture at tests/contract_fixtures.rs:249 and src-tauri/src/ipc/events.rs:984.
