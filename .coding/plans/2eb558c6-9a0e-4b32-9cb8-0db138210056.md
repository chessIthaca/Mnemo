# Plan: System prompts from ~/.mnemo/prompts.toml

## Goal
Load the five compiled system-prompt blocks (preamble, workflow lifecycle, app rules, tool strategy, memory records) from a single user-editable ~/.mnemo/prompts.toml, seeded on first run from source-side defaults, with per-section fallback to the compiled consts and mtime-based hot reload (edits apply next turn, no restart).

## Kind
implementation

## Context
User wants ALL system prompts loaded from a user-editable config file in the home dir, seeded by the "installer" (first run) from a source-side version. Chosen format (user pick): single ~/.mnemo/prompts.toml with one [section] per prompt block. Existing machinery to mirror: mtime-guarded ConstitutionSource + ConstitutionHolder (src/project/agent_md.rs:31-105, src/agent/loop_impl.rs:209-234), DEFAULT_PROJECT_TEMPLATE first-run bootstrap (src/project/agent_md.rs:127, written by Project::init), write_atomic (src/config/mod.rs:357). The five blocks are consts in src/agent/prompt.rs (lines 23, 54, 93, 149, 186) assembled by build_stable_head (line 236, called from turn.rs:514). CONTEXT_FOOTER stays compiled (byte-stable sentinel, tests enforce ≤60 chars, no volatile markers). The volatile tail (workflow state + recalled memories) stays dynamic by design.
