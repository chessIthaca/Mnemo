# Plan: Remove Laya multilingual + external-endpoint support (managed-only, English-only)

## Goal
Remove Laya's two optional capability surfaces so the only configuration left is "off (default)" or "app-managed with the English checkpoint": (1) delete the external-endpoint mode (LayaMode, LayaConfig::endpoint, the config-driven build_classifier, the laya_mode/laya_endpoint patch fields, the Settings mode radios + endpoint input, the external branches in the startup hook and the Settings rewire); (2) delete multilingual support (the multilingual catalog entry and the checkpoint-selection surface: LayaConfig::checkpoint, the laya_checkpoint patch field, laya_setup's checkpoint argument, the checkpoint radio list). Provider endpoints.toml is out of scope. Existing config.toml files carrying the removed keys must keep loading (unknown serde keys are ignored) and lose them on the next save; a regression test pins that. Everything must stay green and warning-free (both crate roots are #![deny(warnings)]), with no leftovers in code, UI strings, fixtures or docs.
