7 TOOLS + our prefixed names (all start image_ per user instruction):
1. image_ui_to_artifact — UI screenshot→code/spec; extra: target(enum code|spec), framework(str)
2. image_extract_text — verbatim OCR; extra: lang_hint(str)
3. image_diagnose_error — error diagnosis; extra: code_context(str)
4. image_understand_diagram — architecture/flow/UML/ER/sequence; no extra
5. image_analyze_chart — charts/dashboards; no extra
6. image_ui_diff — compare two UIs; image_a+image_b (required) + focus(str)
7. image_analysis — generic fallback; no extra
Common params on all: detail_level(enum overview|normal|fine|auto, default auto), question(str), region(str: named like "top-right" or bbox "x,y,w,h" 0-1), thinking(bool, advisory — our vision backend doesn't honor reasoning; accept for spec-fidelity, document as no-op).

ZOOM LOOP DESIGN (the hard part): async fn analyze_with_zoom(vision, data_url, bytes, prompt, detail_level, region, max_rounds=3) -> ZoomResult{markdown, confidence, rounds, regions, warnings}. (1) Decode bytes via image::load_from_memory; on Err → FALLBACK: single pass describe_image_data_url(vision, data_url, prompt), return rounds=0 + warnings=["image decode failed; used single-pass overview"]. (2) Downsample overview (longest edge ≤1568px via DynamicImage::resize(1568,1568,FilterType::Lanczos3) — preserves aspect). (3) If detail_level==overview OR region specified → single pass: if region, crop it from the FULL-RES original (parse named region or bbox), re-encode PNG, send data URL; else send overview. Return rounds=0. (4) Else (normal/fine/auto): send overview + a control prompt asking the model to return JSON {action:"zoom"|"done", region, box:[x,y,w,h], confidence:0-1, answer}. Parse JSON from the describe_image String result (lenient — on parse fail, treat the raw text as the done-answer). If action=done → use answer. If action=zoom → crop box from FULL-RES original, re-encode, send cropped data URL + tool prompt, increment rounds, repeat (model votes again or answers). Early-exit on done or max_rounds. For auto: only continue zooming if confidence<0.7 and rounds<max. Crops ALWAYS from full-res original (never the downsampled overview). Re-encode via DynamicImage::write_to(&mut Cursor, ImageFormat::Png) + base64.

OUTPUT: each tool returns ToolResult::success(markdown_text).with_data(json!({confidence, rounds, regions, warnings})) — the markdown is the primary output (our ToolResult.output is a string); structured metadata goes in ToolResult.data. provider/model fields omitted (we don't expose the vision client's identity here).
