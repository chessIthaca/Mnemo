# Plan: Markdown viewer: hide dot-dirs, show-hidden toggle, configurable skip list, browse button

## Goal
Make the Markdown tab hide md files in dot-directories by default, add a "Show hidden" checkbox to reveal them, make the skip-directory list configurable via Settings, and add a "Browse" button that opens a native file picker (initialized at the project root) to load any .md file from the computer.

## Context
Files of interest:
- src-tauri/src/ipc/files.rs — list_markdown_files + walk_markdown (hardcoded MD_SKIP_DIRS), read_file (sandboxed), list_files.
- src/config/general.rs — GeneralConfig ([general]/[context]/[ui]/[models] sections of config.toml), serde(default), Default impls, load_or_default + save.
- src-tauri/src/ipc/settings.rs — get_settings (GetSettingsResponse ~line 618), save_settings (SettingsSaveDto ~935, apply ~1079), wire structs.
- src-tauri/src/main.rs — invoke_handler registration (~line 235), builder setup.
- src-tauri/Cargo.toml — deps (tauri-plugin-shell present; dialog not yet).
- src-tauri/capabilities/default.json — permissions.
- frontend/src/lib/tauri.ts — listMarkdownFiles (line 518), readFile (505), AppSettings (247), SettingsSavePatch (270).
- frontend/src/components/views/MdViewer.tsx — dropdown + refresh + edit/save toggle.
- frontend/src/components/settings/sections/AdvancedSection.tsx — has a Save button currently bound only to summarize_at_fill_rate.

Design decisions:
- Switch walk_markdown to NAME-based skipping: skip a dir if its name is in the configurable skip_names set, OR (name starts with '.' AND show_hidden is false). This hides all dot-dirs by default and is more intuitive than path-prefix matching.
- skip_dirs lives in a new [markdown] section of config.toml (MarkdownConfig), default [".git","node_modules","target","dist"]. Exposed via get_settings/save_settings and edited in Advanced section.
- Browse uses tauri-plugin-dialog from Rust (DialogExt) so the picked path is read server-side (no arbitrary-read command exposed, no project-root path leaked to JS). Initialized at sandbox.root().
