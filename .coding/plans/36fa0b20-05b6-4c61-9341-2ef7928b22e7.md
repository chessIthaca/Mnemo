# Plan: Phase 5c — IPC contract hardening (Maint H4): golden JSON fixtures + typed settings outputs

## Goal
Hardening the Rust↔TS IPC contract boundary against silent drift (Maint H4) via two deliverables: (1) commit golden JSON fixtures for every SerializableAgentEvent variant + the key IPC DTOs, enforced by a Rust serde-equality test (brain crate for events, app crate for DTOs) that fails on any Rust shape change until the fixture is consciously updated; (2) replace the four hand-built serde_json::Value settings outputs (get_config/get_settings/save_endpoints/save_settings) with typed Serialize response structs whose serde output is byte-identical to today's json! bodies (so no FE change), locking the output shape at compile time. Add a vitest suite that imports every fixture and feeds each event fixture through the real handleAgentEvent reducer + asserts DTO field shapes, so TS-side drift is caught at npm test time. No ts-rs/specta (heavy codegen, out of scope); no FE module consolidation (not in this step's scope). cargo test + npm test + tsc --noEmit must stay green.

## Context
Parent: Architecture review remediation, step 23 (Phase 5c). Finding = Maintainability H4 (manual Rust↔TS contract drift, no single schema source). Recommendation: "ts-rs/specta/JSON Schema OR at least a CI check that golden JSON fixtures round-trip; stop returning untyped Value for stable settings surfaces." Chose golden fixtures (lighter, fits cargo test + vitest + resolveJsonModule=true) over ts-rs (heavy new build dependency, big-bang across ~30 types in brain+app crates — violates the no-drive-by-refactors constitution guard).

Contract surface confirmed:
- Events: SerializableAgentEvent in src/runtime/channels.rs (brain crate), #[serde(tag="kind", rename_all="snake_case")], 19 variants (Started, TextDelta, ReasoningDelta, ToolCallStart, ToolCallArgDelta, ApprovalRequest, ToolResult, Usage, ContextUsage, WorkflowStateChanged, StepCompleted, SuggestionInjected, PromptDispatched, SkillStarted, Finished, Exited, ChildFinished, Error). TS mirror in frontend/src/lib/types.ts.
- DTOs (app crate): AgentInfo + WorkflowStateInfo + ActiveSkillInfo (ipc/agent.rs, Serialize-only output DTOs); BacklogItem + BacklogStatus (ipc/backlog.rs); BacklogChangedPayload + RunAllProgress (ipc/backlog_cmds.rs). PlanFile/PlanStep nested in WorkflowStateInfo (src/workflow/plan_file.rs, brain crate). ToolResult/ApprovalPreview/FinishReason/WorkflowState nested in events (brain crate).
- Untyped Value outputs: get_config (general{default_provider,default_model,safety}, endpoints[], pricing[]), get_settings (config_dir, general{...,vision_model}, context, ui, endpoints[], pricing[], projects[]), save_endpoints ({default_provider,default_model,provider_swapped}), save_settings ({ok,safety,vision_configured}). Input DTOs (EndpointDto, SettingsSaveDto, VisionModelDto, PricingDto) already typed.
- Subtlety to preserve: current json! emits null for None Option fields (no skip_serializing_if) — typed structs must NOT skip None on these surfaces or the FE breaks. Fixtures will lock this.

Fixture location: frontend/src/lib/ipc-fixtures/*.json (TS imports via ./ipc-fixtures/x.json with resolveJsonModule; Rust brain-crate test reads via env!("CARGO_MANIFEST_DIR")/frontend/src/lib/ipc-fixtures/x.json [manifest dir = repo root]; Rust app-crate test reads via src-tauri manifest dir ../frontend/src/lib/ipc-fixtures/x.json). Generate-on-missing test pattern: if fixture absent, write it + panic "newly generated, review & re-run"; if present, assert exact serde equality (the drift detector). Fixtures are frozen committed contract artifacts.

TS-side drift detection: JSON import infers string (not literal unions), so a pure type-level `const x: SerializableAgentEvent = json` check is not viable. Instead a vitest suite feeds each event fixture through the real handleAgentEvent (cast via an `as unknown` narrowing helper) and asserts it dispatches without throwing + produces a sane state slice; DTO fixtures get field-presence/type/discriminant assertions. If Rust changes a shape → Rust fixture test fails → dev updates fixture → vitest re-checks TS expectations → drift caught end-to-end.

Vitest currently 49 tests passing (includes useAgentStore table suite from Phase 5b); tsc --noEmit clean; cargo test 0 failed. On branch feat/bookkeeping-tools-autorun.
