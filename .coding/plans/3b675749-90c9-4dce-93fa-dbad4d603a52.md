# Plan: read_files ToolCard: show file name for the single-file `path` shorthand

## Goal
Make the read_files ToolCard header show the file name (and clickable link) when the agent uses the single-file `path` shorthand — currently both argLabel and argPaths bail out when `files` isn't an array, rendering a bare "read_files" card with no name and no link.

implementation
