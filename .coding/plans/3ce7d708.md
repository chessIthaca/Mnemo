3. src/runtime/agent.rs:1820, drop_non_drop. `drop(compaction);` drops only the `Pin<&mut _>` handle from `tokio::pin!`. The pinned future itself lives on the stack until the enclosing block ends, which is the next line, so the call does nothing. Remove it, and reword the comment above it so it no longer claims the handle is dropped.
4. src/agent/optimizer.rs:752 (test decision_density_is_decisions_per_hundred_messages), needless_update. QualitySignals now has only the one field, so `..Default::default()` has no effect; remove that line.
5. src/memory/tests.rs:3809, useless_vec. `cache_lifetime_from_gaps(&vec![(4000, 0.95); 10])` becomes `cache_lifetime_from_gaps(&[(4000, 0.95); 10])`.
