# Plan: Worker rows keep one status column, aligned on every row

## Goal
In mission control's worker list, the status pill ("Working") and the line under it (the live phase and timer, or cost and elapsed) sit in a fixed-width column that starts at the same x on every row and never changes width with its text.

## Kind
implementation

## Context
WHY: the user (2026-11-01) sent a screenshot of mission control. The "Working" pills and the "Thinking… · 29:23" / "Running shell… · 13:18" lines start at different x positions per row (costView65's column sits further right than graphView69's), because the column's width follows its content. They asked that every row have the same size and layout, with the status and what is going on always the same size.

FINDINGS:
- verified: mnemo2/src/components/WorkerRow.svelte line 44 renders `<span class="worker-meta">` holding the `.status-label` pill (line 45) and either `.worker-live` with ActivityStatus (lines 46-54, size "meta", timer from createdAtMs) or a `<small>` with cost and elapsed (line 56). `.worker-row` is `display: flex; gap: 10px` (line 63); `.worker-meta` has no fixed width, so its width follows the longest of the pill and the line under it.
- verified: `.worker-live { display: block; margin-top: 4px; white-space: nowrap; }` (line 81) and `.worker-meta small` (line 80) never truncate.
- mnemo2/src/components/ActivityStatus.svelte is shared with the lead chat and the worker thread; its label must be allowed to truncate in rows without changing how it looks elsewhere.

DECISIONS:
- `.worker-meta` becomes a fixed-width column (about 150px; pick a value that fits "Running a command… · 29:23" at --text-meta and "In review"), flex: 0 0 <width>, contents left-aligned, so the pill and the line under it start at the same x on every row.
- The pill keeps its natural width; the line under it fills the column. A long phase label truncates with an ellipsis while the timer always stays visible (label min-width 0 with ellipsis, timer flex: none). Cost and elapsed get the same truncation rule.
- ActivityStatus gains an opt-in truncation (for example a `truncate` prop or a class the row passes) so the lead chat and worker thread stay unchanged.
- The breakpoints that hide the line under 1100px and in compact rows stay as they are.

VERIFY (in mnemo2/):
- npm run check
- npx vitest run
- Render http://127.0.0.1:5180/preview.html?scene=mission-control at 1400px wide and confirm the pills and lines start at the same x for every row (measure with getBoundingClientRect in the report).
- Fresh worker worktrees need `npm ci --no-audit --no-fund` at the worktree root first.

## Acceptance scenarios
- In the mission-control preview at 1400px, every row's status pill and the line under it start at the same x position, and the column has the same width on every row.
- A long phase label ends in an ellipsis and the timer is still fully visible; the lead chat's Thinking row looks unchanged.
