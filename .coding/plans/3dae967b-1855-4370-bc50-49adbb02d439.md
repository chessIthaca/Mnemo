# Plan: Auto steer/send switch + steer backlog + landed highlight

## Goal
Make the steer/send distinction automatic (steer while running, send while idle), show a backlog of pending steers above the input box, and highlight in the agent window when a steer lands (is injected into the conversation).

## Context
Currently InputBar.tsx has a MANUAL steerMode toggle (Compass button). The agent's `running` state already drives a Stop button. We want steerMode to be DERIVED from `running` (running → steer, idle → send), removing the manual toggle.

The Rust suggestion flow injects "User suggestion: {s}" as a System message at 4 sites, but there's no event emitted when this happens, so the frontend can't show "steer landed". Also, suggestions buffered during streaming (buffered_suggestions Vec in run_turn) are never drained — a dead-code bug.

Event enums (AgentEvent/SerializableAgentEvent in src/runtime/channels.rs) are non-exhaustively matched in events.rs forwarder and the frontend store switch (both have default arms), so adding a variant is safe.

Key files:
- src/runtime/channels.rs — add SuggestionInjected variant + into_serializable arm
- src/runtime/agent.rs — emit at between-turn injection site
- src/agent/mod.rs — emit at 3 injection sites + drain buffered_suggestions
- frontend/src/lib/types.ts — add suggestion_injected to SerializableAgentEvent
- frontend/src/hooks/useAgentStore.ts — add steers backlog to AgentState, handle suggestion_injected
- frontend/src/components/layout/InputBar.tsx — derive steerMode from running, render backlog, remove manual toggle
- frontend/src/components/chat/Message.tsx — render "steer" transcript kind with highlight
