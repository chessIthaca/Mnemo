# Plan: Fix stuck-open reasoning panel (missing collapse triangle)

## Goal
Fix the reasoning/activity panel in InflightBar so it can always be collapsed when open — show the chevron triangle and enable click-to-toggle whenever the panel is expanded (not only when activity exists) — eliminating the stuck-open state showing a lone em-dash with no collapse control.

## Context
Bug in frontend/src/components/chat/InflightBar.tsx — the reasoning/activity panel can get stuck open showing a lone em-dash with no way to collapse it.

Root cause:
- The collapse chevron (triangle) only renders when `hasActivity` is true (line 171: `{hasActivity && (...)}`).
- The bar's onClick only toggles when `hasActivity` (line 149: `onClick={() => hasActivity && setExpanded(!expanded)}`).
- BUT the panel can be expanded while `hasActivity` is false: the drag handler `startDrag` (line 113-122) calls `setExpanded(true)` unconditionally when `!expanded`. Also `showBar` can be true (so the bar renders) while `hasActivity` is false (e.g. `showTokenUsage` on, or `hasTokens`/`hasContext` true). So the user can drag-open the panel, or it can be left open after activity clears, and then the chevron vanishes and clicking does nothing → stuck open showing the em-dash placeholder at line 315 (`<div className="text-slate-600">—</div>`).

The "weird dash" IS that line-315 placeholder — it shows whenever `expanded && !hasActivity`.

Fix: decouple the chevron + click-to-collapse from `hasActivity`. The chevron should render whenever the panel CAN be toggled — i.e. whenever `expanded` is true (so the user can collapse it), OR when `hasActivity` is true (so the user can expand it). Simplest correct rule: show the chevron + enable the toggle whenever `expanded || hasActivity`. The onClick should always call `setExpanded(!expanded)` (no `hasActivity` guard) so an open panel can always be collapsed. The empty-state dash placeholder stays (it's a reasonable "nothing here yet" indicator) but now the user can collapse past it.

No tests assert on InflightBar rendering (confirmed: no *.test.* matches for InflightBar/stateLabel/headerSuffix). Build via `npm run build` (tsc + vite), test via `npm test --workspace frontend`.
