- [x] 1. **Research: design the improved compaction prompt** — Document the design for a structured compaction prompt. The current prompt (context.rs:88-91) is: 'Summarize the following conversation, preserving key decisions, file paths, and technical details. Be concise but complete.' Research best practices (from training knowledge): (1) structured section-based format (Current Task, Decisions, Files/Identifiers, Errors/Blockers, Open Items) outperforms vague prose; (2) preserve identifiers verbatim (file paths, function names, error strings); (3) compress aggressively (verbose tool outputs → key results, repeated reads → latest, exploratory dead-ends → omit); (4) running-summary update: if messages[1] is already a summary, include it + ask the model to update rather than re-summarize from scratch (less lossy, more efficient); (5) explicit token budget guidance.
