# Plan: Parented subagents: dedicated Subagent workflow state (no derived main-plan state)

## Goal
Replace the implicit main-plan state mirroring for parented subagents with an explicit dedicated WorkflowState::Subagent. The plan stack still loads from the shared dir (read-only mirror: current_plan for reviewers + the UI staircase keep working), but the state never derives Executing/Reviewing. The model resolver deliberately drops the lifecycle-state fallback for subagents ([models.subagent] if set, else the configured default). User decision (backlog c5ded15d), chosen over the round-3 "keep + document" lean.
