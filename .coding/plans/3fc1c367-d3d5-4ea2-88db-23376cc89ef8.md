# Plan: Discover model context/output caps from /models — auto-fill endpoint config, warn on conflict

## Goal
Discover per-model context/output caps from the endpoint's OpenAI-compatible /models response and use them in the endpoint config card: auto-fill empty Max context / Max output fields, warn + one-click Apply when an explicit value conflicts with the discovered one.

## Kind
implementation

## Context
User story: endpoint max_context/max_output_tokens are endpoint-level fields in endpoints.toml (already editable in the Settings→Providers endpoint card — verified, no work needed there). When unset, OpenAI-kind endpoints silently fall back to Capabilities::openai() = 128,000 (src/provider/mod.rs:54), which caused the phantom "128K" after switching to glm-5.3. Chosen design (ask_user): "Auto-fill + warn on conflict" — a discovered context window fills EMPTY fields automatically; if the field is explicitly set AND differs from the discovered value, show a warning + one-click "Apply discovered". Persistence flows only through the normal Save (dirty→save_endpoints→rewire) so the runtime path (capabilities_with_overrides, ContextManager) is unchanged. Precedence: explicit config > discovered-after-apply > kind default. Discovery source: the existing /models probe. Key code: src/provider/openai.rs fetch_models (:174), fetch_models_with_vision (:190, dedupe merge :257-263, construction sites :309/:332, ModelWithVision :152), model_supports_vision helper as the parse-pattern to mirror; IPC src-tauri/src/ipc/models.rs list_models (:34, only frontend caller EndpointCard.tsx :104/:124); frontend/src/lib/tauri.ts listModels wrapper; EndpointCard.tsx max-context/max-output inputs (:386-429, onEndpointChange pattern, "field omitted" hint). Provider key map (lenient, first hit wins): context = context_length (Ollama) / max_context_length (LM Studio) / max_model_len (vLLM) / top_provider.context_length (OpenRouter); output = max_completion_tokens / top_provider.max_completion_tokens. Vanilla OpenAI/z.ai return None → feature is a no-op there (expectation set with user). Reference model for fill/warn = last picker selection, else endpoint.models[0]. Windows/PowerShell; cargo test unpiped + $LASTEXITCODE; zero warnings under deny(warnings) — dead code must be removed, never #[allow]; doc comments on all public items; ModelWithVision literals in openai.rs tests (:1936-2052) need the new fields.
