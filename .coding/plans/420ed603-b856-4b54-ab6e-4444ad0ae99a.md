# Plan: Break memory recall self-reinforcement + expandable auto-recall hits

## Goal
Break the memory self-reinforcement loop (passive surfacing no longer counts as access, so decay works and stale memories sink), and make the auto-recall transcript entry expandable to show all recalled hits end-to-end.
