# Plan: Fix Anthropic dropped-delta + cross-provider raw echo (GLM 400) + 400 retry waste

## Goal
Eliminate the three harness defects that broke the 2027-01 sessions: (A) the Anthropic SSE parser silently dropping event frames at network-chunk boundaries (root cause of "empty {} tool arguments" + dropped text fragments), (B) the OpenAI-compat builder echoing Anthropic-native raw content blocks verbatim after a mid-session provider switch (root cause of the GLM/z.ai 400 code 1214 "content[0].type type error" that bricked the session), and (C) the request-level retry ladder burning 3 attempts on a deterministic HTTP 400. Each fix ships with a red-first regression test; full cargo test green and warning-free at the end.

## Kind
implementation

## Context
Three harness defects behind the 2027-01 session failures (BUG memory 93b01d1b observed the symptoms).

FINDING A — Anthropic dropped deltas (empty/truncated tool args + dropped text). Verified: src/provider/anthropic.rs:1084 `parse_sse_buffer` holds the SSE `event:` name in a fn-local `current_event` reset per call; when a network chunk boundary splits `event: content_block_delta` from its `data:` line, `event_name` arrives as "" (line 1099 `unwrap_or_default`) and the match at line 642 hits no arm — the frame is silently dropped. Dropped `input_json_delta` → truncated args → turn-loop parse failure → handle_bad_json sanitizes to "{}" (turn.rs:4370-4375; anthropic.rs:769-771 also rewrites raw input to {} at message_stop) — the "{}" the model saw was the sanitizer, NOT a model emission. Dropped `text_delta` explains the "dropped text fragments" symptom. Parallel tool calls emit more frames → higher boundary probability → failures clustered on the 2nd call of a batch. Fix: persist the pending event name in StreamState across parse_sse_buffer calls.

FINDING B — GLM/z.ai HTTP 400 code 1214 "messages[8].content[0].type type error", every retry identical. Verified: src/provider/openai/request.rs:559-571 echoes assistant `m.raw` verbatim with NO origin-provider gate; Anthropic-born raw carries content blocks {"type":"thinking"|"tool_use"} (built at anthropic.rs:990-1012 to preserve signatures). Mid-session provider switch → Anthropic block types inside an OpenAI chat-completions body → z.ai rejects. Message.origin_provider/origin_model already exist (set at turn.rs:4390). Fix: echo raw only when origin_provider is absent or matches the target client's kind; otherwise fall through to field-based construction (text as string, tool_calls from structured fields, thinking dropped — a different provider cannot use Claude signatures).

FINDING C — deterministic 400 retried 3× (transcript: "request attempt 1/3... 2/3... 3/3" on an identical payload). Verified: request-level ladder at src/agent/dispatch.rs:1008-1130 retries every provider error; turn-level non-retryable classification exists (runtime/agent.rs:1657 test run_turn_attempt_skips_retry_for_non_retryable_error) but the request level has no 4xx gate. Fix: classify the provider error's HTTP status at the request level — retry only 408/429/5xx/network; other 4xx abort immediately with the provider message.

TEST DESIGN (each test red without its fix, green with it):
A — parser-level test in src/provider/anthropic.rs tests (existing stream-feed patterns at lines 2837, 3143): feed an SSE stream where `event: content_block_delta` for TWO parallel tool_use blocks arrives in one chunk and the `data:` lines in a following chunk; assert every ToolCallArgumentDelta survives and both calls' arguments parse. Red today (frames dropped with empty event name).
B — body-build test in src/provider/openai/tests.rs: assistant Message with Anthropic-shaped raw (thinking block + tool_use blocks, content array) and origin_provider "anthropic", built against an OpenAI-compat client; assert the serialized body contains no "thinking"/"tool_use" content block types and carries tool_calls reconstructed from structured fields. Red today (raw echoed verbatim).
C — dispatch test: request-attempt loop against a provider error carrying HTTP 400; assert exactly one attempt (no backoff ladder). Red today (3 attempts).

Regression-test requirement from the project constitution: every defect gets its red-first test. Commit at each step boundary on wt/* so the review delta stays narrow.
