# Plan: Reviewer tool surface + failed-reviewer protocol + Continue button

## Goal
Harden the reviewer agent into a strict read-only/query surface (no plan tools, no finish, no ask_user, no memory/backlog mutations), add the failed-reviewer protocol (parent never assumes a failed reviewer is done, never blind-respawns — asks the user), add a Continue button for failed agents, and make abandon_plan supersede lingering step-marker memories.

## Kind
implementation

## Context
User-approved change list (2026-09-04 session, supersedes abandoned plan 9275932b) after joint review of the tool×state map:

1. Reviewer leaks confirmed: ToolFilter::Skill arm (src/tool/mod.rs:322) auto-grants ask_user + backlog_status + ALL memory tools (incl. memory_delete) beyond the allow-list; ToolRegistry::schemas (src/tool/mod.rs:379) unconditionally advertises Memory tools. Grok (as reviewer) could genuinely call ask_user; plan-tool calls are dispatch-denied for subagents (plan_mutations_allowed=false, src/agent/dispatch.rs:118) but still callable-visible; `finish` is NOT in that main-agent-only gate — an unrestricted subagent spawned during parent Reviewing inherits it.

Any state mutation NO.
