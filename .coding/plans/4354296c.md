# Plan: Backlog item detail bar + run-all dispatch enrichment

## Goal
Raise the backlog item detail bar so a dispatched (possibly lesser-reasoning) model can succeed without re-deriving context: (a) both write paths (agent backlog_add tool + IPC command) reject terse bodies — the body must carry ≥160 chars AND at least one file-path-like token or an explicit no-code-research marker, with an error naming the full 5-element detail bar (problem+repro, paths+symbols, fix direction, acceptance, pointers); (b) the run-all dispatch prompt auto-attaches a recalled-context block (top-5 semantic memory hits on the item text, best-effort); (c) the Backlog tab composer gains a Template button pre-filling the 5-section skeleton. The 4000-char cap stays.
