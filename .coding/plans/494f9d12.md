# Plan: Fix manual-'c' park sites: Suggestion streak reset + Parked evidence/UI

## Goal
Eliminate the uncovered manual-'c' park sites: (1) the between-turn Suggestion resets the auto-continue budget (external progress — a user steer or a finished descendant's completion notification — not mere guidance), so the closing sequence can never be budget-starved; (2) every park site emits a new AgentEvent::Parked carrying the pre-stall evidence (reason, workflow state, descendants running, streak) — fed to the watchdog activity ring via the existing forwarder, and surfaced in the UI as a distinct banner for the two manual-'c' reasons (Interrupted: "Turn interrupted — send a message to resume"; BudgetExhausted: "Auto-continue budget exhausted — send a message to continue") so an interrupted turn no longer looks like a hang; (3) the Planning-exploration gap and the Interrupt-park semantics are documented (BUG memory + HOW record + queued backlog item). Regression: a Suggestion-driven turn with an exhausted budget auto-resumes (red without the fix).
