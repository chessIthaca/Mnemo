## Bug
On the native Anthropic path, failed tool calls are invisible to the model: every tool_result block is sent with the hardcoded "is_error": false, so Claude treats failures as successes and re-issues the identical tool call over and over (only the "[tool error]" text prefix and the second-failure repeat breaker stand in the way). Additionally, when a stream's message_delta never arrives, stop_reason=None falls back to FinishReason::Stop even though tool_use blocks were emitted — the tool ending is misread as end-of-turn.
