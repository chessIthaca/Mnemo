# Plan: Fix per-turn BPE re-tokenization + Trace-page stats graphs

## Goal
Eliminate the per-iteration full-history BPE re-tokenization in the turn loop (single-pass count+breakdown with exact delta updates), and add a stats-graph section (phase times, tokens, cache hits) in the bottom half of the Trace page.
