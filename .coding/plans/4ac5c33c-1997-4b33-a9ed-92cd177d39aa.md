# Plan: Extend git tool with merge/checkout/stash/branch/push + never_auto_for

## Goal
Extend the git tool with merge/checkout/stash/branch/push subcommands and add a subcommand-aware never_auto_for(&args) trait method so merge/push always force the approval prompt regardless of safety mode.

## Context
The git tool (src/tool/agent/git.rs) currently supports status/diff/log/commit. The Tool trait (src/tool/mod.rs) has never_auto() (no-arg, default false). dispatch.rs (src/agent/dispatch.rs) checks tool.never_auto() to force the approval prompt. The task: add a subcommand-aware never_auto_for(&args) trait method (default false), override it in GitTool for merge/push, extend git.rs with merge/checkout/stash/branch/push subcommands, update dispatch.rs to consult never_auto_for, and add tests. Must NOT touch factory.rs, tests.rs, merge.rs, or src-tauri/. The existing never_auto() stays as-is (MergeToMainTool overrides it to true).

- [x] 2. Update src/agent/dispatch.rs: change `let force_prompt = tool.never_auto();` to also check `tool.never_auto_for(&parsed_call.arguments)` — force prompt if EITHER is true. Update the comment.
