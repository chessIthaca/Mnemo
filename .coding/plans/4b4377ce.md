# Plan: Silence timeout kills a cargo build compiling one large crate

## Goal
A healthy long compile of one large crate is never killed by the silence timeout, while a hung command is still killed in reasonable time.

## Kind
bug_fixing

## Context
WHY: plan 5b85ab61 step 1 replaced the shell's fixed 5-minute wall clock with a silence timeout (DEFAULT_SILENCE = 5 min) plus a 60-minute hard cap (src/tool/agent/shell.rs, DEFAULT_SILENCE/DEFAULT_TOTAL, run_command). The plan assumed cargo prints steadily. It does, between crates, but one crate's rustc run prints nothing until it ends, and the mnemo crate (and Bevy's largest crates on FactoryGame) take longer than 5 minutes cold. Seen live on 2026-11-19: worker sccache01 was killed twice right after "Compiling mnemo v2.6.0".

DECISION: raise DEFAULT_SILENCE to 20 minutes and keep the 60-minute hard cap. A hung command is still killed within 20 minutes, which beats the old polling loops, and a cold single-crate compile fits. No per-command or setting knob (user preference: automate over settings knobs). The silence error text stays, with '5 minutes' replaced wherever the number is shown. The shell tool schema text 'A command is killed after 5 minutes without output or 60 minutes in total.' becomes '20 minutes without output'. docs/FEATURES.md and docs/CONFIGURATION.md, wherever the silence limit is stated, are updated the same way.

REGRESSION TEST: `default_silence_outlasts_a_long_single_crate_compile` in src/tool/agent/shell.rs tests asserts DEFAULT_SILENCE >= 20 minutes, and that ShellTool::new's limits use it. It fails today (5 minutes). The behavioural silence tests keep their short with_limits values.

VERIFY (each alone on its line): `cargo test --workspace`; `cargo clippy --workspace --all-targets`.

## Acceptance scenarios
- A command that prints 'Compiling mnemo' and then nothing for 10 minutes before finishing is not killed.
- A command that prints nothing for 20 minutes is killed with the silence-timeout error naming 20 minutes.

## Bug
A worker's `cargo test --workspace` was killed with "command printed nothing for 300s and was killed (silence timeout)" right after cargo printed "Compiling mnemo v2.6.0". rustc compiles one large crate (mnemo, mnemo-app, Bevy crates) silently for more than 5 minutes, so the default silence limit kills healthy builds.
