# Plan: Cost-saving levers on by default + Dashboard shows savings and % savings

## Goal
Make every cost-saving option on by default and make the Dashboard's recent-events rows report savings instead of raw token in/out. Concretely: (a) `[general.optimizer]`'s six levers (`delta_reads`, `compress_output`, `archive`, `compaction_survival`, `quality_score`, `lean_output_nudge`) default to ON, with `OptimizerConfig::is_default()` tracking the new defaults so an untouched config still writes no section, and all doc/copy/tests that assert off-by-default updated; (b) the Dashboard's recent-events row drops the `tokens_before → tokens_after` arrow and shows the % savings next to the existing metered savings figure (tooltip keeps the before → after detail), with the empty-state and Settings copy updated to the new default.
