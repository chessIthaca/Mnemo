# Plan: CodeGraph freshness+discoverability, stop-flushes-pending, steer history

## Goal
(1) Keep the CodeGraph up to date with every edit (agent tools, human editor, git ops) via an OS file watcher (notify) that debounces change bursts into incremental re-indexes; graph_* tools discoverable in TOOL_STRATEGY (done). (2) Pressing Stop with pending commands immediately starts the first pending command after stopping (queue steers instead of dropping; deterministic drain). (3) Pending commands (steers) appear in the up/down prompt history. No user questions — decide and document.

## Kind
implementation

## Context
Overnight assignment, three items. (1) CodeGraph: index() (src/codegraph/mod.rs:170) is incremental + content-hash-gated (re-parses only changed files; rebuild_edges only when changed), but runs only at startup (src-tauri/src/main.rs:957) and manual codegraph_refresh. User decision: use an OS FILE WATCHER (notify crate) — catches ALL edits (agent tools, human editor, git checkouts) without touching the edit tools.
