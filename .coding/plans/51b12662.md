# Plan: Conversation transcript windowing — render the last K entries with a show-earlier expander

## Goal
Bound the chat transcript's DOM size and per-flush reconciliation cost for long (run-all overnight) sessions: Conversation renders only the last TRANSCRIPT_WINDOW (200) visible entries by default, with a "Show earlier messages (N hidden)" expander above the list that grows the window by 200 per click; the streaming/auto-scroll path is untouched. Option (a) — windowing, no new dependency (virtualization deliberately deferred).

## Kind
implementation

## Context
Exploration done: Conversation.tsx (memoized filter→group→chunk pass keyed on transcript identity; stable entryId keys; endRef auto-scroll with stick-to-bottom; streaming block inside the last turn's group), Conversation.test.ts + Conversation.layout.test.ts (source-contract + pure-helper patterns, node env), BacklogView.test.tsx (renderToStaticMarkup works with useAgentStore components under SSR), agentState.ts (emptyAgentState builder, MAX_TRANSCRIPT_ENTRIES=1000 store cap, stampEntryIds). Design: option (a) windowing — tail window of the post-filter visible list inside the existing memo; expander grows the window stepwise; auto-scroll + streaming path untouched.

## Steps
- [x] 1. **Window the Conversation render (tail window + expander)** — In frontend/src/components/chat/Conversation.tsx: export `const TRANSCRIPT_WINDOW = 200` and a pure generic helper `windowEntries<T>(entries: T[], windowSize: number): { windowed: T[]; hidden: number }` (returns the same array + hidden 0 under the cap; `slice(-windowSize)` tail + hidden = length − windowSize over it). Add `const [windowSize, setWindowSize] = useState(TRANSCRIPT_WINDOW)` (add useState to the react import). Restructure the existing `turns` useMemo: filter (unchanged) → `windowEntries` → group into turns → chunkRuns, returning `{ turns, hidden }`; deps become `[state.transcript, showToolActivity, showKnowledgeActivity, windowSize]`. Above the turns list (inside the content div), render a centered muted expander button when `hidden > 0`: label `Show earlier messages (N hidden)`, `onClick={() => setWindowSize((w) => w + TRANSCRIPT_WINDOW)}` — disappears once everything is visible. Do NOT touch the auto-scroll effect (deps `[state.transcript, state.streamingText, state.pendingApproval]`, endRef after the turns list) or the streaming block (last turn's group) — the tail window always contains the last turn. Check README.md's chat/transcript feature bullets; if one describes transcript behavior, add a phrase documenting the 200-entry render window + expander.
