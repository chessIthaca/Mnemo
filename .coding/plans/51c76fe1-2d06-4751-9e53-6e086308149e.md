# Plan: Per-context model selection foundation

## Goal
Wire up a foundation so each subagent, skill, and workflow state machine step (planning/executing/etc) can run on a configured model (endpoint+model), falling back to the main agent's default model. Add a new `[models]` config section to configure these overrides. This enables e.g. "merge to main skill runs on deepseek v4 flash" while planning uses a smart model.

## Context
Explored the codebase. Key findings:
- Config lives in src/config/general.rs (GeneralConfig{general,context,ui}). Adding a section = new field with serde(default).
- Provider is Arc<dyn LlmClient> built via build_openai_client(config, endpoint, model, multimodal, reasoning_effort) in src/provider/client_factory.rs. Each OpenAiClient has a fixed model.
- AgentLoopFactory (src/agent/factory.rs) holds shared deps incl provider RwLock + context_manager + fill_rate. build_inner() snapshots provider+CM into a fresh AgentLoop. set_provider() swaps default. set_spawner(&self) pattern for late wiring; with_skills(self) consuming builder.
- AgentLoop (src/agent/loop_impl.rs): provider Arc<RwLock<Arc<dyn LlmClient>>>, context_manager Arc<RwLock<ContextManager>>. run_turn (src/agent/turn.rs ~line 56) snapshots provider+CM ONCE per turn at top. set_provider(provider, cm) swaps. Builder methods: with_constitution_source, with_safety_rules, with_safety_mode_handle, with_agent_id.
- Workflow (src/workflow/mod.rs): states Planning/Executing/Complete/Skill. wf.state(), wf.active_skill()->Option<&ActiveSkill> (ActiveSkill.name). allowed_tools().
- Spawner (src-tauri/src/ipc/spawn.rs): spawn_agent_shared builds via factory.build_with_id(id); when parent_id.is_some() sets agent_loop.set_plan_mutations_allowed(false)+workflow flag. This is where to set is_subagent.
- Skills (src/skill/mod.rs): SkillRegistry loaded from .coding/skills/*.toml. SkillSpec{name,available_in,target_state,tools,prompt}. Factory holds skills: Option<Arc<SkillRegistry>>, exposes skills_handle().
- IPC settings (src-tauri/src/ipc/settings.rs): get_settings/save_settings. GetSettingsResponse{config_dir,general,context,ui,endpoints,pricing,projects}. SettingsSaveDto patch. save_endpoints rebuilds provider. Contract fixtures in src-tauri/src/ipc/contract_fixtures.rs + frontend/src/lib/ipc-fixtures/*.json (exact-match golden tests).
- main.rs build_brain(): builds provider from config.default_endpoint, creates factory, wires skills + spawner.
- Frontend: tauri.ts types (AppSettings, SettingsSavePatch), SettingsDialog.tsx sections, types.ts SETTINGS_NAV + SettingsSectionId.

DESIGN DECISION: resolve the model PER TURN at turn start (matches the existing snapshot-once-per-turn pattern in turn.rs). Priority order: skill override > subagent override > workflow-state override > default. ModelRef{endpoint,model} mirrors VisionModel. New [models] config section. ModelResolver trait in core lib; factory holds Option<Arc<dyn ModelResolver>>; loop gets resolver+is_subagent+fill_rate via builders.
