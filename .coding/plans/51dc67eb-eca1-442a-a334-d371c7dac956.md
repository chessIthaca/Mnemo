## Context

Code audit so far: all three browser surfaces already pass --disable-extensions — (1) WebView2 (agent-chat + game-browser child webviews) via WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS in src-tauri/src/main.rs:64-68, (2) headless agent Chromium via BrowserConfig args in src/browser/mod.rs:257-264 with a throwaway profile dir. So a genuine Chrome extension should not load; the likely culprit is Grammarly for Windows (desktop app) code injection into msedgewebview2.exe renderers, which Chromium flags cannot block. User has enabled 'Agent browser inspection' and is restarting the app so game_snapshot/game_screenshot can inspect the live DOM for the <grammarly-desktop-integration> signature.
