# Plan: Second-instance warning: marker cleanup on exit + live dialog retraction

## Goal
Close backlog ea9576d7 — the same-project instance warning must not survive shutdown. (1) A cleanly exiting or project-switching instance removes its own <project>/.coding/instance.json marker, pid-guarded so a newer incumbent's marker survives (last-writer-wins).
