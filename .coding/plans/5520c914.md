# Plan: Leads record a bug plan's regression test by its bare name

## Goal
Every lead (the in-app Mnemo2 lead, the Mnemo1 workflow and an external Claude Code lead) is told, in its system prompt and in the regression_test parameter description, to record a bug plan's regression test as the bare test name, so bug plans stop failing to close over a path or module prefix.

## Kind
implementation

## Context
WHY (2026-11-23): two finished bug_fixing plans stayed open for 11 days because their regression tests were recorded as `build_workflow_tauri_cli_is_declared_and_locked (tests/integration/ci_workflow.rs)` and `agent::tests::constitution_reread_after_agent_md_edit (src/agent/tests.rs)`. The close gate looks the recorded string up as a symbol in the code graph and on disk, so the path suffix and module prefix made it miss. Only the mnemo-plan skill (mnemo2/plugin/skills/mnemo-plan/SKILL.md:23) says "bare test function name"; the system prompts and the parameter descriptions say only "the regression test name", and the plan_create guidance asks the context to name "which test, which file", which invites the file in parentheses. The user asked for this to be in the system prompts so every Mnemo session (the factory/in-app lead included) follows it.

The wording is decided (the lead reviews it word for word). Insert it VERBATIM; do not paraphrase.

W1, the regression_test PARAMETER description (input schemas only):
"The regression test's bare name exactly as written in the source: the test function name (for example retry_stops_after_three_attempts) or, for a string-titled test, the exact it()/test()/describe() title. No file path, module path (a::b::) or note in parentheses: the plan cannot close until this exact name is found in the code."

W2, the in-app lead's system prompt, src/agent/prompt.rs PLAN KIND paragraph (~:105-117): insert this sentence right after "bug_fixing is for CONTAINED defect fixes." (before " The plan file is the CRASH-RESUMPTION document"):
"Record its regression test (update_plan regression_test) as the bare test name exactly as in the source, never with a file path, module prefix or note in parentheses: finish refuses a name it cannot find in the code."

W3, the external Claude Code lead's instructions, src-tauri/src/mnemo2/mcp_server.rs LEAD_INSTRUCTIONS first bullet: replace "plan_create kind bug_fixing for bugs;" with "plan_create kind bug_fixing for bugs, recording its regression_test as the bare test name (no file path or module prefix);".

W4, the Mnemo1 bug_fixing skeleton's Verify step, src/app/tool/workflow/plan.rs ~:61: replace "Record the regression test name via update_plan (regression_test field)" with "Record the regression test's bare name, exactly as in the source and with no file path or module prefix, via update_plan (regression_test field)".

VERIFY: `cargo test --workspace`; `cargo clippy --workspace --all-targets` (warning-free).
