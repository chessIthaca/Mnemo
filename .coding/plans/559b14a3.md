# Plan: Backlog tab: badge the live plan phase as 'plan: <phase>'

## Goal
The Backlog card's single status badge swaps vocabularies — item statuses ("done", "failed"…) on every card, but the raw plan phase ("complete") on the in-flight card, in the same slot — which reads as two statuses for one thing. Prefix the live-phase branch with "plan: " (the badge reads "plan: complete", "plan: executing"…) and add a title tooltip naming the two layers, so the plan's phase can never be mistaken for the item's status. Frontend-only, display-only; the queue vocabulary, styles, and every other card's badge stay untouched.

implementation
