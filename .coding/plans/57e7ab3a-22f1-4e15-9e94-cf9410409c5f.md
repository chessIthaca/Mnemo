# Plan: update_plan tool + abandon_plan needs approval

## Goal
Add an `update_plan` tool that edits/appends to non-finished steps of the active plan (never touching completed steps), and make `abandon_plan` require user approval (last-resort only).

## Context
The user dislikes how often plans get abandoned (abandon_plan is a fresh-plan-from-scratch reset that returns to Planning). They want: (1) a new `update_plan` tool that can only modify NON-finished items (append new steps, edit not-yet-completed steps) — never touch completed steps; (2) `abandon_plan` should require user approval and be treated as a last resort. Need to explore the current plan tools (src/tool/workflow/plan.rs) and the Workflow API (src/workflow/mod.rs create_plan/abandon_plan/complete_step + PlanFile in plan_file.rs) to design update_plan. Likely adds a Workflow::update_plan method that rewrites the active plan's unfinished steps + appends new ones (preserving completed-step checkboxes), and a tool that calls it. abandon_plan safety level change (needs approval) is in the tool's safety classification. Need to confirm whether update_plan should be available only in Executing (modifying the active plan) — likely yes, since in Planning there's no plan yet (use create_plan) and in Complete you create a fresh plan.
