# Plan: Edit path: anchor-by-read-reference — kill post-compaction re-reads

## Goal
Additive anchor-by-read-reference form for the edit tools: read_files mints a short per-read receipt id visible in its output; file_edit (top level + ops items) and multi_edit (ops items) accept {from_read: <id>, lines: [start, end], new_string} anchors validated server-side against the CURRENT file bytes at those lines (path + range-subset + per-line hash) — the verbatim anchor blob never needs to live in the model's context, so compaction is harmless to the edit path. Drift = hard fail with the fresh-read steering (never a fuzzy apply); the existing old_string form stays the unchanged default.
