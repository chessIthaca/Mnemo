FACTS (verified 2026-11-14 — use these exact names):
F1 Product. Mnemo2 is the only app: Svelte 5 UI in `mnemo2/`; Tauri host library `mnemo-app` in `src-tauri/src` (Mnemo2 code in `src-tauri/src/mnemo2/`); app package `mnemo2-app` in `src-tauri/mnemo2-app` with binaries `mnemo2` and `mnemo2-mcp`; the engine library `mnemo` in `src/` (features kernel, headless, app by default; optional browser, embeddings; dev-only test-support). A lead plans on a plan board and dispatches each step to a worker. The lead is Mnemo2's built-in lead chat, or Claude Code through the `mnemo` plugin (`mnemo2/plugin/`, marketplace entry `.claude-plugin/marketplace.json`). Each worker runs on a tier in its own `wt/agent-*` branch and `.worktrees/agent-*` checkout forked from the lead branch tip. Workers cannot plan, spawn agents, ask the user, push or merge. The lead reviews (unanchored diff pass, structured evidence, checks recorded on the exact commit, every finding closed; high-risk work also needs an independent read-only audit) and merges `--no-ff` into its local lead branch (`wt/mnemo` in this repository); Mnemo2 then deletes the worker branch and checkout. Mnemo2 never pushes and never merges into main.
F2 Landing. main is protected by two GitHub rulesets: `main-protection` (id 24182945: pull request required, 0 required approvals, no deletion, no force-push) and `ci-check-required` (id 27026992: the `check` status from `.github/workflows/ci.yml` must pass; only an admin can bypass, and only when merging a pull request). The lead pushes the lead branch, opens a pull request into main and enables auto-merge with merge method "merge"; GitHub merges it once `check` passes. Ruleset 23755694 and "1 required approval / the human approves" no longer exist.
F3 CI. `.github/workflows/ci.yml`, job `check`, windows-latest, on pull requests to main and pushes to main, runs: `npm ci`; `npm run build:mnemo2`; `npm test --workspace mnemo2`; `cargo clippy --workspace --all-targets`; `cargo clippy -p mnemo-app --all-targets --features mnemo2`; `cargo test --workspace --no-fail-fast`; `cargo test -p mnemo-app --features mnemo2 --lib`. `build.yml` is the release pipeline (manual or `v*` tag) and builds Mnemo2_<v>_x64_en-US.msi, Mnemo2_<v>_x64-setup.exe, Mnemo2_<v>_aarch64.dmg and mnemo2.app.zip. `cargo test --workspace` compiles `mnemo` with browser and embeddings because `src-tauri` depends on it with both features; a plain `cargo test` / `cargo test -p mnemo` does not.
