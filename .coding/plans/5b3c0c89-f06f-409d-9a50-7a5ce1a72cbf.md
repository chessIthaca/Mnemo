# Plan: Configurable reasoning effort (toolbar dropdown, default max)

## Goal
Add configurable reasoning effort: a `reasoning_effort` field on endpoints (threaded into the LLM request body), with a dropdown in the toolbar right next to the model picker, defaulting to "max".

## Context
The request body (src/provider/openai.rs build_request_json) currently sends only model/messages/stream/max_completion_tokens + optional tools/tool_choice — no reasoning_effort. The Endpoint config (src/config/endpoints.rs) has no field for it. The provider is rebuilt at runtime by set_model (src-tauri/src/ipc/commands.rs) and initially by build_brain (src-tauri/src/main.rs). The toolbar model picker lives in frontend/src/components/layout/StatusBar.tsx with setModel in frontend/src/lib/tauri.ts and model/provider state in useAgentStore.ts.

Design: add `reasoning_effort: Option<String>` to Endpoint (endpoints.toml, serde default) and OpenAiClientConfig; emit `"reasoning_effort"` in the request body only when Some. Extend set_model(endpoint_name, model, reasoning_effort: Option<String>) — None = omit the field ("off"), Some = send verbatim. build_brain initial provider defaults to "max" (endpoint config ?? "max"). get_config returns per-endpoint reasoning_effort. Frontend: store reasoningEffort (default "max") + setter; StatusBar gets a dropdown right next to the model picker (options: max, high, medium, low, minimal, off) that calls setModel(provider, model, effort===off?null:effort); model switch passes the current effort; App.tsx seeds from the default endpoint config on mount.

## Steps
- [x] 1. src/config/endpoints.rs: add `reasoning_effort: Option<String>` (serde default) to Endpoint + parse tests.
- [x] 2. src/provider/openai.rs: add `reasoning_effort: Option<String>` to OpenAiClientConfig, emit `reasoning_effort` in build_request_json when Some, add tests, and update all OpenAiClientConfig constructor sites (openai.rs tests, vision.rs test, tests/provider_integration.rs) with the new field.
- [x] 3. src-tauri: thread reasoning_effort through — build_brain (main.rs) defaults to endpoint config ?? "max"; set_model (ipc/commands.rs) gains `reasoning_effort: Option<String>` param; get_config returns per-endpoint reasoning_effort; register any new args.
- [x] 4. Frontend store + IPC wrappers: useAgentStore.ts gains reasoningEffort (default "max") + setReasoningEffort; lib/tauri.ts EndpointInfo gains reasoning_effort + setModel takes effort; App.tsx seeds from the default endpoint on mount.
- [x] 5. StatusBar.tsx: add a reasoning-effort dropdown right next to the model picker (options max/high/medium/low/minimal/off) that calls setModel with the current provider+model; model switch passes the current effort.
- [x] 6. Verify: cargo test + npm run build (tsc + vite) both pass.
