# Plan: Plan steps state intent, not code

## Goal
The guidance a lead gets for writing plan steps asks for intent, contracts, rules and named tests, not function bodies, and the board's advisory "Spec notes" stop nagging steps that keep their shared detail in the plan context.

## Kind
implementation

## Context
WHY: the user (2026-11-15) agreed that specs had become nearly the code, so workers only transcribed and the lead did the work twice: "I definitely like the specs that state intent part". The new style: each step says why and what must be true afterwards, names the files and any new contracts (signatures, data shapes, wire formats), lists the rules, edge cases and known traps, names each test with what it must prove, and gives a done checklist and the files not to touch. Function bodies and test code are left to the worker; code is spelled out only where the decision is subtle or easy to get wrong (cfg gating, a lock order, an exact error string). Shared detail can live once in the plan context, and steps refer to it.
WHERE:
- src/app/tool/workflow/board.rs: the plan_create `steps` description (around line 277) and the plan_update `add_steps` description (around line 459). Both currently say "an implementation spec a cheaper model can follow without design decisions… Longer is better than vague."
- The same file: spec_gaps / has_signature (around lines 140-170) produce the advisory notes ("under 120 words", "no signatures", "no tests named", "no done checklist"), plus the existing test that pins them (around line 963).
- mnemo2/plugin/skills/mnemo-plan/SKILL.md: the field list (around line 25) and the section "Write each step as a spec" (around lines 38-52). The skill ships into the app via include_str! in src-tauri/src/mnemo2/claude_code.rs, so no other copy needs editing.
RULES for the advisory:
- Judge a step together with the plan context: words, tests and done-checks may come from either.
- Drop the "no signatures" note: many valid steps add no new signature.
- Keep "no tests named" and "no done checklist", computed over step plus context.
- "under 120 words" becomes "under 60 words" and counts step plus context words.
- Still advisory only; never refuse.
TESTS: update the pinned advisory test to the new notes, and add `context_detail_counts_for_spec_notes` (a short step whose plan context names tests and a done check gets no notes) and `thin_step_and_thin_context_still_get_notes`.
Do not touch mnemo2/plugin/skills/mnemo-lead/SKILL.md or mnemo-review/SKILL.md (another plan edits them), or src/app/tool/workflow/plan.rs (the retired Mnemo1 workflow).
VERIFY: `cargo test -p mnemo --lib app::tool::workflow::board`, `cargo clippy -p mnemo --all-targets`, `git diff --check`.
