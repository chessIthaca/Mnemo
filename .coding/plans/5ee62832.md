# Plan: Split openai.rs size hotspot: models module, complete() stages, openai/ submodules

## Goal
Restructure the repo's size hotspot src/provider/openai.rs (6,589 lines ≈ 2,856 production + 3,733 tests) with ZERO behavior change: (a) relocate the /models discovery family (incl. fetch_models_anthropic) to a new shared src/provider/models.rs; (b) decompose the ~838-line complete() into named stages — prepare_request → open_stream → spawn_stream → pump_sse_stream — each independently callable; (c) split the remainder into openai/ submodules (request/sse/stream/guard) and the test module into openai/tests/ submodules. All existing tests stay green with identical total count (they pin the GLM/DeepSeek/claude behaviors); no behavior change — pure structure.
