# Plan: bug_fixing skeleton: allow appended follow-on steps in Reviewing (backlog 37f8631a)

## Goal
Open a narrow append window in the bug_fixing skeleton lock: update_plan(append=true) with steps succeeds for bug_fixing plans in the Reviewing state only (follow-on fix work during the closing sequence — the fix-findings scope), while steps replacement stays refused in every state and appends stay refused while Executing. The refusal error names the sanctioned alternatives (Reviewing append window, context amendment, create_plan sub-plan). Appended steps stay unchecked through the review (complete_step is hidden mid-review; finish does not gate on them) and meet the same resumability bar as every other step.
