# Plan: GLM stop boundaries: config-driven stop_boundary_strings (drop the hardcoded glm-5.3 prefix check)

## Goal
Replace the hardcoded starts_with("glm-5.3") stop-boundary injection in the generic OpenAI client with an endpoint/model-level config field stop_boundary_strings: Vec<String> (beside stop_token_ids, resolved the same way via stop_boundary_strings_for(model_id)), seeded with the GLM entries in the endpoints.toml examples, so the provider reads config instead of matching model-name prefixes — one mechanism, one place, editable without recompile; aliased/renamed models get guard protection.
