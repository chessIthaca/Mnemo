# Plan: Markdown tab file dropdown

## Goal
Add a dropdown to the Markdown viewer tab that lists every .md file in the project (recursively), excluding the agent's plan documents in .coding/plans/. Selecting a file loads and renders it.

## Context
MdViewer.tsx currently only displays a file when opened via the FileBrowser custom event. There's a non-recursive list_files command and a read_file command, but no way to enumerate all .md files recursively. Plan documents live in .coding/plans/<id>.md. The sandbox validates paths against the project root. Commands are registered in src-tauri/src/main.rs invoke_handler. Frontend wrappers live in frontend/src/lib/tauri.ts.

## Steps
- [x] 1. Add a `list_markdown_files` Tauri command in src-tauri/src/ipc/commands.rs that recursively walks the project root, collecting relative paths of .md files while skipping .git, node_modules, target, dist, and .coding/plans directories. Returns Vec<String> of forward-slash relative paths, sorted. Route through the sandbox root.
- [x] 2. Register the new command in src-tauri/src/main.rs invoke_handler.
- [x] 3. Add a `listMarkdownFiles()` typed wrapper in frontend/src/lib/tauri.ts.
- [x] 4. Update frontend/src/components/views/MdViewer.tsx: add a <select> dropdown in the header that populates from listMarkdownFiles() on mount (with a refresh button), loads the selected file via readFile(), and stays in sync when a file is opened via the FileBrowser custom event.
- [x] 5. Run cargo test + cargo build to verify the backend compiles and tests pass; verify the frontend type-checks.
