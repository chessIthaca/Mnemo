# Plan: Remove startup welcome dialog

## Goal
Remove the first-run welcome panel (with example prompts) from Conversation.tsx so an empty conversation renders blank instead of showing the "Welcome to myharness" dialog.

## Context
Conversation.tsx renders a centered welcome panel with EXAMPLE_PROMPTS when the transcript is empty (the `isEmpty` branch). The user finds this dialog wrong and wants it gone. The panel includes the EXAMPLE_PROMPTS constant, a sendExample() helper, the isEmpty computed flag, and the conditional JSX. Removing it means always rendering the (possibly empty) transcript. The sendExample helper is the only user of the sendPrompt/useAgentStore/emptyAgentState imports in this file, so those become unused and should be dropped too.
