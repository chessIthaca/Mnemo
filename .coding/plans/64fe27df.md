# Plan: Auto-continuation & context safety for long sessions

## Goal
Make three continuation-prevention behaviors automatic in Mnemo itself: preemptive compaction before provider calls that would exceed the hard ceiling; auto-resume when a turn ends with an active executing plan and nothing blocking (bounded by config + streak cap); automatic mid-session memory-consolidation checkpoints past an event threshold instead of advisory-only until exit.

## Kind
implementation

## Context
User approved making all three continuation-prevention behaviors automatic in code. Findings from reading src/runtime/agent.rs: (1) run_turn_with_retry already auto-resumes mid-turn steers as user messages; drive_turns already nudge-resumes after compaction — generalize this pattern. (2) A hard provider ceiling (262144) was hit fatally at ~230K input tokens; no pre-flight guard exists inside run_turn_attempt before each provider call — only between-turn summarize_at_fill_rate. (3) memory_consolidate is advisory-only mid-session; fires only at exit. Config lives in src/config/general.rs (GeneralConfig with clamps like clamp_budget). Never auto-resume Interrupt/Cancel turns. Bounded by config + streak cap so genuine deadlocks still park for the user.

## Steps
- [x] 1. **Pre-flight context guard in run_turn_attempt**
- [x] 2. **Auto-resume + consolidation scheduler** — Two remaining behaviors from the plan goal:

(A) Auto-resume: when a turn ends (Finish::Stop) but the workflow is still in Executing state and nothing is genuinely blocking (no approval pending, no ask_user), push a synthetic 'continue' message and run one more turn — exactly like the existing steer-resume pattern in agent.rs:140-164. Bounded by config (agent.auto_continue, default true) + streak cap (agent.auto_continue_max_streak, default 12) so genuine deadlocks park for the user. Never auto-resume Interrupt/Cancel turns.

(B) Consolidation scheduler: fire memory_consolidate proactively mid-session when working-memory events exceed a threshold, instead of advisory-only until exit. Fire-and-forget spawn like the exit path.
