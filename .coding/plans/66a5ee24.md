# Plan: Chat markdown file links open through the sanctioned openers

## Goal
Markdown links in chat messages open their target through the sanctioned openers instead of dead raw anchors: local file paths (e.g. .coding/reviews/…, .coding/plans/…, .coding/knowledge/…, any project-relative path) deep-link into the Files tab via openFileInViewer with a normalized project-relative forward-slash path; external http/https links open via openExternal (the established CSP-safe shell path); non-openable schemes (mailto:, fragments) render as plain text with no dead affordance. Regression tests pin the click routing through the real requestFileOpen store action and the Message.tsx wiring.
