# Plan: Worker rows show the model again, Laya chips on their own line

## Goal
Every worker row in mission control shows the model the worker runs on, whatever routing chips it carries; the Laya routing and nudge chips move to a small line of their own under the name.

## Kind
implementation

## Context
Why: the user reported that worker rows now show the Laya rating (e.g. `Laya: medium 0.47`) instead of the model. Cause: in mnemo2/src/components/WorkerRow.svelte the name line `.worker-name` is one flex row holding the name, badges, the routing chip, the nudge chip and finally `<ModelBadge model={worker.model} />`. `.route-chip` has `flex: 0 0 auto` (never shrinks) while the model badge has `min-width: 0` and `max-width: 130px`, so on a normal-width row the chips take the space and the model badge shrinks to nothing. The user wants the model used shown; the Laya rating is secondary.

Decision: keep `ModelBadge` on the name line (it stays last, right-aligned via `margin-left: auto`), and render the routing and nudge chips in a new `<span class="worker-route">` line directly under the name line (before `worker-plan`), only when at least one chip exists. The chip texts (mnemo2/src/lib/workerRouting.ts) do not change. The Audit and High risk badges stay on the name line.

Files: mnemo2/src/components/WorkerRow.svelte and mnemo2/src/components/WorkerRow.test.ts only. Do not touch workerRouting.ts, ModelBadge.svelte or any Rust file.

Verification (run in mnemo2/): `npx vitest run src/components/WorkerRow.test.ts src/lib/workerRouting.test.ts` and `npx svelte-check --threshold error`.

## Acceptance scenarios
- A worker row with a Laya routing chip shows its model name on the name line and the chip on a separate line below
- A worker row without routing shows no route line and still shows its model
