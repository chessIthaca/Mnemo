# Plan: Add Reviewing workflow state — enforce the review/commit closing sequence

## Goal
Add a Reviewing workflow state between Executing and Complete so the review→fix→commit closing sequence has a real home with its tools available, and make the review unskippable: a new `finish` tool is the only path out of Reviewing, and it requires a non-empty review report file under .coding/reviews/.

## Context
Root cause: complete_step's final step does Executing→Complete (src/workflow/mod.rs:404), but Complete's ToolFilter (src/tool/mod.rs:227-247) allows only read tools + create_plan/skill_start/ask_user/current_plan — it hides spawn_agent, git, file_edit, file_append, shell. The closing sequence (review→fix→commit) needs exactly those tools, so the moment the last step completes they vanish and the review/commit can't run. The review is only a convention in agent.md, not enforced — which is why it got skipped.

Fix: add a Reviewing state between Executing and Complete. complete_step's final step → Reviewing (not Complete). A new `finish` workflow tool (AutoRun, Reviewing-only) is the ONLY path Reviewing→Complete, and it requires a non-empty review report file under .coding/reviews/ (the dir reviewer subagents already write to). This makes the review unskippable by construction.
