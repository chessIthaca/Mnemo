# Plan: Lead context ring with compaction in the Mnemo2 top bar

## Goal
Show how much of the lead's context window is used as a small circular progress ring in the Mnemo2 top bar, with a Mnemo1-style info popup (breakdown by role) and a "Compact now" button that compacts the lead's context.

## Kind
implementation

## Context
Why: the user wants to see, at a glance at the top of the window, how much of the lead's context is used, and to be able to compact it. They like Mnemo1's context info popup and want its style ported. To save screen space the indicator is a circular progress ring, not Mnemo1's horizontal bar.

\## Acceptance scenarios
- With a native lead whose snapshot reports used_tokens 50000 and max_tokens 200000, the top bar shows a ring whose aria-label reads "Lead context 25% used (… of … tokens)".
- A context_usage lead event with used 150000, max 200000 and a breakdown updates the ring to 75% with the warning colour, without a snapshot reload. The popup lists the four breakdown values.
- Clicking the ring pins the popup. Pressing "Compact now" sends the lead_compact IPC. The button is disabled while the lead is busy.
- compact_started shows "Compacting…" with the button disabled. compacted { before, after } sets the ring to after / max and re-enables the button.
- A Rust test proves the lead compact emits CompactStarted then Compacted and reduces used_tokens, and errors with "the lead session is not open" when no session is open.
