# Plan: Guard the Failed transitions like Done — plan_abandoned arms flip items the plan never owned

## Goal
Guard every plan_abandoned → Failed transition with the same status+linkage discipline the Done transitions got from 5bb1e4cd/e33a07fd: only a still-InFlight item whose plan_id IS the abandoned plan may flip to Failed; a re-queued Pending item stays Pending with its note preserved when an unrelated plan is abandoned. The abandoned plan's id is captured from the turn's transition evidence (the forwarder's prev-top tracking → the TurnResolveLatch), not a live read.

(c) The three resolution functions gain an abandoned_plan_id: Option<&str> param alongside plan_abandoned: bool; the events.rs callers (spawn :332, try_flush_deferred_main_resolution :1122, try_flush_deferred_spawned_resolutions :1187) read both from the latch.

THE GUARD (mirror of plan_linkage_allows_done, pure fn in run_all.rs): plan_linkage_allows_failed(item_status, item_plan_id, abandoned_plan_id) -> bool: status != InFlight → false (a re-queued Pending item stays Pending — NOTE PRESERVED; Done/Failed items don't re-flip); (Some(pid), Some(apid)) → pid == apid; (None, Some(_)) → false (the item never planned); _ → true (blind — no captured id: the pre-guard behavior, no happy-path regression).
