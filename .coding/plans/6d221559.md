# Plan: 429 → automatic cross-provider model fallback

## Goal
On a 429 (rate limit / out of tokens), automatically switch to the same model id on a different endpoint and retry once — instead of burning the 3× same-provider retry stack or failing. Stop after a single 429 against any one provider. If no alternate endpoint serves the model, surface a clear actionable error (main agent) / fail through the existing failed-reviewer protocol (reviewer). Works for all agents including the reviewer subagent.
