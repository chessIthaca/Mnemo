# Plan: Recall delta: compact references for already-injected memories in the volatile tail

## Goal
Add a `recall_delta` token-optimizer lever (default ON, [general.optimizer]) so the volatile tail stops re-sending a memory's 160-char snippet when auto-recall surfaces the same, unchanged memory again: the repeat renders as a compact reference (tier, title, stable id, score, "unchanged since injection (turn N)") that points at memory_search for the full text. Full snippet is still injected for a newly recalled or changed memory (id + content hash compared, never id alone), after compaction invalidates the epoch, and whenever the lever is off (byte-identical to today). Each elision records a savings row (kind "recall_delta") so the Dashboard per-kind table and the session quality counters both carry it, and the lever is togglable in Settings → Savings.

DESIGN (user decision, 2026-01-16): implement reference elision as specified. New lever `recall_delta` in OptimizerConfig ([general.optimizer], default ON). A per-session RecallDeltaCache maps memory id -> RecallEntry{content_hash, epoch, full_turn}; an entry is elidable only when the id matches AND the content hash matches AND the entry's epoch equals the cache's current epoch (so supersede/update changes the hash -> full re-inject; compaction bumps the epoch -> full re-inject). Rendering a repeat as a compact reference: "[tier] Title (id: X, score: s) ��� unchanged since injection (turn N); re-read with memory_search if needed."

ACCEPTED TRADEOFF (explicitly chosen by the user after the finding was raised): the tail is popped after every request (turn.rs:542-543), so a recalled memory's text is NEVER in the next request's context — not just after compaction. A compact reference therefore names text the model must re-read with memory_search. The caveat "only elide when the prior injection is genuinely still in context" is honoured in its implementable form: same id + same content hash + same compaction epoch. Flag OFF must remain byte-identical to today.

SAVINGS: one ledger row per auto_recall that elided anything — kind "recall_delta", detail "N memories (M elided)", tokens_before = estimate_tokens(full render), tokens_after = estimate_tokens(delta render), measured = false. Guard: if the delta render is not smaller (after >= before), fall back to the full render and record nothing (mirrors read_files' reduced-serve guard).
