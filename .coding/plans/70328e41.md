# Plan: Status-bar tok/sec: rolling last-3-requests window

## Goal
Replace the InflightBar status bar's session-wide weighted-mean output tok/sec with a rolling window over the last 3 timed requests, so the rate reflects the model's CURRENT speed (e.g. right after an endpoint switch or a slow patch) instead of drifting toward the session average. Only the status-bar display changes — StatsView, per-request rates, traceStats, and the sessionTiming totals stay untouched.
