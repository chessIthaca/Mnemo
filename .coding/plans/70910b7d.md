# Plan: Reasoning-state continuity: raw-payload source of truth + ProviderPolicy

## Goal
Bring the agent harness to the multi-provider reasoning-state-continuity spec: store each provider's assistant turn verbatim (raw) as the single source of truth and echo it unchanged in requests; drive all provider behavior from a ProviderPolicy data object; support server-side stateful mode (previous_response_id / previous_interaction_id) alongside stateless replay; never trim inside an open tool loop; strip reasoning + set reasoning_stripped on cross-vendor model switches; and fail loudly on serialization-bug 400s. Rule 7's UI-removal is WAIVED (thinking panel + Trace stay); the backend raw/view separation still lands.

## Kind
implementation

## Context
Verified gap analysis against the spec this session. ROOT CAUSE: Message (src/provider/mod.rs:148) is a fixed-field canonical struct and both request builders (openai.rs:1271, anthropic.rs:221) rebuild JSON from its fields — exactly what Rule 1 forbids ("the entire bug this spec exists to prevent"). provider_meta is an allowlist (PROVIDER_PASSTHROUGH_KEYS=&["thought_signature"], mod.rs:378) that silently drops unknown reasoning fields. Anthropic thinking-block signatures are never captured (parser has no thinking arm in content_block_start). No ProviderPolicy, no stateful_key, no reasoning_stripped flag, no fail-loud classifier. Compaction has an orphan-tool boundary fix (summary_cut_index) but no full tool-loop atomicity. Cross-vendor switches silently drop reasoning with no flag. Recent prior work to build on: centralized Message/ToolCall constructors (mod.rs:181-369), thought_signature round-trip via provider_meta (stream.rs DeltaAccumulator + apply_provider_meta), DeepSeek reasoning_content echo (openai.rs:1365), Anthropic unsigned-thinking-echo removal (anthropic.rs:381). Scope: full Rules 1-6; Rule 7 waived at UI (user decision 2026-12-21). Windows/PowerShell; cargo test unpiped + $LASTEXITCODE; #![deny(warnings)] (zero warnings, no #[allow]); doc comments on all pub items; every defect gets a regression test.
