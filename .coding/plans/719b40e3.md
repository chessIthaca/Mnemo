# Plan: search → graph nudge: symbol hint in search/search_read output

## Goal
When `search` (or `search_read`) runs a bare-identifier pattern that exactly names an indexed symbol, prepend a one-line advisory note to the output nudging toward graph_search/graph_context — making symbol-lookup drift self-correcting for every agent session.

## Kind
implementation

## Context
Motivation: agents (including this one, observed 2026-08-29 — the `connectOauth` lookup walked 1455 files) use `search` for symbol lookups where graph tools are mandatory. The nudge makes the wrong path self-correcting at the moment of drift. RESEARCH (verified): SearchTool (src/tool/agent/search.rs) holds `graph: Option<Arc<crate::codegraph::CodeGraph>>` (line 164-176); execute runs in spawn_blocking with two success returns — index engine path returns at ~line 374 `ToolResult::success(with_note(body, &fallback_note))`, walk engine at ~line 463 same shape; `with_note` (line 261) PREPENDS an optional note before the body (notes must be visible before results — tool outputs get capped, so append-at-end risks truncation). search_read.rs (sibling tool) shares try_index/with_note and mirrors both paths. Store::symbols_named(name) (src/codegraph/store.rs:474) = exact case-sensitive indexed SELECT on cg_symbols.name, returns Vec<Symbol>, exists "for cheap lookups". CodeGraph (src/codegraph/mod.rs) exposes view()/search_content()/content_coverage() but NO symbol probe — both lock the store internally; mirror their pattern. Tests: search.rs has make_tool (graph None) + make_indexed_tool (in-memory graph, graph.index(None)) helpers; codegraph mod tests build in-memory graphs. DESIGN: fire ONLY when (a) pattern is a bare ASCII identifier ([A-Za-z_][A-Za-z0-9_]*, any length ≥1), (b) graph is Some, (c) exact case-sensitive symbol match exists. Exact-only keeps precision (substring would fire on ordinary words like "mcp"). Fires in BOTH regex and literal modes (the drift case was default regex), and on zero-match results too (most valuable: "no content matches, but the graph knows this symbol"). Best-effort: any store error → no nudge, never breaks search. Constraints: Windows/PowerShell, cargo test UNPIPED, deny(warnings), doc comments on public items, multi-platform, regression tests, four suites green, reviewer, never commit to main. Untracked knowledge file .coding/knowledge/how/2026-08-29-lookup-taxonomy-*.md on main rides along into the branch commit.
