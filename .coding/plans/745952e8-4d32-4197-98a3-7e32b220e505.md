# Plan: spawn_agent completion notify + auto-combine, ToolCard label, review fixes

## Goal
Close the spawn_agent feedback loop: when a tool-spawned background agent finishes its task, automatically notify its parent agent (which surfaces in the parent's window and can auto-combine results into a plan). Also show the agent's name in the spawn_agent ToolCard, and fold in the quick-win review fixes.

## Context
Three parallel review agents produced reports in .coding/reviews/ (rust-core, tauri-ipc, frontend). No critical issues; cargo build clean, cargo test 357/0, tsc --noEmit clean.

MISSING MECHANISM (the user's core point): spawn_agent is fire-and-forget. AgentTask emits Finished{reason} at end of each turn (stays alive, idle) and Exited only on true termination; events.rs forwarder sets running=false on Finished and removes the agent on Exited. There is NO parent linkage, no completion event back to the spawner, and no notification — so the orchestrating agent (me) has no signal that background agents finished, and no auto-combine step. I had to be told.

Current plumbing: channels.rs AgentEvent/SerializableAgentEvent (tag=kind snake_case). commands.rs spawn_agent_shared(factory,manager,agent_loops,name,initial_prompt)->(id,name) is shared by the spawn_agent Tauri command and IpcSpawner (the tool path). AgentHandle{id,name,command_tx,running}. AgentManager.agents: HashMap. runtime/mod.rs AgentSpawner trait: spawn(name,task)->AgentId. spawn_agent.rs tool delegates; safety=NeedsApproval. Frontend Message.tsx argLabel() already special-cases toolName==='shell' to show parsed.purpose as a '(label)' in the ToolCard header — spawn_agent needs the same via parsed.name.

Review fixes to fold in (quick wins only; defer StatsView over-fetch #2/#3 — needs a refactor, not worth the perf cost now):
- rust#1 (MAJOR): agent/mod.rs ~540 cached-token heuristic over-reports after summarization/first-request. Fix: track per-turn did_summarize (set where summarize_with_interrupt runs ~line 354) and only apply the min(prev,curr) fallback when NOT summarized this turn.
- rust#3: spawn_agent.rs:41 SpawnAgentTool::new missing doc comment (project rule).
- rust#2: agent/mod.rs:559 sid uses self.session_id() loop state instead of the run_turn session_id param (implicit invariant).
- ipc#4: start.bat — the tauri.cmd existence check sits after the dev branch; move it before so `start.bat dev` with no node_modules fails friendly.
- frontend#4: StatusBar selectModel/selectReasoningEffort only console.error on set_model failure; label desyncs. Surface a transient error + re-sync from backend.
Defer (note in plan, don't implement): rust#5 correction 'summar' trigger too broad; ipc#8 CSP hardening; frontend#1 StatsView inconsistent error handling; frontend#5 dropdown a11y; frontend#6 setCode*Color verbosity; frontend#7 CodeBlock copy.
