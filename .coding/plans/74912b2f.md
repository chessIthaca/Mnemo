# Plan: Fix: run-all dispatches next backlog item into the main agent during steering (re-record)

## Goal
Stop run-all from dispatching the next backlog item into the main agent when the user steers mid-run. A steer during run-all should halt the run (mirroring the approval halt), so the steer runs cleanly without interleaving with the next backlog item.

## Kind
bug_fixing

## Context
Root cause confirmed: a mid-turn steer folds into StopReason::Steer → agent soft-stops → emits Finished. The forwarder's TurnResolveLatch::on_finished (src-tauri/src/ipc/events.rs) returns ResolveAction::Success for ANY clean Finished — it ignores FinishReason and cannot distinguish a steer soft-stop from a real turn-end. So on_main_turn_resolved (run_all.rs:663) fires → run_all_dispatch_next (run_all.rs:475) → dispatches item N+1's Prompt into the main agent. The `stopped` flag (run_all.rs:807) was only set by halt_run_all_for_approval — steers never set it.

Fix (already implemented + committed as 235ccbe on wt/agenticcoding): send_suggestion now halts run-all (mirroring the approval halt) BEFORE sending the steer. Generalized halt_run_all_for_approval → halt_run_all(app, reason). Also fixed E2 (halt_run_all now calls end_run even when no in-flight item). Regression test: send_suggestion_halts_run_all_before_sending. Review: PASS (.coding/reviews/2026-12-04-run-all-steer-interleave-review.md).

This plan re-creates the bug_fixing workflow record so the regression_test field can be recorded via update_plan (the original plan missed this step — update_plan is blocked in Reviewing). All work is already done and committed.
