# Plan: Eager Complete → Planning: work-intent nudge + directive STATE_COMPLETE

## Goal
Make the agent more eagerly switch from Complete to Planning when the user's message implies code changes. Today the only guidance is the terse STATE_COMPLETE prompt ("Write tools need a new plan: create_plan first") — purely LLM-judged, with no heuristic or automatic trigger. The improvement adds (1) a directive STATE_COMPLETE enhancement that tells the agent when to plan vs. answer freeform, and (2) a code-level work-intent heuristic that injects a "PLAN NUDGE" into the volatile tail when the workflow is in Complete state and the latest user message contains an imperative work verb (fix, add, implement, refactor, …). The nudge is a suggestion, not a forced transition — false positives are harmless (the agent can still answer a question); false negatives fall back to the enhanced STATE_COMPLETE prompt.
