# Plan: Graph tab shows the whole graph and draws compact nodes and labels

## Goal
The Graph tab opens on an overview of the whole code graph (modules and their most-connected symbols) instead of an empty canvas, and nodes and labels render at a fixed, compact on-screen size at any zoom or neighbourhood size.

## Kind
implementation

## Context
Why: the user said the Graph tab is "missing the display of the whole graph and text and nodes are too big".

Verified facts:
- verified: `mnemo2/src/components/GraphView.svelte` draws only the selected symbol's 1- or 2-hop neighbourhood (`hood`, from `transport.neighbourhood(selected.id, depth)`); with nothing selected the canvas shows the "Nothing selected" empty state (around lines 455 and 525). The left list shows search results and `graph_top` (most-connected symbols).
- verified: nodes are `<circle r={radii[node.id] ?? 6}>` with a `<text>` label at `y = r + 12` and `.graph-node text { font-size: var(--text-meta) }` (line ~654) inside an SVG whose viewBox fits the layout, so a small neighbourhood is scaled up and its circles and text grow with it; zoom buttons call `zoomBy` / `resetView`.
- verified: the backend can already return a whole-graph slice: `GraphView::slice` (`src/codegraph/query.rs` line 382) with no `from_symbol` takes every symbol, applies name/kind filters and caps at `GRAPH_SLICE_CAP` most-connected (degree-ranked), returning nodes plus the edges among them.
- verified: Mnemo2's graph commands are in `src-tauri/src/mnemo2/graph.rs` and registered in `src-tauri/src/mnemo2/mod.rs` (`graph::graph_status` … `graph::graph_context`).

Decisions:
- Overview first: with nothing selected the canvas shows the whole graph. Default to a module overview (one node per file or directory, sized by symbol count, edges aggregated from the symbol edges between them, with counts) and offer a toggle to "Top symbols" (the capped most-connected symbol slice). Clicking a module drills into its symbols; clicking a symbol selects it (the existing neighbourhood view). Choose the aggregation level that stays readable for this repository (about 2-3k files) — e.g. directories at depth 2-3 — and say why.
- New backend command `graph_overview(level, limit)` in a NEW file `src-tauri/src/mnemo2/graph_overview.rs` (registered in `mod.rs` directly after `graph::graph_context`), built on `CodeGraph::view()`; do not edit `src-tauri/src/mnemo2/graph.rs` — another plan is fixing a bug there right now. Frontend transport in `mnemo2/src/lib/graph.ts`.
- Compact rendering: nodes and labels keep a constant on-screen size (counter-scale by the current zoom, or lay out in screen pixels instead of viewBox units): node radius 3-7px by degree, labels at `--text-meta` (10px) and shown only for the selected node, its direct neighbours, hovered nodes and the largest nodes at the current zoom (label collision avoidance or a degree threshold). Fit-to-view on load and on overview/neighbourhood switch.
- Keep the left list, details panel, kind filters and Two hops toggle working.
- Preview: extend the existing `graph` preview scene in `mnemo2/src/test/previewScenes.ts` (in place — do not add a new scene) with seeded overview data through the existing graph seed seam in `mnemo2/src/lib/graph.ts`.

Verification: `cargo test --manifest-path src-tauri/Cargo.toml --features mnemo2 --lib mnemo2::graph_overview`, `cargo clippy --manifest-path src-tauri/Cargo.toml --features mnemo2 --lib --tests --bins -- -D warnings`; in `mnemo2/`: `npm run check`, `npm run check:no-mock`, `npx vitest run`. Never start a dev server or any command that does not exit on its own; the lead renders the preview.

## Acceptance scenarios
- Opening the Graph tab with nothing selected shows an overview of the whole code graph (modules with aggregated edges), with a toggle to the top symbols.
- Nodes and labels stay small (about 10px text) whether the view shows 5 nodes or 300, and labels do not pile on top of each other.
- Clicking a module drills into its symbols; clicking a symbol shows its neighbourhood and details as before.
