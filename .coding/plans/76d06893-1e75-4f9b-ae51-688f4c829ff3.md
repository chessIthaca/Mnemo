# Plan: CodeGraph — GitNexus-style per-project knowledge graph (engine + agent tools + Graph tab)

## Goal
A GitNexus-inspired code knowledge graph for myharness: on project startup, tree-sitter parses the codebase into symbols + edges stored in a per-project SQLite DB (.coding/codegraph.db, gitignored), kept incrementally up to date. Expose it two ways: read-only graph_* agent tools (search / 360° context / blast-radius impact / shortest path) so the agent gets complete structural context in one call, and an interactive right-panel Graph tab (d3-force explorer) over new IPC commands.

## Kind
implementation

## Context
User loves GitNexus (github.com/abhigyanpatwari/GitNexus — tree-sitter → knowledge graph → smart MCP tools; core value: precomputed relational intelligence = complete context in one query instead of grep chains). Chose "Both in one plan": engine → agent tools → visual explorer. Fit confirmed in-repo: per-project .coding/ (Project::from_root), rusqlite bundled SQLite + fastembed infra, factory tool registration (register_memory_tools pattern, src/agent/factory.rs:648), right-panel view registry (frontend/src/hooks/rightPanelViews.tsx — one-place tab add; RightPanelTab union + ALL_RIGHT_PANEL_TABS in agentState.ts with rightPanelViews.test.ts sync test), search tool ignore-list (src/tool/agent/search.rs IGNORED_DIRS + should_search, reusable via pub(crate)). Deps to add: tree-sitter + grammars (rust, typescript/tsx) in root Cargo.toml; d3-force in frontend/package.json. .gitignore needs .coding/codegraph.db* entries (derivable cache). IMPORTANT constraints: #![deny(warnings)] both crates — warning-free; all public fns need doc comments; regression test per defect; cargo test before each step completes; commit to feature branch feat/codegraph (never main); build brain must not block startup (index in background task, failures degrade to "graph unavailable", never fatal). Codebase languages to support first: Rust + TS/TSX (this repo's own languages) — grammar set chosen so the tool dogfoods on itself.

## Steps
- [x] 1. **Branch + tree-sitter deps + file walker** — Create branch feat/codegraph from main. Add to root Cargo.toml: tree-sitter = "0.25", tree-sitter-rust, tree-sitter-typescript (latest compatible pins). Create src/codegraph/walk.rs: pub(crate) walk_project(root) -> Vec<PathBuf> reusing src/tool/agent/search.rs IGNORED_DIRS + should_search (make them pub(crate) exports shared, not duplicated), plus an extension→Language map (rs→Rust, ts/tsx→TypeScript; tsx vs ts via extension). Unit tests: fixture tree with target/, node_modules/, .git skipped; extension mapping correct.
- [x] 2. **Symbol/edge extractor** — Create src/codegraph/extract.rs. Define pub structs Symbol { id, name, kind (function/method/struct/enum/trait/impl/class/interface/module), file, start_line, end_line } and Edge { from_symbol, to_symbol, kind (calls/imports/contains/references) } (all serde Serialize+Deserialize). Parse via tree-sitter queries per language: Rust (fn/struct/enum/trait/impl + method fns, call expressions, use declarations), TS/TSX (function/class/interface/method, imports, calls, new-expressions). Return Vec<Symbol> + Vec<Edge>; edges resolve name→symbol-id within file scope first then project-wide best-effort (unresolved names dropped with a counter). Unit tests on embedded Rust + TSX source strings: symbols extracted with correct kinds + line ranges; call edge fn_a→fn_b; import edge module→symbol.
- [x] 3. **SQLite graph store + incremental upsert** — Create src/codegraph/store.rs + src/codegraph/schema.rs (mirror src/memory's schema pattern: apply_pragmas WAL, apply_schema idempotent, migrate_add_column_if_missing). Tables: cg_files(path PK, content_hash, mtime, indexed_at), cg_symbols(id PK, name, kind, file, start_line, end_line; index on name), cg_edges(from_id, to_id, kind; index both directions). Store::open(path) / open_in_memory(); upsert_file(path, hash, symbols, edges) deletes the file's old rows in one tx; remove_file; stats() (files, symbols, edges, last_indexed_at); prune_missing(present_paths). Append .coding/codegraph.db, .coding/codegraph.db-wal, .coding/codegraph.db-shm to .gitignore. Unit tests with in-memory + on-disk temp DB: upsert→stats, re-upsert replaces (no dupes), remove_file cascades orphan edges, prune_missing clears stale.
- [x] 4. **Query engine (the relational intelligence)** — Create src/codegraph/query.rs: resolve(name) -> Vec<Symbol> (exact then case-insensitive substring, capped 20); context(symbol_id) -> definition + grouped incoming/outgoing edges by kind + neighbor summaries (GitNexus's 360° view); impact(symbol_id, max_depth) -> reverse transitive closure (who breaks if this changes) with per-depth grouping + visited-set cycle guard; path(from_id, to_id) -> BFS shortest directed path with edge kinds. All return serde_json-friendly structs. Unit tests on a synthetic store: diamond dependency impact depth grouping, cycle A→B→A terminates, BFS finds shortest not first, unknown name → empty not error.
- [x] 5. **Indexer + non-blocking startup hook** — Create src/codegraph/mod.rs (pub mod walk/extract/store/query; pub struct CodeGraph { store, root } with Arc<CodeGraph> + interior Mutex<Connection> like MemoryStore). CodeGraph::index(root, store, [progress cb]) walks, hashes files (cheap xxhash-style: use std DefaultHasher on bytes), re-parses only changed/new files, prunes removed; returns IndexStats { files_scanned, files_reindexed, symbols, edges, elapsed }. In src-tauri/src/main.rs build_brain: open .coding/codegraph.db, spawn background task (tauri::async_runtime::spawn) running index; store Arc<CodeGraph> in Brain + factory via new with_codegraph(Arc<CodeGraph>) builder (src/agent/factory.rs) + expose from IpcState (src-tauri/src/ipc/state.rs runtime context). Failure at any point = eprintln! + graph disabled, NEVER fatal to startup. Re-index trigger: config.toml [general] codegraph = true default true (add to GeneralConfig with serde default). Unit tests: index a fixture dir twice — second run re-parses 0 files; edit one file — exactly 1 re-indexed.
- [x] 6. **graph_* agent tools (read-only, AutoRun)** — Create src/tool/agent/codegraph.rs: GraphSearchTool (name→matching symbols w/ file+line), GraphContextTool (symbol_id or name→360° view), GraphImpactTool (name→blast radius grouped by depth), GraphPathTool (from,to→shortest path). Pattern: read-only like search tool (SafetyLevel::AutoRun, ToolCategory::Codegraph), clear JSON output with paths relative to project root. Register via new register_codegraph_tools in factory (register_memory_tools pattern — omitted when no graph wired). Update any tool-count/doc tests that enumerate the registry. Unit tests: execute against a CodeGraph over a fixture dir; unknown symbol returns helpful empty-result JSON not error; impact includes transitive depth.
- [x] 7. **IPC commands** — Create src-tauri/src/ipc/codegraph_cmds.rs: codegraph_status() -> { available, files, symbols, edges, last_indexed_at, indexing: bool }, codegraph_refresh() -> triggers re-index async (returns immediately, status reflects indexing), codegraph_graph(filter?) -> { nodes: Symbol[], edges: Edge[] } capped (top-N by degree when filter omitted, N≈300; optional name/kind/depth-from-symbol filters for focused neighborhoods). Unit tests where feasible (pure filter/cap logic), smoke via cargo build --manifest-path src-tauri/Cargo.toml.
