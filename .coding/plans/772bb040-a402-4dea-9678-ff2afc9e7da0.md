# Plan: Window title shows product name + loaded project folder

## Goal
Set the app window title at startup to show the product name and the loaded project's folder name (e.g. "myharness — myHarness").

## Context
The window title is currently a static "myharness" set in tauri.conf.json. The user wants it to show both the product name and the loaded project's current directory. main.rs resolves the project root at startup (--project flag or current_dir()), available in the setup closure's brain_result (Ok branch: brain.project.root; Err branch: cwd). The window defaults to label "main" in Tauri 2. The fix is localized to main.rs: after resolving the root in the setup closure, set the main window's title to "{product} — {folder_name}" using the last path component of the root.

## Steps
- [x] 1. **Set window title to product + project folder in main.rs setup** — In `src-tauri/src/main.rs`, in the `.setup(|app| { ... })` closure, after the `brain_result` is resolved and the project root is known (both the Ok branch's `brain.project.root` and the Err branch's `cwd`), call `app.get_webview_window("main").expect("main window").set_title(&format!("myharness — {}", root.file_name().and_then(|n| n.to_str()).unwrap_or(".")))` to update the OS window title. Place a single helper call that works for both branches: compute the root PathBuf once (from brain_result Ok → block_on project.root.clone, or Err → cwd), then set the title before the match. Use the folder name (last path component) for brevity. Add a doc comment noting the title reflects the loaded project so the user can tell which project is open at a glance. Keep tauri.conf.json's static title as the initial/fallback (shown before setup runs).
