# Plan: Console mode: -console REPL with /model + /reasoning

## Goal
A `-console` startup flag that runs the full agent brain as a terminal REPL exposing /model + /reasoning (StatusBar set_model semantics), with the headless core (ConsoleRuntime) cleanly separated from the interactive frontend so a future daemon can reuse it.

## Kind
implementation

## Context
Task (backlog, unattended): add a `-console` command-line mode to the myharness Tauri app that replicates ONLY the /model and /reasoning UI affordances (the StatusBar live picker, i.e. the `set_model` IPC command semantics) as a shell/REPL, architected for future headless-agent operation.

Exploration findings:
- src-tauri is a pure binary crate (main.rs + mod ipc). `build_brain() -> BrainOutcome{Ready(Brain)|NeedsProject(Config)}` in main.rs is AppHandle-free and builds config/trace/provider/sandbox/memory/constitution/safety/resolver/browser/codegraph/factory. It resolves project via pending marker → `--project` flag → cwd walk (console inherits this for free).
- `ipc::spawn::spawn_agent_shared(factory, manager, agent_loops, name, initial_prompt, parent, model, role, own_plans_dir)` is the shared spawn path (main agent too); only Tauri coupling is `tauri::async_runtime::spawn` (a global lazy runtime — works without a Tauri app).
- `IpcSpawner` (implements AgentSpawner/ParentAwareSpawner/DescendantTracker) holds an AppHandle ONLY to emit the UI-only `PromptDispatched` event — a console spawner can skip that. Wired in main.rs setup — confirm exact factory setter name during step 1.
- `ipc::agent.rs set_model` (:413): validates endpoint exists + model ∈ ep.models (or == general.default_model), maps reasoning effort (`!supports_reasoning_effort` → None; "off" → None; None → ep.effective_reasoning_effort() default "max"), builds via `build_openai_client(&config, ep, &model, ep.multimodal, effort, Some(trace))`, then `factory.context_manager_for(provider)` + `ipc::config_io::swap_live_provider(&state, &app, ...)` which does factory.set_provider + per-loop set_provider/set_resolved_model(None) + ModelChanged emits. NOT persisted to config (live swap only — matching StatusBar).
- `AgentEvent` (src/runtime/channels.rs): ApprovalRequest/UserQuestion carry oneshot responders inline — console resolves them directly; Approval = Approve/Deny/DenyAll; UserAnswer = Choice{index}|Freeform{text}.
- main.rs:6 `#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]` — release GUI subsystem; console mode needs AttachConsole(ATTACH_PARENT_PROCESS) via raw kernel32 FFI (no new dep) before first output; debug builds have a console natively.
- Repo conventions: `#![deny(warnings)]`, doc comments on ALL pub fns, regression test per defect, PowerShell unpiped cargo test + $LASTEXITCODE, root cargo test does NOT compile src-tauri (run both), frontend vitest node-env (no frontend changes expected but run suite).

DESIGN DECISIONS (documented for the user):
1. `-console` / `--console` checked in main() BEFORE WebView2 env + Tauri builder; console path never initializes Tauri.
2. Layered seam: `console.rs` = ConsoleRuntime (AppHandle-free headless core: brain + manager + agent_loops + fanin_rx + typed ops) + REPL frontend (stdin/stdout, slash commands, interactive approvals). A future headless daemon reuses ConsoleRuntime with a different frontend.
3. /model + /reasoning replicate set_model semantics EXACTLY by extracting the shared logic into `ipc::config_io`: `resolve_model_provider()` (validation + effort mapping + build_openai_client) + `swap_provider_into_loops()` (factory + per-loop swap, returns agent ids). IPC set_model and console both call them — zero drift. ModelChanged emission stays IPC-side (console prints).
4. ConsoleSpawner implements the spawn traits without an AppHandle (no PromptDispatched — UI-only).
5. REPL: plain text = prompt; `/model` lists endpoints+models, `/model <endpoint>/<model>` or `/model <model>` swaps; `/reasoning` shows value (respecting supports_reasoning_effort), `/reasoning <max|high|medium|low|minimal|off>` swaps keeping current model; `/help`; `/exit`. Approvals: y/n/a(ll) on stdin; UserQuestion: numbered options or freeform text — sequential, one pending at a time (matches GUI contract).
6. stdin owned by ONE spawn_blocking reader → mpsc; main loop tokio::select! over fanin_rx + input_rx.
7. NeedsProject/Err in console → clear message + exit code 1. Teardown: Cancel main agent, bounded wait for Exited, bounded browser close (mirror RunEvent::Exit), then exit.
8. tokio: plain `tokio::runtime::Runtime::new().block_on()` in the console entry; nested use of tauri::async_runtime via spawn_agent_shared is fine (global runtime).
