# Plan: Auto-delegate symbol and memory searches inside search/search_read

## Goal
When `search`/`search_read` detects a symbol-shaped query the code graph can answer, or a query targeting semantic memory (.coding/knowledge|reviews globs, typed SPEC:/DECISION:/... prefixes), execute the graph/memory lookup inside the tool and return the answer inline — skipping the file walk — with an AUTO-DELEGATED marker, the steering marker kept coherent, and a one-repeat escape hatch back to plain search.

## Kind
implementation

## Context
Detection already exists: symbol_nudge (search.rs:583) + alternation_nudge (:529) recognize symbol hunts but only emit an advisory note; known_memory_note (:924) is the memory precedent; search_read.rs shares the helpers. Graph internals: run_query/resolve_id (codegraph.rs:48/70, private) + GraphView::context (query.rs:230). Memory: store.recall(q, &MemoryFilter) (retrieval.rs:212). Steering contract: SEARCH_NUDGE_MARK "is an indexed symbol" (steering_stats.rs:266) is detected on the FIRST line of search/search_read output — the delegated block must carry it. Tools are &self behind Arc → escape-hatch state needs Arc<Mutex<Option<Key>>>. Decisions: sticky escape key (until a different query delegates); delegated block carries the steering marker; memory detection conservative (knowledge/reviews globs or typed prefixes only); KnownMemoryHit metric stays uuid-only.
