# Plan: Clickable model picker in the status bar

## Goal
Make the model name in the status bar clickable, opening a dropdown of every configured model (from endpoints.toml), and switching the active model rebuilds the LLM provider at runtime so all agents use it on their next turn.

## Context
The StatusBar (frontend/src/components/layout/StatusBar.tsx:139) shows the model as plain text from the store. Configured models live in endpoints.toml (Vec<Endpoint> with name, kind, base_url, models, max_context, max_output_tokens, multimodal), loaded into IpcState.config. The provider is Arc<dyn LlmClient> inside AgentLoop (provider field) and AgentLoopFactory (provider field) — both need to become swappable (RwLock). The ContextManager depends on the new provider's max_context, so it must be rebuilt on switch (needs fill_rate stored). The API key resolution logic lives in build_brain (src-tauri/src/main.rs:219-224). get_config already returns endpoints with their models.

## Steps
- [x] 1. Add provider/context_manager setters to AgentLoop (swap behind RwLock) and make the factory's provider + context_manager mutable via RwLock, storing the fill_rate so a new ContextManager can be built on switch.
- [x] 2. Add a set_model Tauri command (+ list endpoint/models payload helper) that resolves the endpoint + api key for the chosen model, rebuilds the OpenAiClient, and swaps it into the factory and every live agent loop. Register it in main.rs.
- [x] 3. Frontend: fetch the endpoints/models list (typed getConfig), add a clickable dropdown on the model label in StatusBar listing every endpoint/model pair, call setModel on select, and update the store's model/provider.
- [x] 4. Run cargo test (and a frontend typecheck/build) to verify nothing is broken.
