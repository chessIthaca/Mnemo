# Plan: Fix CodeBlock line-overlap bug

## Goal
Fix the CodeBlock line-overlap bug: keep .hljs box styles on the block <pre> only, never on the inline <code> element.

## Context
rehype-highlight unshifts `hljs` onto the code element's className, so CodeBlock's inner `<code>` gets "hljs language-toml". The .hljs CSS rule (background + padding: 1em !important) then applies to an inline element: inline vertical padding doesn't grow line boxes, but the background paints over the padding area, so lines overlap and the last line's background obscures text. Same bug affects MdViewer.tsx, which renders `<code class="hljs">` via the default ReactMarkdown code renderer. ConfigDialog.tsx already documents the pitfall (avoids `hljs` on pre).

## Steps
- [x] 1. Fix CodeBlock in frontend/src/components/chat/Message.tsx: extract only the language-* class for the inner <code> (also fixes the 'hljs toml' label) and drop the hljs class from it
- [x] 2. Scope the .hljs box styles to pre.hljs in frontend/src/styles/globals.css so inline code never gets background/padding (fixes MdViewer path too)
- [x] 3. Verify: npm run build (tsc + vite) for the frontend and cargo test per constitution
