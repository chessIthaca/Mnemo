# Plan: Fix inflated session tok/sec (avg-time → total-time)

## Goal
Fix aggregate tok/sec to use total time (tokens / total_ms) instead of average per-request time, across InflightBar + StatsView, via a shared pure helper.

## Kind
implementation

## Context
Session/aggregate tok/sec is inflated by N× because it divides total tokens by the AVERAGE per-request time (generation_ms_total / timed_requests) instead of the TOTAL time (generation_ms_total). Substituting: rate = tokens × timed_requests × 1000 / ms_total, but the correct aggregate throughput is tokens × 1000 / ms_total. With 1 request it's accidentally right; it diverges as the session grows. Bug is in 5 sites: InflightBar.tsx (1) + StatsView.tsx (4: ModelTable per-model, ModelTable totals, SessionCard, ProjectCard). The per-request rate in reduceUsage (agentEventReducer.ts:345-348) is CORRECT (single request's ttft/gen) — no change there. An existing test (useAgentStore.test.ts:457-460) encodes the buggy formula and asserts 400 (should be 200). tsconfig has noUnusedLocals:false so dead locals won't fail the build, but I'll remove the dead avgTtft/avgGen in ProjectCard (not used in tooltips there, unlike SessionCard/InflightBar which DO use them in tooltips).
