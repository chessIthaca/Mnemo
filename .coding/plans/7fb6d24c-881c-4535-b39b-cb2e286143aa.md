# Plan: Hang watchdog + main-thread blocking audit (AppHangB1 follow-up)

## Goal
Add a hang watchdog that detects main-thread stalls >10 s and writes an evidence report (.coding/logs/hang-<ts>.txt) on the next hang, audit all main-thread code paths for blocking work, and fix any offenders found.

## Kind
implementation

## Context
Follow-up to the crash diagnosis (plan 234a0219, report .coding/reviews/2026-08-20-research-crash-diagnosis.md): the app's "crashes" are Windows AppHangB1 UI hangs (mnemo-app.exe stopped responding; 3x on 2026-08-20 with identical hang signature 6978). WER captured no stack; the app has no hang instrumentation — that gap must be closed, and the user wants a main-thread blocking audit ("find where we are running things in the main thread when we shouldn't"). Recon findings: no run_on_main_thread call sites; on_window_event (main.rs:222) only submits to the resize worker (R1 fix intact); RunEvent::Exit teardown is timeout-bounded (main.rs:744). The one substantive main-thread path is setup's build_brain() (main.rs:174-233+): sync config load, project resolution, MemoryStore::open (SQLite), provider/factory build, CodeGraph watcher start — startup-only, unmeasured. windows-sys 0.59 already in workspace deps (root Cargo.toml:77, features incl. Win32_System_Threading). The agent-event forwarder lives in src-tauri/src/ipc/events.rs (spawn at :179, forward at :823). Watchdog design: cross-platform core (main-thread heartbeat via app.run_on_main_thread ping every 500 ms + detector std::thread + 10 s stall threshold + once-per-episode report file hang-<ts>.txt in .coding/logs with activity ring fed by the forwarder); cfg(windows) enrichment only (GetThreadTimes busy-vs-blocked + wait chain), graceful degradation elsewhere — multi-platform neutrality preserved because the core + report format are platform-neutral and tested, only capture enrichment is gated.

Extract pure logic into testable types: `ActivityRing` (cap+eviction) and `StallTracker` (staleness + once-per-episode transitions) with unit tests (ring cap eviction order; stale->fired once; re-arm on heartbeat; report formatting from injected state).
