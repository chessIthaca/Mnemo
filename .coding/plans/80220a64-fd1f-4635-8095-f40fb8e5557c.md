# Plan: Auto-approve-project safety mode + 3-option toolbar + allow-for-project button

## Goal
Add a new "Auto Approve Project" safety mode that auto-approves tool calls whose file paths stay inside the project directory, and rework the toolbar safety toggle into a 3-option dropdown (Approve Each, Auto Approve Project, Unsafe) with the warning dialog kept for the Unsafe option. Also add an "Allow for project" button to the per-action approval prompt when the call only touches project files.

## Context


## Steps
- [x] 1. Add a new SafetyMode variant `AutoApproveProject` to src/config/general.rs (between AutoReadApproveWrites and Autonomous). Update the serde/clap rename_all (kebab-case → "auto-approve-project"). Update the Default impl to keep ApproveEachAction. Update the config test `parses_full_config` if needed (it uses auto-read-approve-writes, which still exists). Add a roundtrip test for the new variant.
- [x] 2. Add a `project_scoped` predicate to the approval module (src/agent/approval.rs) — a function `is_project_scoped(tool_name: &str, args: &Value, sandbox: &Sandbox) -> bool` that returns true when the tool call only accesses files inside the project directory. For file_edit/file_write/file_append/file_read: validate the `path` arg through the sandbox (success = inside). For search: always true (it walks the project tree only). Keep AutoReadApproveWrites as-is (== ApproveEachAction). Update the signature + all call sites (src/agent/mod.rs execute_tool_call). Update existing approval tests.

Clicking opens a small dropdown (like the plan step picker). Selecting Unsafe opens the existing SafetyToggleDialog (warning) before switching; the other two switch immediately. Update the button label/icon/color per mode. Keep the SafetyToggleDialog for Unsafe only.
