# Plan: Deferred checkbox — exclude backlog items from Run-All

## Goal
A `deferred` flag on backlog items, ORTHOGONAL to BacklogStatus: a deferred item stays pending + visible in the Backlog tab but Run-All never selects, adopts, or counts it — when only deferred items remain the run ends cleanly via the existing end_run path ('no eligible items', no spin, no error). Manual dispatch (per-card ▶) and auto-feed still see deferred items (only Run-All selection skips). Toggle from the UI (checkbox beside the status chip + a visible DEFERRED badge, persisting immediately) and from agent sessions (a `deferred` arg on the `backlog_status` tool, so a run-all session can park an item it cannot resolve instead of failing it). Old backlog.jsonl lines without the field parse unchanged; the field round-trips through the git union merge.
