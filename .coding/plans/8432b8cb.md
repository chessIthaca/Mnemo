# Plan: Ruleset-aware run-all landing — PR path on protected mains

## Goal
Make the app-managed run-all landing ruleset-aware: on a repo whose main is protected by an ACTIVE pull_request ruleset (this repo: 23755694), the landing must NOT merge into local main — instead push the worktree branch and open a PR (gh pr create --base main --head <branch>), report the PR URL on the item, and keep the branch for the human merge (worktree removed, branch kept). Repos without the ruleset keep the direct local-merge landing unchanged. Never bypass the ruleset (no force-push, no admin override, no ruleset edits).

## Kind
implementation
