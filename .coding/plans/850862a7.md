# Plan: Tool-card timing: duration + wall-clock next to the check

## Goal
Show each tool card's timing next to the success check — the call's elapsed duration and its wall-clock start time — so the user can see how long each tool took and how much time passed between tools, without hovering.

## Kind
implementation
