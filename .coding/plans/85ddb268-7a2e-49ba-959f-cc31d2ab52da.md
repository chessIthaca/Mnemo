# Plan: Add convert_line_endings tool (CRLF↔LF without shell)

## Goal
Add a `convert_line_endings` agent tool that converts a file's line endings to LF or CRLF in-place (with before/after counts), so the agent doesn't need shell invocation to fix line endings.

## Kind
implementation

## Context
Tool pattern (from file_append.rs): struct with Sandbox, Tool trait impl (name/category/schema/safety/execute), blocking work in tokio::task::spawn_blocking, sandbox.validate_for_write() for path safety (refuses .coding bookkeeping), serde_json args struct. Existing helpers in src/tool/agent/line_endings.rs: normalize_line_endings(s, le) collapses lone \r + converts; detect_line_ending(content) majority-votes. Integration points found: src/tool/agent/mod.rs (pub mod + doc list), src/agent/factory.rs (use stmt ~line 49, register in register_agent_tools ~line 539, expected-name test at ~line 1146), src/agent/approval.rs is_project_scoped (line 120 file-tool match arm), src/safety_rules.rs key_argument (line 417), src/agent/turn.rs is_durable_tool (line 1568). Frontend/docs have no per-tool references to file tools.
