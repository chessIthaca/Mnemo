# Plan: Dashboard: live-update while the tab is open (no close/reopen)

## Goal
Make the token Dashboard refresh itself while it is open: a mount-scoped 2 s poll (the PlanProgress idiom) plus an immediate refresh on window focus / visibility change, an in-flight guard against overlapping IPC, and ticks skipped while the document is hidden — so newly written savings_events rows appear without closing and reopening the tab.

## Kind
implementation

## Context
USER REPORT (2027-01-25): "the token dashboard should automatically update when open. right now I have to close and reopen to see updates."
