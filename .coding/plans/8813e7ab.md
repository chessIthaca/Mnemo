# Plan: Human-friendly tool-card labels — one human headline per run, raw tool names on expand

## Goal
Every chat tool card shows a human sentence for the call while collapsed (e.g. "Searching for \"WorkflowState\"", "Editing files", "Running tests"), and a RUN of consecutive calls — including different tools — bundles into ONE card whose headline summarizes the run ("Searching for \"WorkflowState\" and editing 2 files"). The raw tool name (search, file_edit, shell, …) renders only in the expanded detail, per call, which also carries the clickable path/URL/markdown chips and the call's args/results. Covers every registered tool with a graceful fallback for unknown/MCP names; approval surfaces keep raw names.
