# Plan: Diff tab: changed-files dropdown per top-level plan

## Goal
Add a dropdown to the right-panel Diff tab listing every file changed (file_edit/file_write/file_append) during the current top-level plan, letting the user browse each captured diff. The list resets automatically when a new top-level plan starts.

## Kind
implementation

## Context
Verified this session: (1) The Diff tab is frontend/src/components/views/DiffViewer.tsx — renders a pending-approval diff, else a single global lastDiff from useAgentStore. (2) lastDiff is captured in reduceToolResult (frontend/src/hooks/agentEventReducer.ts:219-307) for file_edit/file_write only; effects flow through applyAgentEvent → Effects. (3) Plans are a stack in src/workflow/mod.rs (stack: Vec<PlanFrame>, root = index 0); Workflow has plan_id()/plan_depth() but no root-plan accessor. (4) AgentEvent::WorkflowStateChanged(WorkflowState) (src/runtime/channels.rs:120, serde variant :249, mapping :384) is emitted ONLY in src/agent/turn.rs:878-893 after workflow tools (create_plan/update_plan/complete_step/abandon_plan/skill_*), carrying just the state — the frontend cannot distinguish a new top plan from sub-plan push/pop today. (5) Sub-plans keep the root plan on the stack, so carrying the ROOT plan id lets the frontend reset exactly when a new top-level plan starts (id changes), with no reset on sub-plan push/pop or skill transitions. (6) Golden fixture tests: tests/contract_fixtures.rs asserts exact JSON equality with frontend/src/lib/ipc-fixtures/event-workflow-state-changed.json (update by hand); tests/ipc_bridge.rs:117 constructs the variant; vitest store tests are table-driven (frontend/src/hooks/useAgentStore.test.ts) with a resetStore() seeding helper; frontend/src/lib/ipc-contract.test.ts dispatches the fixtures. (7) selectMainAgentId(s.agentParents, s.agents) identifies the main agent in the frontend. (8) No @testing-library/react — reducer/store tests are the pattern, not component tests. (9) On main with a clean tree — the closing commit must go to a NEW feature branch (constitution). Windows + PowerShell shell; run cargo test unpiped and check test-result lines / $LASTEXITCODE.
