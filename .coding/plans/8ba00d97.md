# Plan: Plan steps: headline + collapsible details (plan window) + headline-only executing popup

## Goal
Make the implicit headline/details split real in the UI: PlanProgress step rows show a compact headline with a rotating-chevron collapsible details block (default collapsed, active step auto-expands, auto-collapses when it completes), and the StatusBar executing popup shows only the current step's headline as a single CSS-truncated line — never the recipe body. Display-layer only: the stored `**Header** — body` format, the plan file, the model's plan rider, and the IPC payload stay untouched.
