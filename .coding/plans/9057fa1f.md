# Plan: Deterministic Complete→Planning on run-all backlog dispatch

## Goal
When run-all dispatches a backlog item to the main agent resting in Complete, deterministically transition the workflow to Planning before the Prompt runs (immediate UI feedback, STATE_PLANNING guidance instead of Complete+hope), steer defect-shaped items to kind:"bug_fixing" in the preamble, and preserve the plan-loop gate semantics (the pre-turn transition never counts as loop_evidence).

implementation

## Context
User report: pushing a backlog item into a Complete-state agent should move it to Planning immediately; today everything is advisory text. Scope chosen (ask_user): run-all dispatch only — chat prompts keep the existing PLAN_NUDGE heuristic. Research done: (1) src-tauri/src/ipc/run_all.rs — run_all_dispatch_next (line 372): next_pending → busy guard → git checkpoint (rollback safety) → InFlight transition → re-check busy under manager lock → ONE AgentCommand::Prompt at line ~500 carrying RUN_ALL_STEER preamble + item text (run_all_prompt). CRITICAL: a dispatch-time Complete→Planning transition must not be counted by that latch, else a freeform turn could fake-qualify as Done. (4) STATE_COMPLETE + append_plan_nudge (src/agent/prompt.rs) stay untouched. Frontend already renders workflow-state-changed events (plan progress window) — no frontend change expected.
