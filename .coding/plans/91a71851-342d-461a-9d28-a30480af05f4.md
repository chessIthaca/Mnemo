# Plan: Settings: memory cleanup + semantic-search rebuild with progress

## Goal
Two maintenance tools in the Settings dialog — "Clean up memory" (consolidate un-consolidated sessions, delete their raw working rows, VACUUM) and "Rebuild semantic search" (re-embed all memories with the active model, rebuild the FTS5 index, VACUUM) — each a button with a live progress bar, backed by new Tauri commands that stream progress events to the frontend.

## Kind
implementation

## Context
Exploration confirmed all machinery exists: (1) `MemoryStoreTrait::reembed_all` (src/memory/mod.rs:1034) re-embeds every row but has NO progress hook; (2) `consolidation::consolidate_session(store, session_id, Option<&dyn LlmClient>, corpus)` (src/memory/consolidation.rs:103) compresses working→episodic, extracts semantic/procedural with an LLM, and deletes the session's working rows; (3) `corpus_digest(plans_dir, reviews_dir)` builds the extraction corpus; (4) FTS5 is an external-content table `memories_fts` kept in sync by triggers — `INSERT INTO memories_fts(memories_fts) VALUES('rebuild')` is the proven rebuild (schema.rs:145); (5) `AgentLoop::session_id()` (src/agent/loop_impl.rs:692) exposes live sessions for a skip-list (cleanup must not consolidate a session still being written); (6) progress-event pattern: `embedder://status` emitted from a spawned task, consumed by `onEmbedderStatus` (frontend/src/lib/tauri.ts:450) driving a bar in EmbeddingSection.tsx:219-232; (7) Settings shell: sections in frontend/src/components/settings/ (types.ts SETTINGS_NAV + SettingsDialog.tsx render blocks + per-section files); (8) IpcState.runtime.memory_store: Option<Arc<MemoryStore>>, embedder_handle() exists (used at ipc/memory_debug.rs:152); memory_debug_overview already returns per-tier counts + fingerprint mismatch flag for the section header; (9) commands register in src-tauri/src/main.rs generate_handler (~line 510, memory_debug entries). Backend orchestration goes in a new myharness module (testable without Tauri), IPC layer just wires state + emits events.
