# Plan: Make ConfigDialog tabs scrollable

## Goal
Both tabs (Appearance and Endpoints) in the Settings/ConfigDialog overflow the screen with no scrollbar. Fix the flex/height chain so the tab content area scrolls and all content is reachable.

## Context
ConfigDialog is in frontend/src/components/layout/ConfigDialog.tsx. The dialog (DialogContent) uses `max-h-[90vh] flex flex-col overflow-hidden`. Its body div is `min-h-0 flex-1 overflow-hidden` (NOT a flex container). Inside, the Radix Tabs root has `flex h-full flex-col` — the `h-full` percentage height does not resolve because the parent body's height is indefinite (derived from `flex-1` under a `max-height`, not a fixed height). As a result the Tabs div grows to full content height, the body's `overflow-hidden` clips it, and the TabsContent's `overflow-y-auto` never constrains. Fix: establish a definite height at each level using flex-1 + min-h-0 (avoid percentage heights), make the body a flex column, and pin header/footer/tabslist with shrink-0 so only the TabsContent scrolls.
