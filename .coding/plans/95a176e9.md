# Plan: Mid-run model/reasoning changes land before the next call (+ honest tab label)

## Goal
Model and reasoning-effort changes made while a run is in flight must take effect on the immediately-next provider request of that same run (steer-like semantics — no restart, no extra turn), and the UI must be told when the change actually lands so the tab's model label (agentModels[id], driven by AgentEvent::ModelChanged) shows the newly-served model/effort. Must work in every workflow state (including Reviewing) and while streaming. CONSTRAINT: reviewer subagents keep the configured reviewing model — resolve_turn_provider's ordering (skill → pin → forced → subagent → state) is not to be reordered; only the fallback read + the emission change.
