# Plan: Add per-tab close (x) button to right-panel tool tabs

## Goal
Each enabled tool tab in the right panel gets a small "x" button that disables (toggles off) that tab. The tab can be re-enabled from the left toolbar, which already exists.

## Context
RightPanel.tsx renders Radix Tabs/TabsList/TabsTrigger for each enabled tool tab (filtered by disabledTabs). The store already has toggleTabAndReveal(tab) which disables a tab, falls back to the first enabled tab if the active one is disabled, and hides the panel when the last tool is turned off. Sidebar.tsx already re-enables tools via the same action. So the only change needed is a UI affordance inside each TabsTrigger.

Constraint: Radix TabsTrigger renders a <button>, so a nested <button> is invalid HTML. Use a <span role="button" tabIndex={0}> with onPointerDown + onClick + onKeyDown handlers that stopPropagation/preventDefault so the tab is disabled instead of selected. The X icon is already imported in RightPanel.tsx. Add `group` to the TabsTrigger className so the X can reveal on hover (group-hover:opacity-100).
