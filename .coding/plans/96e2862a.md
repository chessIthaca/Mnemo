# Plan: Run-all gate re-checks at the next resolution instead of halting on non-closures

## Goal
Make the run-all gate re-check at the next turn resolution instead of halting permanently: a non-closure or turn-failure resolution keeps the run armed (item in_flight, no dispatch) so the turn that later completes the plan resolves the item and the run continues — mirroring the existing stopped-run semantics (b83e891f) and the single-dispatch path's non-terminal non-closures.

## Bug
Run-all halts permanently when a dispatched item's turn ends without the plan loop closing — a turn abort (3 consecutive tool errors), a clean mid-plan turn end, or an unverifiable state. The agent routinely recovers on its own (auto-continue resumes mid-plan turn ends; reviewer-finish notifications resume the closing sequence) and the plan finishes cleanly, but the halted run never re-checks: the completing turn's resolution finds run_all == None, the item strands in_flight, and the next item never dispatches.
