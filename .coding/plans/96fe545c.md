# Plan: Make src-tauri/tauri.conf.json macOS-clean: rename the identifier off the `.app` suffix

## Goal
Remove the release-build warning that the bundle identifier ends with `.app` (which tauri flags as conflicting with the macOS application bundle extension) by renaming `identifier` in src-tauri/tauri.conf.json to `com.mnemo.desktop` and sweeping every live reference, keeping the Windows WebView2 per-instance UDF logic and both platforms' build surfaces coherent. No regression test: user directive 2027-01-16 — for this bug it is not possible.
