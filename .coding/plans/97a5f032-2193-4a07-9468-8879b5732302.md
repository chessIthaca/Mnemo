# Plan: Graph browse-to-source: shared editor + resizable bottom pane

## Goal
Graph tab: "Browse source" on a selected node replaces the bottom memory-log pane with the shared code editor (SourceEditor extracted from FileViewer), and the bottom area becomes drag-to-resizable with persisted height.

## Kind
implementation

## Context
Current GraphView (frontend/src/components/views/GraphView.tsx): selected-node side panel (w-52, "Focus neighborhood" button at line ~622) with node.file/start_line; bottom fixed MemoryAccessSection (max-h-32, rendered in both layout branches — review B1 keeps it visible when codegraph unavailable); no bottom resize. FileViewer (frontend/src/components/views/FileViewer.tsx, 649 lines) owns the editor: module-level editorSession cache (B1 dirty-survives-tab-switch, with direct session writes around unmount), content/savedContent/editing state, dirty guard, handleSave (normalizeForSave, browsed-no-save), mdEdit toolbar (TOOLBAR_BUTTONS) + split preview, code-fence path via Markdown/CodeBlock, binary placeholder, loadFile/openEntry/pendingFileOpen, tree splitter (h-1.5 handle, border-y hairlines). No FileViewer.test.ts exists; GraphView.test.ts (11 tests) pins pure helpers + source contracts. User wants: (1) "browse to it" on a selected graph node, (2) it REPLACES the bottom log window and shows the source code, (3) reusing the SAME editor as the files area, (4) bottom area resizable. Decisions: extract the whole content pane into shared SourceEditor (single source of truth, no duplication); SourceEditor always renders its own compact toolbar row (path + lang + dirty dot + Edit/Done + Save + optional ✕) so FileViewer's top header keeps only path + Browse + Refresh (Save/Edit relocate to the pane toolbar — minor visual change, avoids duplicated controls); session-cache persistence is opt-in via persistSession prop (FileViewer only — GraphView's peek view is ephemeral, two live sessions must not fight over one cache); revealLine scrolls by measuring per-line height from the rendered pre (approximate but deterministic); bottom height persisted to localStorage like other panes; splitter reuses the hairline motif (border-y border-border + grip pill) shipped earlier today. Dogfooding create_plan's new branch param (feat/graph-browse-source) — this is its first real use.
