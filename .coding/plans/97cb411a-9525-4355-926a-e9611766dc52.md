# Plan: About dialog with dependency credits + licenses

## Goal
Add an About dialog, opened by clicking the app logo (Code2 icon, top-left of the Sidebar), that credits all direct dependencies and lists each one's license with a link to show it.

## Kind
implementation

## Context
Pure-frontend feature. Dependencies reviewed across 3 manifests: root Cargo.toml (lib: tokio, serde, rusqlite, fastembed, chromiumoxide, reqwest, etc.), src-tauri/Cargo.toml (tauri, tauri-plugin-shell/dialog, log), frontend/package.json (react, radix-ui, lucide-react, zustand, react-markdown, vite, vitest, tailwindcss, etc.). App = myharness v0.1.0, MIT license. The "app icon" = the existing Code2 logo at the top-left of Sidebar.tsx (lines 32-34) — user chose to make it clickable. Dialog pattern: Radix Dialog via frontend/src/components/ui/dialog.tsx (Dialog/DialogContent/DialogTitle/DialogDescription); SafetyToggleDialog.tsx is the small-dialog template. External links: shell:allow-open is granted in capabilities/default.json; @tauri-apps/plugin-shell is already a frontend dep but not yet imported anywhere — use its open() to launch license/registry URLs in the system browser (CSP default-src 'self' blocks <a target=_blank>). App version available via getVersion() from @tauri-apps/api/app (core:app:default includes allow-version). No backend command needed. Build/test: cd frontend; npm run build (tsc+vite) + npx vitest run; cargo test unaffected but run per rules.

## Steps
- [x] 1. **Create the dependencies data file** — Create `frontend/src/components/about/dependencies.ts`. Export a `DependencyEntry` type `{ name: string; license: string; registry: string; licenseUrl: string }` and a `DependencyGroup` type `{ title: string; entries: DependencyEntry[] }`. Export a `DEPENDENCY_GROUPS: DependencyGroup[]` array with four groups, each entry carrying the SPDX license label, a registry URL (crates.io/crates/<name> or npmjs.com/package/<name>), and a license-text URL (opensource.org/licenses/<ID>; for dual licenses like "MIT OR Apache-2.0" use opensource.org/licenses/MIT). - [x] 2. **Create the AboutDialog component** — Create `frontend/src/components/about/AboutDialog.tsx`. Export `AboutDialog({ open, onClose }: { open: boolean; onClose: () => void })`. Use `Dialog`/`DialogContent`/`DialogTitle`/`DialogDescription` from `../ui/dialog`. Import `open` from `@tauri-apps/plugin-shell` and `getVersion` from `@tauri-apps/api/app`. Add a local `openExternal(url: string)` helper (async, calls `await open(url)` in a try/catch logging errors) with a doc comment. On mount (when open), fetch the version via `getVersion()` into state (fall back to "0.1.0" on error). Layout: header row (Code2 icon in cyan + DialogTitle "About myharness" + version pill + close X button calling onClose); a short body line: "myharness is MIT-licensed. Built on these open-source projects:" with "MIT-licensed" as a link (openExternal(APP_LICENSE_URL)); then a scrollable (`overflow-y-auto max-h-[60vh]`) list rendering each `DEPENDENCY_GROUPS` group as a subheading (`text-xs font-semibold uppercase tracking-wide text-slate-500`) followed by rows. Each row: the dependency name as a link (openExternal(entry.registry), styled `text-cyan-400 hover:underline`) + a license badge (`text-[0.65rem] rounded bg-bg-tertiary px-1.5 py-0.5 text-slate-400`) that is itself a link (openExternal(entry.licenseUrl), `hover:text-cyan-400`). Use `onEscapeKeyDown`/`onInteractOutside` → onClose. DialogContent className mirrors SafetyToggleDialog: `mx-4 w-full max-w-lg rounded-lg border border-border bg-bg-secondary shadow-2xl`. Add a doc comment on the component. Footer: a muted line "Click a name or license to open its page in your browser." + a Close button.
- [x] 3. **Wire the About trigger into the Sidebar** — In `frontend/src/components/layout/Sidebar.tsx`: import `AboutDialog` from `../about/AboutDialog`. Change the top logo container (lines 32-34, the `div` with `Code2`) into a `<button type="button" onClick={() => setAboutOpen(true)} title="About myharness" className="flex h-10 w-10 items-center justify-center rounded-lg bg-bg-tertiary transition-colors hover:bg-bg-tertiary/70 focus:outline-none focus-visible:ring-2 focus-visible:ring-cyan-500">` wrapping the existing `<Code2 className="h-5 w-5 text-cyan-400" />`. Render `<AboutDialog open={aboutOpen} onClose={() => setAboutOpen(false)} />` at the bottom of the Sidebar return (next to the existing `<ConfigDialog>`). Keep everything else unchanged.
