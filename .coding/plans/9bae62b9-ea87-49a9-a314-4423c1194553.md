# Plan: Actionable invalid-args error for file_read/read_files tool mix-ups

## Goal
Make the invalid-args error of the read tools (file_read / read_files) actionable when a model mixes up the two tool shapes. The reported failure (backlog item 65): a model called `file_read` with `{"files": [{path, start_line, end_line}]}` and got only `invalid arguments: missing field 'path'` — technically true but useless: serde silently ignores the unknown `files` key and the message neither names the received keys nor hints that `read_files` (plural) takes a `files` array. No descriptor is missing (read_files is registered + visible, its schema documents files[].max_lines); the defect is the error message, which must let the model self-correct.
