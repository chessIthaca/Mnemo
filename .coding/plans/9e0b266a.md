## Context

Not a schema-knowledge gap — an ambiguity the DUAL INPUT FORMS expose: the advertised schema (src/tool/agent/read_files.rs:161-191) offers `files` (array) AND `path` (single-file shorthand) + top-level start_line/max_lines, with NO `required` array at all — two mutually-exclusive optional ways to say the same thing, so an empty object violates nothing the model can see. ROOT CAUSE ANCHORS: ReadFilesArgs { files: Vec<ReadSpec> } (no serde default — an empty call fails deserialization with missing field `files`, sanitized to "parameter 'files' is required"); the execute() path-shorthand lifting (:198-216, "absorbing the shape rather than erroring on it"); invalid_args_error's unused `hint` param (:75-103 — the recovery-rule vehicle); read_files_paths (src/agent/dispatch.rs:1284-1295) parses BOTH forms from raw args for steering (a read of path P clears P's drift state) — keeping the absorption means NO dispatch.rs change. read_files is NOT in STRICT_TOOLS (strict.rs:250 — read-only tools are excluded), so the advertised schema IS the wire schema on every endpoint and the budget test measures it raw. DESIGN DECISIONS: (1) collapse the ADVERTISED schema to files-only + required:["files"] (the model sees one unambiguous form; strict endpoints can then reject an empty call pre-flight) while KEEPING the execute() absorption of the unadvertised shorthand — graceful for harness steering, habit-shaped calls, and the code's own "the shape a model most naturally reaches for simply works" philosophy; the acceptance criteria's conditional (update read_files_paths + its tests) does NOT trigger. (2) The recovery rule rides the ERROR MESSAGE too (via invalid_args_error's hint param), not just the description — the model reads the error at retry time; the description note only helps before the first failure, and the circuit breaker only fires after two identical failures. (3) Backlog item 4 (merge read into search) DEFERRED — architectural, beyond the acceptance criteria; search_read's never-fumbled shape (one required plain-string pattern) is the design evidence for the files-only collapse instead.
