# Plan: Line-ending-agnostic file_write/file_append + constitution rule

## Goal
Make file_write and file_append line-ending-agnostic (normalize to the existing file's style, like file_edit already does), extract the shared helper, and add a constitution rule about preserving line endings.

## Context
Findings from reading src/tool/agent/{file_edit,file_write,file_append,file_read}.rs:

- file_edit.rs HAS line-ending normalization: detect_line_ending() (lines 70-81) + normalize_line_endings() (lines 83-96), used in prepare_edit_literal (lines 116-118) and prepare_edit_regex (lines 170-172). An LF old_string matches a CRLF file and vice versa; the file's own endings are preserved on write. Tested by crlf_file_matches_lf_old_string, lf_file_matches_crlf_old_string, crlf_file_preserves_crlf_after_edit, crlf_file_replace_all_with_lf_strings, regex_crlf_file_lf_pattern.

- file_write.rs does NOT normalize: line 112 std::fs::write(&validated, &args.content) writes verbatim. Overwriting a CRLF file with LF content → mixed endings + git "LF will be replaced by CRLF" warning. This is the root cause of the repeated tripping.

- file_append.rs does NOT normalize: line 113 file.write_all(args.content.as_bytes()) appends verbatim. Appending LF content to a CRLF file → mixed endings.

- file_read.rs just reads; no normalization needed.

Plan: extract detect_line_ending + normalize_line_endings from file_edit.rs into a shared module (src/tool/agent/line_endings.rs), reuse in file_write (normalize to existing file's style when overwriting; leave new files as-is) and file_append (normalize appended content to existing file's style; leave new files as-is). Add tests mirroring file_edit's CRLF tests. Then add a short constitution rule to agent.md.

## Steps
- [x] 1. Extract detect_line_ending + normalize_line_endings from file_edit.rs into a new shared module src/tool/agent/line_endings.rs (pub fns with doc comments). Update file_edit.rs to import them instead of defining its own private copies. Confirm file_edit tests still pass.
- [x] 2. In file_write.rs: when overwriting an existing file, detect its line-ending style and normalize args.content to match before writing. New files: write content as-is. Add tests: overwrite_crlf_file_with_lf_content_preserves_crlf, overwrite_lf_file_with_crlf_content_preserves_lf, new_file_keeps_content_as_is.
- [x] 3. In file_append.rs: when appending to an existing file, normalize args.content to the file's detected style. New file: append as-is. Add tests: append_lf_to_crlf_file_normalizes, append_crlf_to_lf_file_normalizes.
- [x] 4. Add a short rule to agent.md (Code style section): preserve the line-ending style of existing files; the file tools normalize automatically, but prefer file_edit (targeted) over file_write (full rewrite) for existing files.
