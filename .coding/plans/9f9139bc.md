# Plan: Memory auto-typing via Laya — confidence-gated prefix correction at memory_write

## Goal
Confidence-gated Laya auto-typing at memory_write: classify title+content as a choice question over the six typed prefixes (SPEC/DECISION/BUG/PLAN/HOW/REVIEW); confident answer retypes the title (correct dir/file/row), low confidence or no answer keeps the writer's prefix, and with the new auto_type_memories flag off (the default) or Laya disabled the behavior is byte-identical to today. Ships the seed labeled-set builder (the fine-tuning path) + regression tests for all three acceptance paths (disabled untouched / stub override / low-confidence keep).
