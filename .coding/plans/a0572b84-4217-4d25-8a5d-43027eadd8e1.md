# Plan: Fix compaction bugs: tool-call boundary, mid-turn resume, start/end announcements

## Goal
Fix the three compaction bugs: (1) orphaned tool_call_id after compaction breaks the next request, (2) mid-turn compact stops execution instead of resuming, (3) /compact start/result announcements come from the backend on every path.

## Kind
implementation

## Context
Three compaction bugs, all diagnosed:

1) ORPHAN TOOL MESSAGE (user screenshot: "messages[2] is a tool message whose tool_call_id 'call_otgxxm0u' has no matching assistant tool call"). src/agent/context.rs `summarize()` (line ~148) and `summarize_with_interrupt()` (line ~230) keep the last `keep_recent` (6) messages verbatim via `&messages[len-6..]` with no tool-call-boundary check. When the cut lands between an assistant tool_calls message and its tool results, the kept tail starts with orphaned tool messages; the next request is rejected, retried 3x, fails terminally — this also wedges/stops execution.

2) EXECUTION STOPS AFTER COMPACT: a mid-turn /compact aborts the turn (StopReason::Compact) → run_turn_with_retry returns AfterTurn::Compact(steers) → src/runtime/agent.rs arms (lines ~347 and ~415, duplicated in Prompt and Suggestion branches) run compact_context, push steers as user messages, then fall back to `cmd_rx.recv()` — the interrupted work never resumes and queued steers are never driven. Fix: extract a drive_turns helper that loops on AfterTurn; after a completed compact (stop==None) push a "[harness note] Context compacted mid-task; continue" user message when no steers, then run a follow-up turn. On Interrupt during compact: keep current behavior (push steers, go idle). On Cancel: terminate.

3) ANNOUNCEMENTS: "Compacting context…" is faked frontend-side only on the slash-command path (frontend/src/components/layout/InputBar.tsx:372-375); popup-button path gets no start message; failure/no-op paths leave the start message hanging. Fix: new backend AgentEvent::CompactStarted (serialized kind "compact_started") emitted at the start of compact_context (runtime/agent.rs:579) and the auto-compact path (src/agent/turn.rs:230, next to Phase::Compacting); emit Compacted whenever stop.is_none() (drop the used<before guard on both paths) and format the no-reduction case in the frontend reducer ("Nothing to compact…"). Remove the InputBar optimistic push.

User decided: do NOT add compact as a model-callable tool (bugs only).
