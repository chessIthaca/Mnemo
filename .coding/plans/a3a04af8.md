# Plan: Record request_stats for errors, summarizer calls, and TTFT (R21)

## Goal
Make request_stats cover the full request population: error requests (per failed complete_with_retry attempt + once per mid-stream error) write a row with our estimated prompt tokens, cached_tokens NULL (not 0 — a real miss stays distinguishable) and outcome='error'; compaction's own call writes a row tagged purpose='summarize' with the forwarded Usage event (including ttft_ms); the schema gains nullable cached_tokens + outcome/purpose columns via an idempotent table-rebuild migration; the existing successful-stream plumbing (including ttft_ms) is preserved.

## Kind
implementation
