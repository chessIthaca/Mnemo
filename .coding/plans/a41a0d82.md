# Plan: Graduated symbol-lookup redirect gate (advisory → intercept after 2 ignored nudges)

## Goal
Give the C3 symbol-nudge escalation teeth: after an agent ignores the search symbol-nudge ESCALATION_THRESHOLD (2) times without switching to a graph tool, intercept the next symbol-shaped search/search_read call at the dispatch funnel and return a redirect result embedding the symbol id — instead of running the search and appending another ignorable NOTE. The gate lifts when the agent switches to a graph tool once (existing C3 semantics). This would have caught the 2026-12-04 drift (6 symbol lookups via search) on call 3, saving 4 wasted round-trips.
