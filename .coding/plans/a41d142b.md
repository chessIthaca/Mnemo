# Plan: CI Rust deprecates AtomicUsize::fetch_update: replace it in the mnemo2-mcp quit test

## Goal
The mnemo2-mcp tests compile on both the local Rust 1.95 and the CI's newer stable Rust.

## Kind
bug_fixing

## Context
The only `.fetch_update(` call in the repo is test code in src-tauri/mnemo2-app/src/mnemo2_mcp/quit.rs (~line 296-298), inside a closure `move |_: u32| alive.fetch_update(Ordering::SeqCst, Ordering::SeqCst, |left| left.checked_sub(1)).is_ok()` that decrements a liveness counter if it is above zero and reports whether it was. `try_update` (the new name) does not exist on rustc 1.95, so neither name works on both toolchains. Fix: replace the call with a version-neutral equivalent, e.g.
```
let left = alive.load(Ordering::SeqCst);
left > 0 && alive.compare_exchange(left, left - 1, Ordering::SeqCst, Ordering::SeqCst).is_ok()
```
(the closure is called sequentially by the test, so this is equivalent). Change nothing else. Regression test: the quit test that holds this closure (find its name around line 270-310) must still pass; CI compiling it is the real check.

Verification: `cargo test -p mnemo2-app`, `cargo clippy -p mnemo2-app --all-targets -- -D warnings`.

## Acceptance scenarios
- cargo test -p mnemo2-app passes locally and the file has no fetch_update call
