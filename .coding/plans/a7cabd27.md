# Plan: Remove the Mnemo1-only code and dead settings from the core

## Goal
The core library and Mnemo2 lose the code only Mnemo1 used and the settings nothing acts on any more (about 3,800 lines), with every kernel feature an embedder or Mnemo2 uses left intact.

## Kind
implementation

## Context
WHY: Mnemo1 was deleted on 2026-11-11 (PR #120, merged to main). The inventory .coding/analysis/2026-11-11-mnemo1-only-core-code.md (merged 5087231e) classifies what it left behind. Its `## Candidates` sections give every symbol with file:line and the exact references; its `## Proposed removal steps` is the basis of the steps below. READ THE REPORT SECTION YOUR STEP NAMES BEFORE EDITING.

THE RULE: the core (`mnemo`, src/) is a public embeddable library (README "Embedding the kernel", examples/second_consumer.rs, tests/boundary.rs). Remove ONLY what a step lists. Everything the report marks KEEP stays, notably: `wire_brain`, `Brain`, `SharedResources`, `BrainMemoryOptions` (minus `on_screen_browser`), `resolve_startup_provider`, `should_reembed_at_startup`; all src/host modules other than the listed functions; `agent_*` worktree functions; `CodeGraph::index`; backlog deferral (`deferred`, `set_deferred`, `set_auto_defer_reason`, `transition`, `set_status`, `requeue`, `clear_finished`); the off-screen browser (`BrowserManager`, `PageInfo`, `ConsoleEntry`, `ConsoleEvent`, `subscribe_console`, ordinary navigate/list_pages/screenshot/console/snapshot/eval/click/type_text, `normalize_url`); the webview_args profile helpers (`mutex_name_for`, `secondary_webview_data_dir`, `set_webview_data_dir`, `webview_data_dir`) used by src-tauri/src/webview_udf.rs; `SerializableAgentEvent` and every other event variant; `RoutingNotice`; `UNATTENDED_PROMPT_PREFIX` and the unattended policy (lead decision: keep, only reword its docs); `[general.budget]` and `BudgetConfigDto` (enforced by src/agent/turn.rs budget_gate; Mnemo2 Models edits them); per-task model slots and per-turn routing; `SettingsSaveDto` and pricing; `[ui]` theme and sound keys; every other Laya flag.

ORDER: steps 1, 4, 5 and 6 are independent. Step 2 follows step 1. Step 3 follows step 2. Step 7 follows step 1. Step 8 is last. No two steps edit the same file.

Users' existing config.toml files may still contain retired keys; the config structs do not use deny_unknown_fields, so those keys are ignored on load — no migration.

VERIFY (every step, plus its own checks): cargo build -p mnemo2-app; cargo clippy --workspace --all-targets; cargo clippy -p mnemo-app --all-targets --features mnemo2; cargo test --workspace --no-fail-fast; cargo test -p mnemo-app --features mnemo2 --lib; when a step touches mnemo2/: npm test --workspace mnemo2 and npm run check --workspace mnemo2. #![deny(warnings)] applies: remove imports a deletion orphans. Known timing flakes you may re-run once: runtime::agent cancel_during_approval and interrupt_during_approval. After deleting, `git grep` every deleted symbol name across src src-tauri tests examples mnemo2/src and confirm only comments you are about to fix remain.
