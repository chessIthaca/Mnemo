# Plan: file_edit drift failures steer to a fresh read — no blind retries, gate on the third

## Goal
file_edit's drift-class failures (old_string not found / past-EOF / empty) carry a fresh-read nudge with a stable steering marker, and after two failed attempts without an intervening read the next file_edit is intercepted with an actionable re-read instruction naming the path (backlog 714196da) — no more blind-retry loops.

## Context

The steering framework is the established vehicle: MarkerKind table in src/agent/steering_stats.rs (marker substring / targets / label / index / detect — tool-scoped, first-line for text-bearing tools), observe_result counts markers on ALL completed results incl. failures (dispatch.rs:448/474 — the error text is the result output), observe_call counts a switch when the next call names a target tool, C3 escalation queues at ESCALATION_THRESHOLD=2 (steering_stats.rs:271), C5 gate symbol_search_redirect (dispatch.rs:734) is the interception pattern — gate fires when fired>=2 && switched==0 (should_gate_symbol_search :467), gate result bypasses execution so it never feeds its own counter (dispatch.rs:245-247). Load-bearing: arrays are literal-sized [..;9] (Inner::counts, agent_fired/agent_switched, or_insert([0;9]) at :442) — a 10th kind must bump every size; use MARKERS.len() instead. Read tool names for switch targets: read_files / file_read / search_read (verify file_read registration in factory.rs during execution). The gate needs the edit path from parsed_call.arguments (available at the dispatch choke point). Wording contract: the nudge's stable marker substring is "Re-read the file" (case-sensitive, on the error's first line). Design: threshold 2 means failure 1 nudges, failure 2 nudges + queues escalation + arms the gate, the THIRD file_edit attempt is intercepted with an actionable message naming the path — preventing the blind third failure entirely (the user's "not timeout after three failures"). Scope: only the drift-class errors get the nudge (identical-strings/mode-exclusivity are schema mistakes, not drift — excluded).
