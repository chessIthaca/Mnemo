# Plan: Window title and tray tooltip name the open project folder

## Goal
With two Mnemo2 instances in the Windows taskbar, the user can tell them apart: the main window title (shown when hovering the taskbar button) and the tray icon tooltip read "Mnemo2 - C:\FactoryGame" while that project is open, and plain "Mnemo2" when no project is open.

## Kind
implementation

## Context
WHY: the user now runs one Mnemo2 instance per project. Both taskbar buttons and both tray icons say only "Mnemo2", so they cannot tell which instance works on which folder. The user asked for the taskbar tooltip to read like "Mnemo2 - c:\Factorygame".

WHERE THINGS ARE TODAY:
- `src-tauri/src/mnemo2/mod.rs` `install_shell`: `WindowBuilder::new(app, "main").title("Mnemo2")` — the main window label is "main". Keep that initial title.
- `src-tauri/src/mnemo2/mod.rs` `install_tray`: `TrayIconBuilder::with_id("mnemo2").tooltip("Mnemo2")` — the tray id is "mnemo2". The tray may be missing (installing it can fail; `tray_ok`), so a missing tray is not an error.
- `src-tauri/src/mnemo2/ipc.rs` `lead_open` (tauri command): every project open (UI pick, `--project`, and Claude Code's mnemo_init_project / MCP open request, which reach the UI and then this command) goes through it. The root is `project::canonical_root(...)`, which uses `dunce::canonicalize`, so it is already a plain `C:\FactoryGame` without the `\\?\` prefix. On success it ends with `state.sync_run_file(Some(&root));`. Earlier, when a previous runtime is replaced, it calls `state.sync_run_file(None);` right after `old.shutdown().await;`.
- `src-tauri/src/mnemo2/ipc.rs` `lead_close` (tauri command): `state.release_external_lead(&app).await; state.shutdown().await; browser.close().await`.
- `Mnemo2State::sync_run_file` / `shutdown` have no AppHandle; do not add one to the state. Call the new helper from the commands, which have `app: AppHandle`.

DECISIONS (taken, do not revisit):
- Format: exactly `Mnemo2 - <root.display()>` with an ASCII hyphen and single spaces, e.g. `Mnemo2 - C:\FactoryGame`. No project open: exactly `Mnemo2`. The user wrote this format.
- The same text goes to both the main window title and the tray tooltip.
- Display the canonical root as `Path::display()` gives it; no shortening, no folder-name-only form.
- A failure to set the title or tooltip is ignored (`let _ =`) — it must never fail an open or close.
- After a failed open that replaced a previous project, the title reads `Mnemo2` (the old project is closed by then).

VERIFY: `cargo test -p mnemo2-app window_title` (or the crate that owns src-tauri/src/mnemo2 — find it with `cargo metadata`/Cargo.toml; the unit tests live in that crate), then `cargo clippy` on that crate with no new warnings, and `cargo build` of the mnemo2 binary.

## Acceptance scenarios
- With C:\FactoryGame open in Mnemo2, hovering its Windows taskbar button shows the title "Mnemo2 - C:\FactoryGame", and the tray icon tooltip shows the same text.
- After closing the project (back to the start screen), the window title and tray tooltip read "Mnemo2".
- Switching the open project from C:\Mnemo to C:\FactoryGame changes the title from "Mnemo2 - C:\Mnemo" to "Mnemo2 - C:\FactoryGame".
