# Plan: Chat readability: thread line, prose cap, turn tint, hover timestamps (each a setting, default ON)

## Goal
Implement the four approved readability suggestions as individually toggleable settings (all default ON, Settings → Chat): a vertical thread line along consecutive activity cards, a ~100ch prose width cap (code blocks/diffs/tool outputs stay full width), an alternating faint turn background, and entry timestamps on hover. Each follows the established show_tool_activity settings pattern end-to-end (Rust [ui] config → IPC DTO → store → App hydration → Chat section toggle → display).

## Kind
implementation
