# Plan: pr_sweep skill: a repo-local PR-queue sweep overlay (+ REPO_LOCAL_SKILLS classification, pinning test, docs)

## Goal
Author a repo-local `pr_sweep` skill that lets the agent work the open pull-request queue end-to-end with the tools it needs: enumerate the open PRs, gate each one (CI on the merge commit, the Cargo.lock vendored-patch check for cargo PRs, changelog + real build for major bumps), approve and merge the ones that pass (`gh pr review --approve` + `gh pr merge --merge` — the authors are dependabot[bot], so this is not a self-approval against ruleset 23755694), sync local main, and report — leaving any PR that needs source/manifest edits OPEN for a plan instead of merging it. Classify the skill in REPO_LOCAL_SKILLS, pin it with a test that asserts its load + merge-gate ORDER, and sync docs/FEATURES.md. Then (Phase B, outside this plan, from Complete) start the skill and use it to sweep the 5 currently open dependabot PRs.
