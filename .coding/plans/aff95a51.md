# Plan: Tighten empty-call descriptors + wire the graph_search → graph_context pointer

## Goal
Cut the per-turn tool-descriptor cost of the hand-copied empty-call boilerplate down to one shared, tested helper, and put the graph_context chaining rule where the decision actually happens — in graph_search's RESULT — so the under-chaining observed in this session cannot recur. The error-side recovery hint (the mechanism with evidence behind it) is preserved unchanged.

## Kind
implementation

## Context
Root cause + evidence from the 2027-01 session analysis (memory: "HOW: empty-call descriptor boilerplate — cost vs efficacy, and the graph_context chaining gap", knowledge file .coding/knowledge/how/2027-01-11-empty-call-descriptor-boilerplate-cost-vs-effica.md).

(1) DUPLICATION. The 4-sentence empty-call block is hand-copied into every tool with a required field — 13 occurrences across 5-6 files: src/tool/agent/codegraph.rs (graph_search:274, graph_context:436, plus graph_impact/graph_path later in the file), src/tool/agent/read_files.rs:164, src/tool/agent/shell.rs:395, src/tool/agent/git_read_tool.rs:73, src/tool/memory/mod.rs:130. Each tool carries it TWICE: the schema description AND the hint string passed to read_files::invalid_args_error.

(2) EFFICACY EVIDENCE. This session an empty read_files call was emitted DESPITE read_files' description leading with exactly that rule; recovery came from the ERROR text on the next call. So the descriptor copies are per-turn cost with unproven benefit, while the error-side hint is the proven mechanism and STAYS. Design: keep one leading contract sentence + the inline call-shape example per tool, drop the rest.

(3) UNDER-CHAINING EVIDENCE. Zero graph_context calls this session. The rule "call this immediately after graph_search" lives in graph_context's OWN description (src/tool/agent/codegraph.rs:446) — the tool not being called — and graph_search's payload (src/tool/agent/codegraph.rs:372-392: {query,count,symbols,hint?,note?}) carries no pointer, unlike the search auto-delegation path (symbol_delegation_block, src/tool/agent/codegraph.rs:159-165).

(4) TEST PIN. src/tool/agent/git_read_tool.rs:239 schema_advertises_the_no_zero_argument_rule asserts starts_with("Always pass `op`") + contains "No zero-argument form" / "do not resend the empty shape" / "If you catch yourself" / "e.g. {". History: backlog d9ad618e + 26cdbaf8 landed the block deliberately — this revises it with data, not as a bug fix, and must keep the shape example + the error hint.
