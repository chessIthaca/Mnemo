# Plan: Settings: default-model dropdown + card-header visibility

## Goal
Add a prominent, always-visible way to change the default model in the Settings dialog: a "Default model" dropdown in the Providers section header, plus show the current default model in the endpoint card's collapsed header, reusing the existing saveEndpoints path.

## Kind
implementation

## Context
User: "add a way to change the default model" → clarified "There is no way to set it in the config dialog. That is what is missing." A buried control exists (Providers → expand default endpoint card → per-model-row "set ★" button, EndpointCard.tsx:524-537 → onDefaultModel → ProvidersSection defaultModel state → saveEndpoints, which persists default_model to config.toml AND live-swaps the provider) but is not discoverable. User chose "Both" placements: a header dropdown AND promoted visibility in the card header. No backend changes needed — saveEndpoints already handles default_model + provider swap. No existing vitest coverage of ProvidersSection/EndpointCard. Style: text-[0.65rem]-text-xs controls, --text-muted/--text-primary/--accent-color CSS vars, bg-bg-primary/bg-bg-secondary, rounded-lg borders (see EndpointCard.tsx effort select ~348-370 and VisionSection for a select-in-section pattern). serializeProviders (settings/types.ts:137-144) already includes dm in the dirty snapshot.
