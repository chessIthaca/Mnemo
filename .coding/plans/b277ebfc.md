# Plan: MCP servers v1: config, lazy manager, deferred tool groups, Settings UI

## Goal
MCP server support v1: configurable servers in ~/.mnemo/mcp.toml (stdio + remote), lazy per-server connections via an McpManager, tools exposed as per-server deferred groups revealed by load_tools, McpTool adapters with NeedsApproval gating, Settings page with test button — built-ins (browser/image) untouched except for sharing the (generalized) deferred-group table.

## Kind
implementation

## Context
User-approved MCP architecture (2026-02-13 design chat). LOCKED SCOPE: (1) Storage = global ~/.mnemo/mcp.toml, [[server]] entries with name + enabled + either stdio transport (command/args/env: Vec<String> — env var NAMES only, never values) or remote transport (url + headers_env map of header→env-var-name); validated on load, atomic save w/ .bak, mirroring src/config/endpoints.rs. (2) Client = rmcp crate first (stdio + streamable-HTTP/SSE); if rmcp fails to build warning-free on both platforms or drags heavy deps, fall back to a minimal in-crate stdio JSON-RPC client (initialize/tools.list/tools.call only) and note remote transports as backlogged. (3) Loading = per-server deferred groups: DEFERRED_GROUPS (src/tool/mod.rs:502, pub const) becomes static base + runtime entries mcp.<server> built by the factory from the manager; load_tools (src/tool/agent/load_tools.rs) enum+validation from the runtime table; one stable-head index line per enabled server; agent calls load_tools {group:"mcp.<name>"} → connect + tools/list → McpTool adapters join the tools array next request (same mechanism as browser group). (4) McpTool adapter: name = mcp__<server>__<tool>, schema = MCP inputSchema passthrough (JSON Schema ↔ provider::ToolSchema 1:1), execute → tools/call with output capped (cap_tool_output), SafetyLevel::NeedsApproval ALWAYS, category chosen so tools are Executing-only and outside the reviewer allow-list; subagents: normal tools (reviewer allow-list excludes them naturally). (5) IPC: mcp_list_servers/mcp_save_servers/mcp_test (connect + report tool count/names/error; never log env values); Settings → MCP page. (6) Browser/image tools stay NATIVE — only the deferred-group table is shared.
