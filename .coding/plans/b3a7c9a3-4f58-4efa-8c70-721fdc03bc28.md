# Plan: Forgiving base URLs on load + per-model caps auto-fill in EndpointCard

## Goal
Make base URLs forgiving on every config path (normalize missing trailing slash on load), and make the EndpointCard caps discovery auto-fill + conflict warnings target the per-model entry (each model gets its own max input/output tokens) instead of endpoint-level fields.

## Kind
implementation

## Context
Backlog item (config bugs): "the provider url requiring a / really is something you can determine and add yourself. Make it forgiving. Also within an endpoint there can be multiple models. Each model has its own max, input * output token. Also each has their own reasoning effort list." Exploration found most of it ALREADY shipped: save-path normalization (src/config/patch.rs validate_endpoint appends missing '/'), all URL builders trim (openai.rs:197/255/616, anthropic.rs:757, vision.rs:155), per-model ModelSpec{max_context,max_output_tokens,reasoning_efforts} (src/config/endpoints.rs:99-115) with resolution (max_context_for:188, effective_reasoning_effort_for:220, reasoning_efforts_for:259), client_factory applies per-model caps (:90-91,112-113), config_io.rs resolve_reasoning_effort clamps (:77), StatusBar per-model effort dropdown (:31-63), EndpointCard ModelRowConfig per-model editing strip (:742-829). GAPS: (1) load_or_default (endpoints.rs:298) does not normalize base_url on load — hand-edited endpoints.toml without trailing slash loads as-is (builders tolerate it, but the config should be forgiving everywhere); (2) EndpointCard.tsx caps auto-fill (lines 119-140) writes ENDPOINT-level max_context/max_output_tokens from the reference model's discovered caps — wrong for multi-model endpoints where each model has its own caps; the conflict warnings (lines 523-566) + "Apply discovered" also target endpoint-level. Helpers modelConfigFor/upsertModelConfig exist + tested in frontend/src/components/settings/types.ts (:224,:245) with tests in types.test.ts (vitest include src/components/settings/**/*.test.ts already registered). DiscoveredCaps: EndpointCard.tsx:81, applyServerModels populates capsById (:194-204).
