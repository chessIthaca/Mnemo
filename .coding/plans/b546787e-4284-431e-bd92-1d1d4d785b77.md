## Steps

- [x] 2. **Delete merged branches with -d and verify** — For every branch listed by `git branch --merged main` that is NOT 'main' (and not the current branch — we are on main): `git branch -d <branch>` one at a time (safe delete; never -D). After all deletions, run `git branch` to verify the final state and report which branches were deleted and which (if any) remain because they are unmerged.
