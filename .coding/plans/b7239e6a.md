# Plan: Worker thread: no name/time line on the worker's own messages

## Goal
In a worker's thread (mission control and the compact panel), the worker's own messages show only their body; the "LEAD · time" and "HARNESS NOTE · time" lines stay on messages from others.

## Kind
implementation

## Context
WHY: the user (2026-11-15) saw "QCODEREDIT01 · now" repeated above every message in a worker's output: the thread is that worker's own, so its name and the time on each of its messages waste space. Messages written into the thread by someone else (the lead, the harness) keep their header so it stays clear who spoke. Code: mnemo2/src/components/WorkerThread.svelte line ~122, inside `{#snippet threadMessages()}`: `<span>{entry.from === "lead" ? "LEAD" : entry.from === "harness" ? "HARNESS NOTE" : worker.name.toUpperCase()} · {entry.time}</span>`. WorkerThreadEntry.from is "worker" | "lead" | "harness" (mnemo2/src/lib/types.ts:174). VERIFY: `npm run test --workspace mnemo2`, `npm run check --workspace mnemo2` (0 errors, 0 warnings). A fresh worktree needs `npm ci` first.

## Acceptance scenarios
- A worker's own message in its thread shows no name/time line, only the message body.
- A lead message in the same thread still shows 'LEAD · <time>', and a harness note still shows 'HARNESS NOTE · <time>'.
