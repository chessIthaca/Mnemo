## Goal
Implement the five fixes from .coding/reviews/2026-08-18-rdp-freeze-diagnosis.md: (R1) move the agent-chat webview resize off the main event loop via a latest-wins worker thread; (R2) bound the frontend rAF delta buffers with a synchronous flush past 64 KiB; (R3) rAF-throttle browser-rect reports + try_lock skip-on-busy backend set_rect; (opt-in) MYHARNESS_DISABLE_WIN_OCCLUSION browser arg; (R5) bound the RunEvent::Exit teardown with a timeout. Each fix gets a regression test per the project constitution.
