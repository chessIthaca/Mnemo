# Plan: Persist Mnemo2 project cost and token breakdown

## Goal
Replace the header's transient token total with durable per-project estimated cost and a cached/input/output token tooltip, using vendor pricing when configuration has none.

## Kind
implementation

## Context
verified: mnemo2/src/components/TopBar.svelte:17-19 derives header totals from $app.workers and selects tokens whenever teamCost is null; WorkerRecord telemetry is mapped in mnemo2/src/lib/store.ts:1515-1529, so worker deletion removes its contribution and lead usage is not represented. verified: read-only PowerShell inspection of ~/.mnemo/endpoints.toml returned `pricing = []`. Implement a project-scoped durable usage accumulator in the existing Mnemo2 project state, record both lead and worker SerializableAgentEvent::Usage activity, and expose an aggregate through TeamSnapshot. Persist raw per-model token usage so totals survive restart, project switching, and worker deletion and can be repriced when pricing changes. Treat prompt_tokens as including cached_tokens: uncached input = prompt_tokens.saturating_sub(cached_tokens). Use integer micro-USD and saturating arithmetic, consistent with WorkerTelemetry. Add vendor-default pricing as a fallback to explicit endpoints.toml pricing (explicit rows always win) for the configured vendors/models; obtain rates from official vendor pages, including https://ollama.com/pricing, https://platform.claude.com/docs/en/about-claude/pricing, https://ai.google.dev/gemini-api/docs/pricing, and official DeepSeek/Kimi pages. Do not fabricate unknown rates. This is a feature-scale correction to the reported non-persistent token display. Preserve all unrelated uncommitted changes. Public functions need doc comments and the build is warning-free under deny(warnings). Verification: cargo test --workspace; in mnemo2, npm test and npm run check. UI requirement: the visible top-right metric is cost, never a token fallback; hover and keyboard focus expose cached, uncached input, and output token counts, with an honest unavailable/partial indicator if any usage has no price.
