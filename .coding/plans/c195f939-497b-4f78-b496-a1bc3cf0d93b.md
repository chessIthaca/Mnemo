# Plan: One-decimal percentage formatting everywhere (99.8%)

## Goal
All user-facing percentage displays show at most one decimal digit (e.g. 99.8% instead of 99% / 100%) via a shared formatter.

## Kind
implementation

## Context
Backlog 9042b47c: percentages currently render as integers (Math.round / toFixed(0)) at ~12 sites; cache-hit % is the motivating case (99.3% shows as "99%"). Shared formatters live in frontend/src/lib/format.ts (fmtTokens/fmtRate/fmtDuration + format.test.ts). cacheHitPct (frontend/src/lib/traceStats.ts:77) returns an integer-rounded % consumed by LlmTraceView badges/tooltip and tokenTipRows (traceStats.ts:270-276, pinned "(55%)" in traceStats.test.ts:299).
