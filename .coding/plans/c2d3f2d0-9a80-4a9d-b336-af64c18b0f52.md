# Plan: Fix compact popup hover + surface /compact feedback

## Goal
Make the Compact context button reachable by keeping the popup open while the mouse is over it; make /compact visibly work by surfacing compaction success (before→after tokens) and failures in the transcript; and upgrade the compaction prompt to the user's 8-heading structured format for higher-fidelity handoff summaries.

## Kind
implementation

## Context
User report: (1) the Compact button in the ctx-bar popup is unreachable because the hover popup closes when the mouse leaves the bar; (2) /compact seems not to work, though it does compact when typed — 500K→24K felt suspicious. Diagnosis: (1) `frontend/src/components/chat/InflightBar.tsx:233` popup uses `mb-1` margin between trigger bar and popup; margins are hover dead zones, so `group-hover` breaks across the 4px gap and the popup hides before the button is reached. Fix = convert gap to padding (pb-1) on a wrapper (padding is inside the hover box). (2) Compaction failures are silently swallowed at `src/runtime/agent.rs:579` and `src/agent/turn.rs:225` (`.unwrap_or_else(|_| (messages.clone(), …))`), and success has no feedback — the transcript shows "Compacting context…" then nothing. 500K→24K is by design (system prompt + structured summary + 6 recent messages kept verbatim). Fix = emit a `Compacted{before,after}` event on success (transcript confirmation) and an Error event on failure instead of swallowing.
