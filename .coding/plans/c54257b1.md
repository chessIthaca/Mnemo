# Plan: Flaky CI test: profile_dir_is_removed_on_close launches a real Chromium

## Goal
CI never launches a real Chromium for the profile-removal coverage; the removal retry loop and close's profile release are covered by Chromium-free tests that run everywhere, and the end-to-end test stays available with --ignored.

## Kind
bug_fixing

## Context
ROOT CAUSE: test environment, not product code. src/browser/mod.rs's test module marks every real-Chromium test with `#[ignore = "integration: spawns a headless Chromium process; run with \`cargo test -- --ignored\`"]` (navigate_and_list_pages, eval_awaits_promises, respawn_after_close, watchdog_probe_does_not_reap_healthy_browser, ...). profile_dir_is_removed_on_close (cfg(windows), end of the module) lacks it, so every CI run launches Chromium and fails when the runner is slow to start it. FIX: give it the same #[ignore] and replace its CI coverage with Chromium-free tests of the pieces it exercises: BrowserManager::schedule_profile_removal (background retry loop, std::thread, 60 x 250 ms) and BrowserManager::close's profile handling (state.profile taken, unregister_live_profile, the TempDir dropped when no browser is attached). The kill-before-removal contract (kill_browser) needs a real child process and stays covered only by the ignored end-to-end test. Helpers available in the module: register_live_profile(&Path), unregister_live_profile(&Path), static LIVE_PROFILES: LazyLock<Mutex<HashSet<PathBuf>>>; tests already reach `manager.state.lock().await`. REGRESSION TESTS (src/browser/mod.rs, mod tests): `profile_removal_retries_until_a_lock_is_released` (cfg(windows): a file inside the dir held open with share_mode(0) makes remove_dir_all fail; without the retry loop the dir would survive after the handle is released), `profile_removal_removes_an_unlocked_dir`, `close_without_a_browser_releases_the_profile`. VERIFY: `cargo test -p mnemo --lib browser::tests` (the three new tests pass; profile_dir_is_removed_on_close shows as ignored), `cargo clippy -p mnemo --all-targets` clean, `git diff --check`.

## Steps
- [x] 1. **Ignore the real-Chromium test; add three Chromium-free tests** File: src/browser/mod.rs only, test module only (no production code). A. On `profile_dir_is_removed_on_close`: keep `#[cfg(windows)]` and `#[tokio::test]`, add the module's standard `#[ignore = "integration: spawns a headless Chromium process; run with `cargo test -- --ignored`"]` (copy the exact attribute text from navigate_and_list_pages). NEW test, directly after it: ```rust /// The removal loop keeps retrying while a file in the profile is locked /// (as a dying Chromium's crashpad or an AV scan does) and removes the dir /// once the lock goes away. #[cfg(windows)] #[test] fn profile_removal_retries_until_a_lock_is_released() { use std::os::windows::fs::OpenOptionsExt; let dir = tempfile::tempdir().expect("tempdir"); let path = dir.path().to_path_buf(); let locked = path.join("Default").join("Lock"); std::fs::create_dir_all(locked.parent().unwrap()).unwrap(); std::fs::write(&locked, b"x").unwrap(); // share_mode(0): no other handle may read, write or delete it. let handle = std::fs::OpenOptions::new().read(true).share_mode(0).open(&locked).unwrap(); BrowserManager::schedule_profile_removal(dir); std::thread::sleep(std::time::Duration::from_millis(1000)); assert!(path.exists(), "a locked profile must survive the first attempts"); drop(handle); let deadline = std::time::Instant::now() + std::time::Duration::from_secs(10); while path.exists() && std::time::Instant::now() < deadline { std::thread::sleep(std::time::Duration::from_millis(100)); } assert!(!path.exists(), "the loop must remove the dir once the lock is released"); } ``` C. NEW test (all platforms): `profile_removal_removes_an_unlocked_dir` — `#[test]`; tempdir with a nested file `Default/Preferences` containing `{}`; keep the path; `BrowserManager::schedule_profile_removal(dir)`; poll up to 5 s (100 ms steps) until the path is gone; assert it is gone. D. NEW test (all platforms): `close_without_a_browser_releases_the_profile` — `#[tokio::test]`; `let manager = BrowserManager::new();` `let dir = tempfile::tempdir().unwrap(); let path = dir.path().to_path_buf();` `register_live_profile(&path);` `manager.state.lock().await.profile = Some(dir);` `manager.close().await.expect("close");` assert `!LIVE_PROFILES.lock().unwrap().contains(&path)` with message "close must unregister the profile"; assert `!path.exists()` with message "with no browser attached, close drops the TempDir and the dir goes"; assert `manager.state.lock().await.profile.is_none()`. If `BrowserManager::new()` is not the constructor the other tests use, use the same one they use. E.
