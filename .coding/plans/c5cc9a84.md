# Plan: Strengthen graph-tool steering: lower escalation threshold + directive note + HOW memory

## Goal
Make the steering layer's symbol-nudge escalation harder to ignore, so agents stop reaching for `search` on symbol-lookup questions where graph_context answers callers/callees in one call. Three changes: (1) lower the escalation threshold from 3 to 2 (catch the pattern one round-trip sooner), (2) rewrite the escalation note to be directive and cost-explaining instead of permissive, (3) add a HOW memory reinforcing the act-on-the-nudge habit.

## Kind
implementation

## Context
2026-12-04 run-all/steer bug investigation: agent used `search` for 5+ symbol lookups (send_suggestion, send_prompt, on_main_turn_resolved, run_all_dispatch_next, backlog_add, steer) where callers/callees were the actual question. The symbol_nudge fired (confirmed for `steer`) but was ignored. The C3 escalation (threshold 3, soft note with "or deliberately ignoring it" escape hatch) fired too late and was too permissive. All symbols are indexed (verified), so the nudge fires — the gap is the escalation being ignorable. Standing decision c8ddb1f2: "prose mandates alone underperformed" — so the code change (steering layer) is the primary fix; the HOW memory is complementary.
