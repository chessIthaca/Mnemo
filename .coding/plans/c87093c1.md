## Bug
finish falsely errors for a regression test written in any language the code graph doesn't parse: "regression test symbol 'X' not found in the code graph and no source file on disk contains the name (verified after a forced re-index)" — e.g. a .js or .py test that exists on disk and is runnable. The agent is blocked from finishing and steered toward a phantom rename. Root cause: CodeGraph::reindex_files_containing (src/codegraph/mod.rs:604) filters its disk scan to Lang::from_extension (.rs/.ts/.tsx only), so non-indexed code files are invisible to the gate's containment check, and the graph cannot parse them so the symbol never resolves.
