# Plan: Descendant tracker lags session completion — clear the running flag before the finish notification (backlog 2c406d72)

## Goal
Make the descendant tracker and the child-finish notification agree by construction (backlog 2c406d72): when the event forwarder processes a spawned child's Finished (or final Error) event, the child's running flag is cleared BEFORE the completion Suggestion is sent to the parent — so the parent's very next dispatch-cycle gate consult (has_running_descendants) can never see a verifiably-finished child as still running. Regression tests pin the invariant: after the finish notification is emitted, has_running_descendants(parent) returns false immediately.

## Kind
bug_fixing

## Context
Root cause traced this session: in the event forwarder (src-tauri/src/ipc/events.rs), the notification match (lines 516-540) runs BEFORE the running-state match (lines 553-678) for the same Finished/final-Error event. notify_parent_on_completion (events.rs:767) sends the completion Suggestion to the parent's inbox (waking the parent immediately); only afterwards does the forwarder run emit_child_finished (a webview emit) and — in the separate running-state match — acquire the manager lock and call set_running(agent_id, false) (events.rs:600-601). The parent can wake on the Suggestion, run a full turn, and hit the descendant gate (dispatch.rs review-exit gate → IpcSpawner::has_running_descendants → AgentManager walk, src-tauri/src/ipc/spawn.rs:522) while the child is still marked running. Under a saturated frontend the emit+lock window between notification and flag-clear stretches across a whole parent turn. Related: backlog 569b5922 (gate narrowed to review-exit transitions) already landed in commit 264ba82 — this fix makes the tracker and the notification agree, which that item explicitly could not fix. Key code: AgentManager::set_running/has_running_descendants (src/runtime/mod.rs:37-110), AgentHandle::new/with_parent (src/runtime/channels.rs:846/860), FlagDescendantTracker mock pattern (src/runtime/agent.rs:5405-5412), AgentLoopMap (src-tauri/src/ipc/state.rs:91).
