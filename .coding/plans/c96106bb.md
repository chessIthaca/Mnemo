# Plan: Clippy 1.99.1: fix the three new lints that fail the PR gate

## Goal

## Context
WHY: the new PR gate `.github/workflows/ci.yml` (job `check`) installs current stable Rust (1.99.1) with dtolnay/rust-toolchain@stable. Its first live run on PR #118 (run 42986685775) failed in `cargo clippy --workspace --all-targets`. Clippy 1.99 added three lints, and `#![deny(warnings)]` in src/lib.rs turns them into errors:
- src/app/plan_board.rs:1117 useless_borrows_in_formatting;
- src/memory/mod.rs:1128 chunks_exact_to_as_chunks;
- src/memory/mod.rs:1209 needless_late_init.
The local default toolchain is 1.95, which does not report them. The lead reproduced the failure locally with `cargo +1.99.1 clippy`: the same three errors, nothing else reached. Clippy stops at the mnemo lib, so later targets have not been checked under 1.99.1 yet.

- Do not add `#[allow(...)]`.
- Fixes must be the mechanical ones clippy suggests and must not change behaviour.
