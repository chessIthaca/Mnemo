# Plan: Make tool card text + frame scale with font size

## Goal
Make the tool card text and its frame (padding, gaps, icons) scale with the user's font-size setting by converting rem-based Tailwind utilities to em-based ones.

## Context
The Conversation container sets `font-size: var(--app-font-size)` as the inherited base. But ToolCard/CallDetail in Message.tsx use Tailwind rem-based utilities (`text-sm`, `text-xs`, `p-2`, `gap-1.5`, `mt-2`, `space-y-3`, `h-4 w-4`) which are relative to the root <html> font size, not the parent. So neither the tool text nor the frame (padding/gaps/icons) responds to the font-size setting. Converting these to em-based arbitrary values makes them scale relative to the inherited --app-font-size, so both text and frame shrink/grow together.

## Steps
- [x] 1. Convert ToolCard container + header utilities (p-2, text-sm, gap, chevron icons, status text-xs, mt-2, space-y-3) to em-based arbitrary values
- [x] 2. Convert CallDetail utilities (space-y-1.5, text-xs labels, pre p-2, mb-0.5) to em-based arbitrary values
- [x] 3. Build frontend (tsc + vite) to verify it compiles
