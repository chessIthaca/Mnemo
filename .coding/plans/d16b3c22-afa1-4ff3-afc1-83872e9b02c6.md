# Plan: Knowledge-as-files: linked typed records, rebuildable memory index, working-branch topology

## Goal
Typed semantic records live as linked markdown files (git-tracked truth); memory DBs become pure rebuildable caches reconciled at startup with a progress dialog; working-branch topology (wt/* → develop → main) lands with mergeable backlog/stack state.

## Kind
implementation

## Context
Research plan a9baae92 + user decisions (2026-08-23): typed semantic records (SPEC/BUG/DECISION/HOW) become git-tracked md files in .coding/knowledge/<type>/ with TOML front matter (title/status/supersedes/created) and [[wiki-links]] to records, plans, and repo files; the existing derived-record indexer (src/memory/indexer.rs, UUIDv5 source keys + content hashes) turns them into budgeted digest memories, so git merges converge both worktrees' indexes with no import step. memory.db/codegraph.db remain gitignored pure caches: startup reconciliation vs files with a progress wait dialog, delete-to-rebuild. Memory tools (src/tool/memory/mod.rs) become file-backed for typed writes; finish_capture routes through the same writer; one-time migration converts existing authored typed rows to files. Branch topology: long-lived wt/* instance branches → shared develop → protected main; stack.json goes local; backlog becomes jsonl with UUID ids + union merge driver. All phases on ONE branch (house pattern). Key files: src/memory/{knowledge.rs(new),indexer.rs,schema.rs,mod.rs,maintenance.rs,finish_capture.rs}, src/tool/memory/mod.rs, src/tool/agent/sandbox.rs, src-tauri/src/ipc/projects.rs, src/project/git_ops.rs, src/backlog.rs, frontend/src/components/{views/MemoryDebugView.tsx,chat/Message.tsx,settings/sections/MemorySection.tsx}, .coding/skills/merge_to_main.toml, agent.md, README.md.

- [x] 1. **Knowledge record module: format + parser** — Create src/memory/knowledge.rs: type→dir map (.coding/knowledge/{spec,decision,bug,how}), slug rule YYYY-MM-DD-kebab, TOML front matter between +++ fences (title, status live|superseded, supersedes, created), graceful degradation when front matter is missing (title = first heading/line, status live). - [x] 2. **Indexer: knowledge source family** — Extend src/memory/indexer.rs: scan .coding/knowledge/**/*.md as a source family (key knowledge:<type>/<slug>); derive typed digest memories with the existing budgets + mandatory pointer line 'path .coding/knowledge/...'; map front-matter status/supersedes onto superseded_by; store links in the row's data JSON; reuse content-hash incremental skip + removal detection. Tests: idempotence, supersede chain excluded from recall, file removal.
- [x] 3. **File-backed memory tools** — src/tool/memory/mod.rs: memory_write with a typed prefix writes/updates the knowledge file directly (internal fs, not sandboxed file tools) and synchronously reindexes that one source; budgets now validate the digest — the file body is unbounded. memory_update/supersede/delete on knowledge-derived ids edit files (supersede = write successor file with supersedes + flip old status='superseded'). Route src/memory/finish_capture.rs typed captures through the same writer. Untyped writes stay DB-only. Add .coding/knowledge/ to the protected lists in src/tool/agent/sandbox.rs.
