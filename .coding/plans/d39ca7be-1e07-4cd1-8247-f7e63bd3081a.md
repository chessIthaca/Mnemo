# Plan: Image paste in message box + shell purpose indicator

## Goal
Allow pasting images into the message box (with an attachment indicator), sending them as multipart messages to the agent. Also add a `purpose` field to the shell tool so the ToolCard shows what a shell command does (e.g. "shell (running tests)").

## Context
Two features requested together:

**1. Paste image into message box.** The InputBar (frontend/src/components/layout/InputBar.tsx) currently only handles text. The user wants to paste an image (via clipboard), see an indicator that an image is attached, and have it sent with the prompt as a multipart message (text + image_url block).

Current flow:
- `AgentCommand::Prompt(String)` (src/runtime/channels.rs:29) carries only text.
- `send_prompt` Tauri command (src-tauri/src/ipc/commands.rs:90) takes `text: String`.
- `AgentTask::run` (src/runtime/agent.rs:106) pushes `MessageContent::text(prompt)`.
- The frontend `sendPrompt(agentId, text)` (frontend/src/lib/tauri.ts:19) invokes the command.
- `MessageContent` already supports `Parts(Vec<ContentPart>)` with `ImageUrl` blocks (src/provider/mod.rs:135-188), and `build_request_json` was just updated to send/strips image blocks based on multimodal capability.
- The transcript user entry is `{ kind: "user", text: input }` (frontend/src/lib/types.ts:117).

Design: Change `AgentCommand::Prompt(String)` to `Prompt { text: String, images: Vec<String> }` where each image is a base64 data URL (`data:image/png;base64,...`). The agent task builds `MessageContent::Parts` when images are present. The frontend handles paste events, converts to data URLs, shows a thumbnail indicator, and sends them with the prompt. The transcript shows an image indicator on the user message.

**2. Shell command purpose indicator.** The shell tool (src/tool/agent/shell.rs) has no `purpose` field in its schema — the ToolCard shows just `shell` with no context. Add an optional `purpose` field to the shell schema that the model fills with a short label (e.g. "running tests"). Display it in the ToolCard header via the existing `argLabel` function (frontend/src/components/chat/Message.tsx:162).

Files to change:
- src/runtime/channels.rs — AgentCommand::Prompt variant
- src/runtime/agent.rs — AgentTask::run Prompt arm
- src-tauri/src/ipc/commands.rs — send_prompt command
- frontend/src/lib/tauri.ts — sendPrompt wrapper
- frontend/src/lib/types.ts — TranscriptEntry user kind (add optional images)
- frontend/src/components/layout/InputBar.tsx — paste handler, image indicator, send logic
- frontend/src/components/chat/Message.tsx — display image on user messages + shell purpose in argLabel
- src/tool/agent/shell.rs — add purpose field to schema + ShellArgs
