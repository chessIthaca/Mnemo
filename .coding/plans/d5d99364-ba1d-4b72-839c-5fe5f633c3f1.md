# Plan: Replace Browser-tab iframe with embedded child WebView2

## Goal
Replace the Browser tab's iframe (frontend/src/components/views/BrowserView.tsx) with a native child WebView2 embedded in the existing "main" Tauri window, so sites that refuse framing (Google/YouTube — X-Frame-Options / CSP frame-ancestors) load normally. A child WebView2 is never "framed," so those headers don't apply. The human drives it via the Tauri Webview API (all builds); the agent inspects/controls it via CDP attach to the shared debug port (debug-only, unchanged). Bonus: eliminates the iframe coordinate-offset bug (review H1) + the same-origin limit on game_eval/click/type.
