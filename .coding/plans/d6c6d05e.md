# Plan: Speed up build/link (lld + reduced debuginfo) + remove git-spawning tests

## Goal
Speed up the Rust build + test cycle with two levers: (1) switch the MSVC linker to the faster lld (already in the toolchain, just not configured) and reduce debuginfo to line-tables-only; (2) remove all git-spawning tests per the user's principle that git is an external tool we don't need to re-verify — keep only pure-logic tests. Target: src-tauri link ~70s to ~20s; zero git subprocesses in the lib test suite.

implementation
