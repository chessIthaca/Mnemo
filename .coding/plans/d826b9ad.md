# Plan: merge_to_main skill: sync main with origin BEFORE the branch merge

## Goal
Make the merge_to_main flow pull the remote first: step 2 of the skill becomes "git checkout main, then sync main with origin (fetch + pull --no-rebase) before any branch merge". Mirror the same step in the two places that copy the flow (GitView.tsx::mergePrompt override prompt, MergeToMainDialog.tsx step list) and in docs/FEATURES.md, and pin the new ordering with tests (Rust skill-prompt assertion + a new frontend mergePrompt test).

## Context

Syncing first makes the landed merge immediately pushable.
