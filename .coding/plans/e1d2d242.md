# Plan: Flaky test: constitution_reread_after_agent_md_edit relies on the wall clock for mtime

## Goal
Make constitution_reread_after_agent_md_edit deterministic by setting the edited file's mtime explicitly instead of relying on the wall clock, the same fix its sibling unit test already has.

## Kind
bug_fixing

## Context
WHY: ConstitutionSource (src/project/agent_md.rs, reload_if_changed ~L205-235) re-reads agent.md only when `std::fs::metadata().modified()` differs from the cached SystemTime by exact equality. The agent-level test writes PROJECT-RULE-V1 at setup, runs turn 1 (fast, mocked provider), then writes PROJECT-RULE-V2-NEW and sleeps 1100 ms. The sleep comes AFTER the write, so it does nothing for the mtime: when the second write lands in the same file-timestamp tick as the first (Windows updates file times on a coarse clock tick), the mtime is unchanged and the edit is missed. The sibling unit test `project::agent_md::tests::source_rereads_after_mtime_change` (src/project/agent_md.rs ~L358-393) already fixed this exact flake by setting the mtime explicitly with `File::set_times` to now + 60 s; copy that pattern.

DECISIONS: change only the test, never ConstitutionSource (exact-equality mtime compare is intended and cheap). Remove the 1100 ms sleep (it is useless and slows the suite). No other test needs this: src/safety_rules.rs reload_picks_up_external_edits goes from a missing file to a present one (mtime None -> Some, always detected) and src/mcp/mod.rs idle_timeout_expires_stale_connections_lazily sleeps for an idle timeout, not an mtime.

REGRESSION TEST: `agent::tests::constitution_reread_after_agent_md_edit` in src/agent/tests.rs itself, made deterministic. Mechanism proof (red, not committed): setting the edited file's mtime back to its turn-1 value makes the test fail at the turn-2 assertion, which is exactly the CI failure.

VERIFY: `cargo test -p mnemo --lib constitution_reread_after_agent_md_edit` passes 5 runs in a row; `cargo test -p mnemo --lib` exit 0; `cargo clippy --workspace --all-targets -- -D warnings` exit 0.

## Acceptance scenarios
- `cargo test -p mnemo --lib constitution_reread_after_agent_md_edit` passes 5 runs in a row, with no sleep in the test.
- With the edited file's mtime forced back to its turn-1 value, the test fails at the turn-2 assertion (the CI failure), proving the explicit bump is what makes it pass.
