# Plan: ask_user question system

## Goal
Add an `ask_user` tool + question system so the agent can ask the user a question with clickable options plus a freeform "Let's talk about it" fallback, one question at a time. Mirror the approval flow exactly (oneshot-based pause/resume). The two-questions example (skill mastery + favorite color) drives the integration test.

## Context
Explored the approval flow end-to-end — it's the exact architectural template. Approval path: dispatch.rs emits AgentEvent::ApprovalRequest{responder: oneshot::Sender<Approval>}; into_serializable() strips the sender; PendingApprovals (ipc/approval.rs) holds it keyed by (agent_id, tool_call_id); the `approve` Tauri command resolves it; the agent task blocks on the receiver. Frontend: agentState.ts PendingApproval, ApprovalPrompt.tsx renders buttons, agentEventReducer.ts reduceApprovalRequest, useAgentEvents.ts wiring, Conversation.tsx renders it.

The ask_user tool mirrors this: a tool that emits AgentEvent::UserQuestion{responder: oneshot::Sender<UserAnswer>}, a PendingQuestions map holds the sender, a QuestionPrompt component renders clickable options + an always-present "Let's talk about it" freeform input, and an answer_question command resolves it. One-question-at-a-time is automatic (the tool blocks the turn on the oneshot). The two-questions example (skill mastery + favorite color) is the integration test.

UserAnswer = Choice(usize) | Freeform(String). The "Let's talk about it" is always Freeform — rendered alongside the N options. SafetyLevel::AutoRun (asking isn't a mutation). Available in all workflow states (like memory tools).
