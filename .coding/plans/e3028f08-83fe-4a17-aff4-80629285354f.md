# Plan: Collapsible syntax-highlighted JSON viewer for the Trace panel

## Goal
Replace the flat pretty-printed <pre> JSON in LlmTraceView (Raw-JSON request view + expanded message rows) with an interactive, collapsible, syntax-highlighted JSON tree component.

## Context
frontend/src/components/views/LlmTraceView.tsx renders request/response JSON as flat JSON.stringify(..., null, 2) in two places: (1) the REQUEST section's "Raw JSON" toggle (line ~330, full request body) and (2) MessageRow's expanded detail (line ~245, per-message JSON). The RESPONSE section stays as raw SSE text (not JSON). No JSON-viewer dependency exists in frontend/package.json; tests are pure node vitest suites (no DOM renderer — DiffView.test.ts imports only pure functions from the .tsx). Project convention for UI components: tailwind classes with muted slate palette + cyan accents, lucide-react icons, doc-comment header on exported components. Build must stay warning-free (cargo test for Rust unaffected, npm test + npm run build for frontend).

## Steps
- [x] 1. **Create JsonView component** — new file frontend/src/components/common/JsonView.tsx: a recursive, dependency-free JSON tree viewer. Exported `JsonView({ data, defaultDepth }: { data: unknown; defaultDepth?: number })`. Behavior: objects render as collapsible nodes (chevron toggle) with `{N keys}` preview when collapsed; arrays likewise with `[N items]`; nested children auto-expanded down to defaultDepth (default 1) and collapsed below it. Leaf values syntax-highlighted: strings emerald, numbers/booleans/null cyan/amber, keys slate with trailing colon; row uses a 1px indent guide. Pure React + tailwind, no dangerouslySetInnerHTML. Include a short doc comment.
- [x] 2. **Wire JsonView into LlmTraceView** — frontend/src/components/views/LlmTraceView.tsx: import JsonView from ../common/JsonView; replace the Raw JSON <pre> in RequestSection (currently `{JSON.stringify(req.request_json, null, 2)}`) with `<JsonView data={req.request_json} defaultDepth={2} />` (request body has messages/tools arrays — depth 2 keeps top-level chips visible and collapses per-message subtrees); replace MessageRow's expanded <pre> (`{JSON.stringify(msg, null, 2)}`) with `<JsonView data={msg} defaultDepth={1} />`. Keep the Raw/Smart toggle and chevrons as-is. Remove now-unused formatting helpers if any become dead.
- [x] 3. **Add unit tests** — frontend/src/components/common/JsonView.test.ts: export a pure helper from JsonView.tsx (e.g. `shouldAutoExpand(depth, defaultDepth)` or a `summarize(data)` count helper) and test it: nested object collapse depth logic, array key-count summary strings, null/primitive leaf handling. Register the file in frontend/vitest.config.ts include array.
- [x] 4. **Closing sequence** — run npm test AND npm run build in frontend/ (both green, tsc warning-free), run cargo test to confirm the Rust side is untouched-green, spawn a read-only reviewer on all uncommitted changes against this plan, fix every finding, re-run both suites, commit to the current feature branch.
