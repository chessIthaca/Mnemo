# Plan: Opt-in browser inspection (CDP) for release builds

## Goal
Replace the hard `#[cfg(debug_assertions)]` gate on the CDP debug port with an opt-in `enable_browser_inspection` config flag (default off), so the `game_*` tools work in release builds when the user explicitly enables browser inspection in Settings → Advanced and restarts. Debug builds remain always-on (unchanged).

## Kind
implementation

## Context
The game_* tools fail in release with "game inspection requires a debug build". Root cause: main.rs:42-46 sets WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9222 only under #[cfg(debug_assertions)], and ensure_webview (src/browser/mod.rs:660) fail-fasts with !cfg!(debug_assertions). This was a deliberate security gate (CDP on localhost is unauthenticated — HIGH finding in .coding/reviews/2026-11-22-cdp-attach-spike-review.md). User wants an opt-in Settings toggle instead of a hard debug-only gate.
