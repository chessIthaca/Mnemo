# Plan: Preserve Mnemo2 drafts and add image-aware busy steering

## Goal
Preserve Mnemo2 composer drafts across Lead/Team navigation and add Mnemo1-compatible image paste, busy typing/steering, and independent stop behavior, with direct Team-to-Mission-Control navigation.

## Kind
implementation

## Context
The user wants Mnemo1's composer behavior in Mnemo2. Verified: Composer.svelte keeps draft only in component-local state and disables send while busy; TopBar.svelte opens TeamPeek before Mission Control when clicked from Lead; store.sendLeadMessage drops busy submissions; LeadRuntime.send_prompt rejects busy turns and always sends empty images; SessionCommand::Steer currently discards images even though AgentCommand::Suggestion(SteerPayload) already supports them. Keep drafts in memory per open project (not persisted across application restart), including image attachments, and reset them on project switches. Team navigation must go directly to Mission Control; retain preview code only if unused, without making it a navigation stop. Reuse frontend/src/lib/attachImages.ts for pasted-image downscaling rather than copying its pipeline. Busy submissions must become queued steers injected at the next safe point, while Stop remains independently available and does not erase an unsent draft. Preserve pending-question answers and current interrupt behavior. This is a feature-scale correction to composer/navigation behavior; the busy/image command contract is high risk. Verification: cargo test --workspace and mnemo2 npm test/npm run check on the integrated tree. Preserve unrelated uncommitted work.

\## Acceptance scenarios
- Typing text and attaching an image, switching Lead → Team → Lead, restores the exact unsent draft and attachment; opening another project starts with an empty draft.
- Clicking Team from Lead immediately sets route=team, closes any peek, and renders Mission Control without first opening the right-side preview.
- While the native lead is busy, the textarea remains editable and both Steer and Stop are available; submitting text and/or images sends a steer rather than an error or a second prompt.
- A busy lead submission reaches AgentCommand::Suggestion with the same text and images, and is injected at the next safe boundary; an idle submission remains AgentCommand::Prompt.
- Image-only submissions are accepted; pasted images are downscaled through the shared attachment pipeline, shown as removable thumbnails, and included in the outgoing payload.
- Stop interrupts the active turn without submitting or clearing the in-flight draft.
- Existing pending-question answer behavior, legacy SessionCommand JSON without steer images, and unrelated lead/team flows remain compatible.
