# Plan: Non-blocking trace file writes

## Goal
Move traces.jsonl / provider-errors.jsonl mirroring off the request/streaming path onto a background writer thread, so enabling the trace log no longer slows the agent.

## Kind
implementation

## Context
src/provider/trace.rs `LlmRequestLog` mirrors records to disk synchronously: `start()` and every `with_record()` update (i.e. EVERY streamed SSE chunk via `append_response`) call `write_record_to_file`, which clones the full record, regex-redacts + re-serializes it, reads the ENTIRE existing traces.jsonl, parses every line to find the row by id, rewrites the whole file, and re-applies the user-only DACL — all under the `records` mutex on the streaming thread. `maybe_log_error` similarly does create_dir_all + append + restrict under the lock. This makes the agent crawl when "Log to file" is enabled. Design: agent path enqueues a cheap message (record id, or a pre-serialized error line) on an unbounded mpsc channel; a lazily-spawned background writer thread owns ALL redaction/serialization/disk I/O, coalescing dirty ids per drain into one batched read-modify-rewrite. All existing public method signatures stay unchanged; tests gain a `flush_file_writes()` to make async writes observable.

## Steps
- [x] 1. **Restructure `LlmRequestLog` into `Arc<Shared>` + lazy writer channel** — In src/provider/trace.rs: move `records`, `next_id`, `log_path`, `log_enabled`, `error_log_path`, `error_logged_ids` into a private `struct Shared`; `LlmRequestLog` becomes `{ shared: Arc<Shared>, writer: Mutex<Option<mpsc::Sender<Msg>>> }`. Add `enum Msg { Dirty(u64), ErrorLine(String), Flush(mpsc::Sender<()>) }`. Private `ensure_writer(&self)`: under the `writer` mutex, on first use create the channel, spawn the writer thread with `(Arc<Shared>, Receiver<Msg>)`, store the Sender. No Arc cycle (thread holds Arc<Shared>, not Arc<LlmRequestLog>); when the log drops, the Sender drops and the thread exits on recv error. Keep every public method signature identical.
- [x] 2. **Replace sync file writes with channel sends on the agent path** — In `start()` and `with_record()`: where `write_record_to_file(r)` is called today, instead `ensure_writer()` + `send(Msg::Dirty(r.id))` when `log_enabled` (ignore send errors). In `maybe_log_error()`: keep the dedup (`error_logged_ids`) + `LlmRequestSummary` serialize + `redact_text` on the caller (small, no payloads — microseconds), but send the finished line as `Msg::ErrorLine(line)` instead of doing create_dir_all/open/append/restrict inline. No `std::fs` remains on any path reachable from `start`/`with_record`.
- [x] 3. **Writer thread: coalescing drain + one batched rewrite per drain** — Add `fn writer_main(shared: Arc<Shared>, rx: Receiver<Msg>)`: `rx.recv()` then drain `try_recv()` into (BTreeSet<u64> dirty ids, Vec<String> error lines, Vec<Flush acks). Re-check `log_enabled` + `log_path` at write time (a toggle-off between enqueue and write skips the write, matching today's synchronous gating). Snapshot dirty records by cloning them under the `records` lock (ids evicted before snapshot are skipped — acceptable, document it). Generalize `write_record_to_file` into `write_records_to_file(path, &[LlmRequestRecord])`: ONE read of the existing file, replace/append all batch ids, ONE write, ONE `restrict_log_file`. Error lines: create_dir_all + append + `restrict_log_file` in the writer. Finally send `()` to every Flush ack.
- [x] 4. **Add `pub fn flush_file_writes(&self)` and wire shutdown** — New public method: doc-commented 'block until every queued file write has completed'; no-op when no writer was spawned; otherwise send `Msg::Flush(ack)` and `ack.recv()`. Call it at the top of `set_logging_enabled(false)` so the file is final once the checkbox turns off. In src-tauri/src/main.rs, if there is an app-exit hook (search for `RunEvent` / `.run(` / `on_exit`), call `trace.flush_file_writes()` there; if none exists, skip — dropping pending writes on exit matches the documented crash-tolerance tradeoff.
- [x] 5. **Update tests + docs for async mirroring** — In the trace.rs test module: call `log.flush_file_writes()` before EVERY `read_to_string`/`exists` assertion on traces.jsonl or provider-errors.jsonl (tests: file_logging_mirrors_latest_state_to_one_jsonl_row, file_logging_appends_distinct_requests_and_is_gated_by_toggle, error_log_appends_on_fail_and_dedupes, error_log_skips_successful_requests, error_log_is_always_on_without_trace_checkbox, error_log_transport_error_status_zero, traces_redact_api_key_in_request_body, traces_redact_authorization_in_response_body, traces_redact_json_key_in_response_case_insensitive, error_log_redacts_bearer_in_error_text, error_log_file_is_user_only, traces_file_is_user_only). Add a coalescing test: enable logging, start a record, call append_response ~50x, flush once, assert exactly ONE row holding the final concatenated text. Update the module doc + `write_records_to_file` doc: mirroring is asynchronous on a background thread, the file is eventually-latest per id, and a crash before the writer drains can lose the most recent state.
- [x] 6. **cargo test green + warning-free** — Run `cargo test` (PowerShell; read `test result:` lines / `$LASTEXITCODE` unpiped per agent.md). Fix any failures; `#![deny(warnings)]` means a green run also proves zero warnings.
