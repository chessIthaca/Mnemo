# Plan: LLM Trace tool page — request/response JSON inspector for cache-hit optimization

## Goal
A new "Trace" right-panel tool tab that records every request sent to the OpenAI-compatible /chat/completions endpoint (exact request JSON + raw response SSE) and shows them in a smart UI: collapsed message wall, usage/cached-token cards, and a per-message compare against the previous request to see what breaks the cache prefix.

## Context
Capture point: src/provider/openai.rs OpenAiClient::complete() builds the exact request body (build_request_json) and owns the raw SSE stream; cached_tokens is already parsed into LlmEvent::Usage. Providers are built via client_factory::build_openai_client (call sites: main.rs default provider, ipc/agent.rs set_model, model_resolver.rs build_turn_provider via build_provider_for; vision client passes None). IPC: commands registered in src-tauri/src/main.rs invoke_handler, shared state in src-tauri/src/ipc/state.rs IpcState. Frontend: right-panel tabs derive from the RightPanelTab union + ALL_RIGHT_PANEL_TABS in frontend/src/hooks/agentState.ts and the registry in frontend/src/hooks/rightPanelViews.tsx (rightPanelViews.test.ts auto-asserts registry/union sync). IPC wrappers in frontend/src/lib/tauri.ts, wire types in frontend/src/lib/types.ts. Vision + embedder requests are out of scope. No agent id available at the capture point (requests are globally ordered by monotonic id).
