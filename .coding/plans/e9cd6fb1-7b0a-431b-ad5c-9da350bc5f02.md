# Plan: Spike: two-tab handling + crash resistance (shared-env re-verify)

## Goal
A standalone throwaway Tauri spike proving (1) two add_child webviews in a bare WindowBuilder window switch tabs correctly (show/hide, draw order) and (2) a renderer crash in tab 1 leaves tab 2 alive (crash resistance under shared-env).

## Kind
research

## Context
Path (a) spike fa099902 previously proved tab switching + crash isolation GO, but a later spike (71bd2daa) found BOTH add_child webviews share ONE WebView2 environment (no CDP isolation). That casts doubt on whether crash isolation still holds with a shared env/browser-process. This spike re-verifies tab handling + crash resistance under the shared-env reality. Throwaway — no production source changes; spike/ dir is deleted after. Convention: prior spikes lived in spike/ at project root (now deleted).

## Steps
- [x] 1. **Scaffold standalone spike** — create spike/two-tab-crash/ with Cargo.toml (tauri 2 + tokio, no plugins), build.rs (`tauri_build::build()`), tauri.conf.json (productName, identifier, `windows: []`, dummy `frontendDist: "dist"`), and dist/index.html (empty `<html>`).
- [x] 2. **Write spike main.rs** — set WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9222 (debug only); bare `WindowBuilder::new("main")` + two ordered `add_child` webviews: tab1→https://example.com (created first, grabs 9222), tab2→https://example.org; show tab1/hide tab2 initially. Async self-test (tokio, 3s load delay): (a) switch tabs (hide tab1/show tab2, then back), (b) crash tab1 renderer via `eval` OOM (`for(;;)a.push(new Uint8Array(67108864))`), wait 6s, (c) survival check: `tab2.navigate(example.net)` returns Ok = shared browser process survived, (d) recreate tab1: `tab1.navigate(example.com)` returns Ok. Print `[PASS]/[FAIL]` report to stdout + spike-result.txt, then `app.exit(0)`. Use only confirmed APIs (show/hide/navigate/eval/add_child) — avoid Webview::url() (unconfirmed on child).
- [x] 3. **Build + run + observe** — `cargo run` in spike/two-tab-crash (debug build; first compile takes a few min — tauri recompiles standalone). Read stdout + spike-result.txt. If compile fails on an API mismatch (WindowBuilder::new signature, navigate/eval signature), fix and rerun.
- [x] 4. **Record findings + cleanup** — write the verdict (tab handling + crash resistance under shared-env: GO/NO-GO) to a semantic memory + .coding/spike-two-tab-crash.md, then delete the spike/two-tab-crash/ dir.
