# Plan: Show the splash indexing-progress dialog when switching projects

## Goal
When the user switches projects (ProjectPicker → switch_project → process restart), show the same splash-branded IndexingOverlay with the live "N/M files indexed" bar that cold start shows — instead of today's behavior where the overlay usually never appears on switch (events are 1s-gated and the freshly recreated webview subscribes late, so fast passes are entirely silent). Cold-start behavior (already-indexed project reopens silently) must not regress.

## Kind
implementation
