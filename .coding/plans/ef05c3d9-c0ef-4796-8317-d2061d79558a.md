# Plan: Fix tao keyboard deadlock (AppHangB1) — vendored backport + emit coalescing

## Goal
Eliminate the recurring AppHangB1 UI hang: backport tao PR #1215 (the upstream deadlock fix) onto the pinned tao 0.35.3 as a vendored 0.35.4 via [patch.crates-io], and add Rust-side delta coalescing to the agent event forwarder to cut the per-token IPC/WebView2 chatter that drives the inbound SEND triggering the deadlock.

## Kind

## Context
Root cause confirmed at source level (tao 0.35.3 in the cargo registry cache): public_window_callback takes KEY_EVENT_BUILDERS.lock() then calls process_message, which calls PeekMessageW while the lock is held; PeekMessage dispatches inbound sent messages, re-entering the window proc on the same thread, and parking_lot::Mutex is not reentrant → self-deadlock. Fixed upstream in tao 0.36.0 by PR #1215 (changelog c704261c) — the fix hoists the peek out of the locked region. Cannot upgrade: tauri-runtime-wry 2.11.4 (latest published, 2026-06-30) and wry 0.55.1 both require tao ^0.35; 0.36.0 doesn't satisfy it. Decision: backport PR #1215 onto the exact 0.35.3 the app runs (renumbered 0.35.4, vendored under vendor/tao, [patch.crates-io]) rather than forking 0.36.0 — 0.36.0 bundles unrelated breaking changes (window-subclassing removal #1231, keyboard refactor #1238, Android JNI renames). Second change: Rust-side delta coalescing in the agent event forwarder (src-tauri/src/ipc/events.rs, single choke point for agent://event) — batch TextDelta/ReasoningDelta/ToolCallArgDelta (flush on structural event / 16 ms timer / 64 KiB cap); the frontend already rAF-buffers deltas (useAgentEvents.ts hybrid flush policy), so concatenated payloads are frontend-invisible. ## Bug
AppHangB1 UI hang — main thread self-deadlocks in tao 0.35.3's KEY_EVENT_BUILDERS lock: typing while the agent streams makes KeyEventBuilder::process_message call PeekMessageW under the lock, which dispatches an inbound SEND (WebView2 COM marshalling) that re-enters public_window_callback on the same thread and re-locks the non-reentrant parking_lot mutex. 3 byte-identical hang reports (.coding/logs/hang-1787574592659.txt, hang-1787575710423.txt, hang-1787586964715.txt), 3 different PIDs, episode 1 each, 0% CPU — permanent self-deadlock, not a transient stall.
