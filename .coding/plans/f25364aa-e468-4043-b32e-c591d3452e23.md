# Plan: Persist window geometry + colors/fonts + resizable tools panel

## Goal
Three related UX improvements: (1) persist the app window's size + position across restarts, (2) add a "Reset" button in the Settings dialog that restores all appearance prefs (theme, font, colors) to defaults, and (3) make the right tools panel width user-resizable via a drag handle, with the width persisted.

## Context
The app is a Tauri 2 + React + Zustand frontend. Window geometry is currently fixed in tauri.conf.json (1200x720, centered). Display prefs (font family/size, theme, 11 colors) already persist to localStorage via the store setters in useAgentStore.ts. The ConfigDialog.tsx already has a "Reset" button but it only resets Colors (resetColors), not theme/font. The right panel (RightPanel.tsx) has a fixed `w-2/5 min-w-[300px]` width with no drag handle. Tauri's core:window:default permission is enabled (includes set-position/set-size/outer-position/outer-size). The frontend uses @tauri-apps/api v2. There are no existing window-API imports in the frontend. The store has readLs/writeLs helpers and a clear pattern for persisted prefs.

## Steps
- [x] 1. 1. Window geometry persistence (frontend): In App.tsx, on mount read persisted window geometry (x, y, width, height, maximized) from localStorage; if present and not maximized, apply via the Tauri window API (getCurrentWindow().setPosition/setSize). Add a beforeunload + window resize/move listener (debounced) that saves the current outer position + outer size + maximized state to localStorage. Skip saving when maximized (keep the last normal bounds). Add the @tauri-apps/api/window import.
- [x] 2. 2. Resizable tools panel (frontend): Add a `rightPanelWidth` persisted number (px) to the store (localStorage-backed, default null = use the existing 40% via flex-grow). Add a `setRightPanelWidth` setter. In App.tsx, render a vertical drag handle between the main column and RightPanel; dragging it updates rightPanelWidth. Apply rightPanelWidth as an explicit pixel width on RightPanel (replacing w-2/5), clamped to [300, window.innerWidth*0.8]. Persist on drag-end (debounced).
- [x] 3. 3. Reset-all button in Settings (frontend): Add a `resetAppearance` store action that resets theme, font family, font size, AND all colors to defaults (reusing the existing DEFAULT_* constants + apply* helpers). In ConfigDialog.tsx, promote the existing Colors-only Reset into a single 'Reset all appearance' button (or add a second reset for appearance) that calls resetAppearance. Keep the live preview updating.
- [x] 4. 4. Build + typecheck: run `npm run build` (tsc + vite) in frontend/ to confirm no type errors, then `cargo test` from the project root.
- [x] 5. 5. Review + commit: spawn a read-only reviewer subagent over all uncommitted changes, write findings to .coding/reviews/, fix every finding, re-run cargo test, then commit to the current feature branch.
