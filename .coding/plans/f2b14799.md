# Plan: reasoning_effort 'off' wire encoding: config-overridable DeepSeek none-mapping

## Goal
Make the reasoning_effort "off" wire encoding config-overridable: add endpoint/model-level `reasoning_effort_off_wire` (the wire value "off" encodes as; model-level wins over endpoint-level) that overrides the built-in kind+name DeepSeek→"none" policy, which remains as the zero-config fallback — so renamed/aliased/fine-tuned DeepSeek models can be fixed by config instead of losing the mapping (instant non-retryable 400 on "off"). Thread it through both resolvers + the request builder, preserve it across Settings saves via apply_endpoints carry-over, add the four regression-test shapes from the task, and update docs (README config paragraph, policy.rs comments, PLAN.md quirk note if present).
