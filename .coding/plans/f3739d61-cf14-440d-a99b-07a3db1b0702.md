# Plan: Live turn phases, timer, token counter + per-trace phase timings

## Goal
Live turn-phase indicator replacing the static "thinking…": the InflightBar cycles through sending → waiting → thinking → running tools (with approval/question overrides), shows a live elapsed timer ("1m 3s" / "22s") and a live tokens-received counter; and every LLM trace entry records the time spent in each phase (send / wait / generation / tools).
