# Plan: kNN overlay classifier for failure triage — genuinely online learning (Laya item 4b)

## Goal
Ship the kNN overlay classifier for failure triage (Laya item 4b): KnnClassifier implementing the existing Classifier trait, slotted into the existing FailureTriageHandle gate (consulted before the shared Laya classifier slot, no new classifier swap sites, no triage-call-site changes). It embeds each incoming failure text with the app's existing live Embedder (the shared embedder slot), retrieves the k most similar logged failures from the failure-triage training log (<global_config_dir>/laya/training/failure_triage.jsonl), and majority-votes the class with vote-share as the confidence — genuinely online learning: the index builds from the JSONL at startup (lazily on first consult) and picks up appended dispositions without a restart. Opt-in flag laya.failure_triage_knn (default off), independent of the Laya endpoint; with it off the behavior is byte-identical to today.
