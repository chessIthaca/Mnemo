# Plan: Refined subagent permission model: all states spawn, subagent ⊆ parent, state-transition gate on running descendants

## Goal
Refine the subagent permission model: (1) all workflow states can spawn subagents; (2) a subagent's tool surface is a subset of the spawning agent's current permissions (roles restrict further; read-only role tools like write_review_report/git_diff are exempt); (3) the agent cannot change workflow state while spawned subagents are running.

## Context
REFINED PERMISSION MODEL (per user clarification):
1. ALL workflow states can spawn subagents (not just Complete) — spawn_agent must be visible in Planning + Complete too (it's already visible in Executing/Reviewing since those allow all Agent tools).
2. Subagent permissions ⊆ parent's CURRENT permissions. A subagent can never have a tool the spawning agent doesn't currently have (e.g. a subagent spawned from Planning can't get file_edit, since Planning hides file_edit). Roles can only restrict further (reviewer = read-only ∩ parent).
3. EXCEPTION: special role tools that are read-only/AutoRun (write_review_report, git_diff) can be granted to a role even if the parent doesn't have them — they're safe (sandboxed output / read-only diff). Verified: both are SafetyLevel::AutoRun.
4. GATE: the agent cannot change workflow state AT ALL while spawned subagents are running — applies to every state transition (create_plan, skill_start, abandon_plan, finish, complete_step that completes the plan, skill_end, abandon_skill). Wait for all descendants before any transition.

Key existing pieces:
- `AgentManager::has_running_descendants(id)` (src/runtime/mod.rs:140) already walks the parent_id chain — the right check.
- `AgentSpawner` trait (src/runtime/mod.rs:183) is the decoupling pattern: brain defines trait, IPC provides impl. Mirror for descendant tracking.
- `IpcSpawner` (src-tauri/src/ipc/spawn.rs:198) already holds `Arc<Mutex<AgentManager>>` — implements the new trait directly.
- `AgentLoopFactory::set_spawner` (src/agent/factory.rs:187) is the wiring pattern — add `set_descendant_tracker` alongside.
- `spawn_agent_shared` (src-tauri/src/ipc/spawn.rs:80) is where the subagent's tool_allowlist is set (line 142 for reviewer role). This is where the subset intersection must happen.
- `Workflow::allowed_tools()` (src/workflow/mod.rs:259) returns the ToolFilter; the subagent's allow-list overrides it. The intersection must be computed at spawn time against the PARENT's current filter.
- The parent's current filter = the spawning agent's `workflow.allowed_tools()` at spawn time. The spawner (IpcSpawner) has access to the parent's AgentLoop via `agent_loops` map (it already reads `agent_loop.workflow_handle()` in spawn.rs:122).
