# Plan: Reviewer-only report authorship: main agent can never review code

## Goal
Make it structurally impossible for the main agent to author a code review. The only way a review report can be written is through a spawned agent constructed with role:"reviewer" (whose strict ToolFilter::Reviewer allow-list includes write_review_report). Enforce at three layers: (1) ToolFilter — write_review_report is visible ONLY under ToolFilter::Reviewer; every base state (Planning/Executing/Reviewing/Complete) and every Skill list denies it; (2) Sandbox — .coding/reviews/ becomes a protected write target for the file tools (file_write/file_edit/file_append/convert_line_endings) so the main agent cannot fabricate a report through file writes; (3) Protocol — the "self-review" fallback is deleted from the failed-reviewer instructions (dispatch error text, system-prompt APP_RULES, Reviewing state block, agent.md). Additionally, add abandon_plan to the Reviewing filter so an un-completable review is escapable (the main agent can abandon the plan and return to Planning) — the main agent is never stuck in Reviewing. The reviewer capability remains constructor-only: role validation restricts to "reviewer" and the reviewer allow-list is granted only via set_reviewer_allowlist on the spawn path.
