# Plan: InflightBar UX fixes

## Goal
Fix four InflightBar UX issues: (1) show session weighted-mean tok/sec instead of per-request, (2) add a hover popup on the ctx bar showing the context breakdown (prompt/completion/reasoning/cached), (3) show the bar from the start (before the first prompt), (4) keep the reasoning expand chevron visible when idle if there's reasoning content.

## Context
Explored the InflightBar (frontend/src/components/chat/InflightBar.tsx) + the reducer (agentEventReducer.ts) + agentState.ts. Four UX issues:

1. TOK/SEC IS PER-REQUEST, NOT SESSION MEAN: The bar shows lastRequestTiming.input_tok_sec/output_tok_sec (the latest Usage event). The user wants the session weighted mean (prompt_tokens / avg_ttft_s), like StatsView computes. The reducer's reduceUsage accumulates tokenUsage per-turn but reduceStarted resets it. Need a session-level accumulator (ttft_ms_total + generation_ms_total + timed_requests + prompt/completion totals) that persists across turns (reset only on clearConversation, not on Started).

2. CTX POPUP ON HOVER: The ctx bar has a basic title attr. The user wants a rich popup (like Hermes) showing the context breakdown: prompt/completion/reasoning/cached. The Usage event carries these; need to track the last request's breakdown (lastContextBreakdown) for the popup.

3. NUMBERS MISSING UNTIL AFTER FIRST PROMPT: The bar hides when !running && !hasActivity && !hasTokens && !hasContext (line 104). Before the first prompt, everything is 0 → bar hidden. The user wants it visible from the start.

4. REASONING CHEVRON MISSING DURING IDLE: The expand chevron only shows when hasActivity (line 142). After a turn finishes, the reasoning stays in activityLog (cleared only on next Started), so hasActivity should be true — but the bar hides when idle+no-tokens+no-ctx. The user wants the chevron (to expand/collapse reasoning) always visible when there's reasoning content, even when idle.

StatsView already computes the weighted mean: avgInputRate = prompt_tokens / (avgTtft/1000) where avgTtft = ttft_ms_total / timed_requests. Mirror that.
