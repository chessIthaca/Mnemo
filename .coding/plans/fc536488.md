# Plan: Remove mission control's manual dispatch bar

## Goal
Mission control no longer has its own dispatch form; all work starts through the lead (Claude Code or Mnemo2's built-in lead).

## Kind
implementation

## Context
Why: the user looked at mission control's second row (plan picker, step picker, brief box, model and effort pickers, Dispatch button) and decided: "it is plain just not needed. All work should start through the lead, whether that is claude or mnemo2's own lead."

Verified facts:
- verified: the row is the `<form class="dispatch-bar">` in `mnemo2/src/components/ControlRoom.svelte` (line ~187) with state `dispatching`, `brief`, plan/step pickers, `workerModel`/`chosenEffort`, `canDispatch` (~113) and `dispatch()` (~125) calling `actions.dispatchWorker(...)`; when no plan is open it shows `<p class="dispatch-empty">No open plan — ask the lead to plan the work first.</p>` (~185); styles `.dispatch-bar`, `.dispatch-empty`, `.dispatch-model` (~253-258).
- verified: `dispatchWorker` lives in `mnemo2/src/lib/store.ts` (~line 1774) and is only called from ControlRoom (grep of components and store).
- verified: the leads dispatch through other paths (Claude Code via the MCP `team_dispatch` tool; the built-in lead via its team tools in the engine), which this change must not touch.

Decisions:
- Remove the form, its state, pickers, styles and the empty-plan line from `ControlRoom.svelte`; the header (title, live/slots chip, Stop all, Delete old) and the worker list/output split stay exactly as they are.
- Remove `dispatchWorker` from `store.ts` and the actions object if nothing else uses it, plus the frontend transport method only if it has no other caller; keep the backend `team_dispatch` IPC command (the built-in lead and tests may use it) unless grep proves it unused, and say what you found.
- Update or delete the tests that exercised the bar (ControlRoom tests, store dispatch tests) and the mission-control preview scene if it seeds dispatch state.
- Theme tokens only for any remaining style.
- Another worker is editing `store.ts` (the width setters around `clampWorkbenchWidth`/`clampBoardWidth` and the preference payload); keep your `store.ts` edits to the dispatch function and its export.

Verification: in `mnemo2/`: `npx svelte-check --tsconfig ./tsconfig.json`, `npm run check:no-mock`, `npx vitest run`; `cargo test --manifest-path src-tauri/Cargo.toml --features mnemo2 --lib mnemo2::` only if Rust changes. Never start a dev server or any command that does not exit on its own.
