# Plan: Write review report + address partial-output finding

## Goal
Write the review report to .coding/reviews/ and address the one finding: surface a non-fatal note when a mid-stream error arrives after partial output (text/tool-calls), so the stream truncation is visible without stopping the agent or killing the turn.

## Context
Self-review of the mid-stream error retry fix found one finding: the partial-output case. Previously the LlmEvent::Error handler emitted AgentEvent::Error { retrying: false } unconditionally — which was itself buggy (it set running=false in the UI mid-turn while the turn kept running). My change removed that emit entirely, which fixes the no-output case (now returns Err → outer retry) but leaves the partial-output case silently swallowing the error with no user-visible signal that the stream was truncated. The fix: emit a non-fatal note for the partial-output case so the user knows the stream was truncated, without stopping the agent (the partial output is still used).
