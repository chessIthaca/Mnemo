## Observations (no action required)

1. **FTS-phrase ≠ substring is a known, accepted approximation — not a defect.** Following the TIP (regex→`literal:true`) can change the match set at token granularity (regex `hello` matches inside `xxhelloxx`; an FTS phrase does not; a punctuation-joined pattern like `foo-bar` can over-match `foo bar`). This is the same approximation that already governs every `literal:true` index answer since 2da09da (documented at search.rs:612-616), and D1 explicitly cites non-equivalence as the reason the TIP is advisory and never auto-routed. The TIP's text only claims an engine switch, which is true.
2. **Symlinked directories are no longer traversed by the walk** (`DirEntry::file_type().is_dir()` is symlink-unaware, so dir-symlinks fall through to `is_file()` and are skipped). This is a deliberate narrowing (documented in `walk_searchable`) and it ALIGNS the walk with the index coverage walker (codegraph walk.rs `visit` uses the same `file_type().is_dir()` check and documents the same rule) — the old glob walk followed dir-symlinks while the index never did, so the old engines were inconsistent; now they agree. Symlinked files are still searched (`path.is_file()` follows), matching old behavior.
3. **`merged_note`'s "at most two of the three can co-occur in practice" is loose** — static analysis shows at most ONE component can ever be Some (fallback requires metachars ⇒ TIP ineligible; nudge requires identifier/prefix shape ⇒ no metachars ⇒ no fallback; TIP suppressed under nudge). The uniform 3-way join is harmless future-proofing; the doc comment is just conservative rather than wrong.
4. **`strip_definition_prefix` misses `const fn foo` / `extern "C" fn foo`** (single keyword + modifier list only; `const fn foo` strips `const ` then requires a bare identifier and returns None). Advisory-only, precision-over-recall, and pinned negative tests cover the shape — acceptable as designed.
5. **Compile/test status**: every new item was statically checked for compile-consistency (signatures, array lengths 6, indexes 0-5, closure/borrow shapes, `io::Error::other` fn-arg form, array `into_iter().flatten()`); no issues found — but the matrix run is still owed by the main agent (plan step 6), including `cd src-tauri; cargo build`.
