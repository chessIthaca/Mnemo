### Design note — NOT a finding (no action required)

**Finish with an unchecked appended step → restart re-derives Executing, not Complete.** Because `complete_step` is hidden mid-review, the only in-session exit after appending is `finish()` with the step still unchecked; `load_latest` then derives Executing from `is_complete() == false` (the persisted `reviewed` flag only matters when the plan is complete, mod.rs:1247-1257), so a restart resurrects the finished plan as in-flight — the agent completes the step, returns to Reviewing (`reviewed=false`), and re-reviews/re-finishes. Traced and assessed as deliberate, not a defect: (a) it is the exact flip side of the crash-resumption feature the backlog item asked for ("a crash mid-follow-on loses the step tracking" was the problem being fixed — the plan file's KEY SEMANTICS documents this derivation explicitly); (b) it is byte-for-byte the semantics implementation plans have had since 2026-12-23 (plan aa653afc / backlog 24e1c98e — its PASS review records "appended steps stay unchecked through the exit" as the contract); (c) it is safe — self-healing, the review is never skipped, no data loss, and the state machine errs conservative. A future refinement could have `load_latest` consult `reviewed` before `is_complete()` (the flag does distinguish "crashed mid-follow-on" from "finished with an unchecked appended step"), but that is a cross-kind behavioral change deserving its own plan, not a fix owed by this diff. Recorded here so the characteristic is on the record.

### Security

- The append window cannot be used to dodge the review: the only path to Complete remains `finish()` (gated on a reviewer-authored PASS report), and any restart out of the appended-step state re-enters Reviewing with `reviewed=false`.
- The reviewer subagent surface is unchanged and untouched: `ToolFilter::Reviewer`'s strict allow-list never names `update_plan`, and every subagent runs with `plan_mutations_allowed(false)` — a reviewer cannot append steps to launder its own findings.
- No new file, network, or shell surface; the change only relaxes a plan-mutation rule for the main agent inside an already-privileged state, behind the existing resumability gate.
