### Requested c26e41e regression checks — all three resolve clean

**1. Read-then-write gap (874→880) — no await, microseconds, every interleaving converges.** The read-clone, the pure predicate, and the restore write are consecutive synchronous statements; no lock is held across them (the read guard drops at the end of the statement; the config mutex was released at 830; the child lock is never taken in this arm — no nesting is possible). The full interleave map:

- **(i) A concurrent writer X lands in the µs gap after our read saw our own progress state** → the restore buries X with `pre_setup`. For every X with a live writer the dishonesty is bounded and self-correcting: X = a rewire's `Starting` (rewire.rs:114-115) → its `start_managed_server` probe still writes its generation-gated terminal `Ready`/`Failed` later (laya.rs:990-1027) → converges; X = a `classify()` self-heal → a client exists in the slot, the next call rewrites (classifier.rs:360-364) → converges; X = a second setup's `Installing`/`Downloading("uv")` → its next own write corrects within seconds (see check 3). The one X with no remaining writer is a *terminal* value from a None-slot external flip (`Disabled`/`Failed`, client_factory.rs:387/401) landing inside the µs gap — the strict-subset residual of round-4 (b), now confined to a microsecond coincidence instead of firing unconditionally on any timing (see residual R1 below). Accepted.
- **(ii) A writer lands after our write** → their value wins, and it is by definition the newest honest writer. If it lands between our write and our emit, one stale event may briefly order after theirs — the status lock holds the truth and the next emit corrects; this write-then-emit shape is shared by every status writer in the file (`emit_download` 495-503, `start_managed_server` 975-997, the rewire mirror rewire.rs:179-181) and is not introduced by c26e41e.
- **(iii) Our read sees a concurrent writer's value** → predicate false → no write → the honest value stands untouched. This is the round-4 (b) cure: a rewire's `Starting`, a winner's `Ready`, a terminal `Failed`/`Disabled`, a live classifier's self-heal, a second setup's `Downloading{cp2}` — all now survive, where pre-c26e41e each was clobbered.
- **(iv) No concurrent writer** → `current` is our own last tick → the restore fires → the R3 contract holds.

Round 4 accepted precisely this shape of residual TOCTOU for `owns_generation` ("no await between check and write; last-writer-wins window is microseconds; every interleaving converges — not a finding"). The gap here is the same class and strictly smaller than what it replaced.

### Accepted residuals (non-findings, documented for the record)

Both are strict subsets of manifestations inside the round-4 LOW, unchanged-or-narrower under c26e41e, display-only, and self-healing — flagged here so the map is complete, not as required fixes:

- **R1 — buried terminal writer.** A mid-setup save that flips to a None-slot world (external-without-endpoint, or managed-with-uninstalled-checkpoint; the plain disable case is already handled honestly by the `laya_off` arm) writes its terminal `Disabled` *before* the pipeline's final tick → the pipeline's own subsequent ticks bury it → at completion `current` is our own tick → the predicate is true → the restore resurrects the pre-flip snapshot (e.g. a stale `Ready`). The predicate inspects only `current`, so it cannot see a writer that our own earlier ticks buried — the inherent limit of snapshot-restore. Impact: a stale badge only — `Ready` is not busy (ClassifierSection.tsx:104-106), the slot is correctly `None` so no calls are ever made — and the next save or restart corrects it. Pre-c26e41e this fired on *every* timing of that flip; now only the buried-before-final-tick timing remains. If it is ever worth hardening, the one-line close is to validate the snapshot side (skip the restore when `pre_setup_status` is itself a transient) or re-derive `Disabled` when the slot is empty — optional polish, not required.
- **R2 — poisoned snapshot.** The snapshot (820-823) can catch a rewire probe mid-flight (its `Starting` or a `Downloading` tick); if that probe's terminal write later lands mid-pipeline and our ticks bury it, the restore resurrects the stale *transient* — a busy badge until the next `classify()` (the rewire left a client in the slot, so the self-heal exists). Requires the probe to be in flight at the µs snapshot moment; the current-value manifestation of round-4 (a) is cured, only the buried-write variant remains.
