### LOW-2 (approval-arm drain hole) — FIXED; the fix code is correct

- **drain_run_all_on_main_exit** (run_all.rs:1521-1546): the `run_all` tokio guard is scoped to a block that only reads `current_item` (std mutex, statement-scoped) and drops before any store access; the store lock is taken and dropped for the annotate; `end_run` then re-takes `run_all` (its guard is a statement-scoped temporary dropped before `emit_backlog_changed`).
