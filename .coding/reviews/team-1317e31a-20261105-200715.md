### BUG: v2.0.0 CI round 3 — tauri default-run + macOS-only dead code under deny(warnings)

Fixed on wt/agent-macDeadC @ 043b128b (plan 1317e31a, step 1), addressing build.yml run 42032429722 on the 2.0.0 branch.

Three distinct root causes, all only observable in CI (Windows tauri job / macOS test job):

1. Tauri default-run. src-tauri/Cargo.toml now declares three feature-gated [[bin]] helpers beside the app binary (mnemo2, mnemo2-mcp, mnemo2_route_eval, each required-features=["mnemo2"]). With more than one bin candidate, `tauri build` fails: "failed to find main binary, make sure you have a `package > default-run` in the Cargo.toml file". Fix: `default-run = "mnemo-app"` in [package]. Verify with `cargo metadata --format-version 1 --no-deps --manifest-path src-tauri/Cargo.toml` → packages[mnemo-app].default_run == "mnemo-app". NOTE: adding any future [[bin]] to src-tauri keeps working only because of this key.

2. macOS unused import. src-tauri/src/main.rs imported `global_config_dir` in the shared `use mnemo::config::{...}`, but its only use was inside `#[cfg(windows)] fn browser_inspection_enabled()`. On macOS/Linux that import is unused and `#![deny(warnings)]` (crate root of main.rs) fails the build. Fix: drop it from the shared use and call `mnemo::config::global_config_dir()` by full path inside the Windows-only fn. General rule for this repo: any import used only inside a cfg(windows) item must NOT sit in a shared `use` — it will break macOS CI, which Windows dev never sees.

3. macOS dead test helper. src/host/laya.rs `LayaManager::with_serve_command` was `#[cfg(test)]`, but its only caller is the `#[cfg(windows)]` test `stopping_the_manager_kills_the_server_tree`, so non-Windows test builds reported "method with_serve_command is never used". Fix: `#[cfg(all(test, windows))]`. The `serve_override` field it sets keeps plain `#[cfg(test)]` — it is read inside `spawn_server`'s own `#[cfg(test)]` blocks (not Windows-gated), so it stays used on every test build and needs no gating.

Re-store any durable fact above without plan/branch references.
