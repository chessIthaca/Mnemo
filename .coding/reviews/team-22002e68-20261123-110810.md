Guard: Rust integration test `build_workflow_tauri_cli_is_declared_and_locked` in tests/integration/ci_workflow.rs parses build.yml, root package.json + every workspaces package.json, and the lockfile bin entry. Lesson: any new external CLI a release workflow calls must be declared in a workspace package and guarded by a ci_workflow test, since PR CI does not execute release workflows.
