### HOW: mnemo2 TS has no Node types — share Node code via .mjs + .d.mts

mnemo2's TypeScript program (mnemo2/tsconfig.json, `types: ["vite/client"]`) has NO @types/node — `npm ls @types/node` is empty and no .ts file in the repo imports `node:*`; an import like `node:os` fails `npm run check --workspace mnemo2` with "Cannot find name 'node:os'". Node-API code that vitest.config.ts or mnemo2 tests must share therefore lives in plain .mjs with a sibling .d.mts declaration (pattern used by scripts/test-tmp.mjs + scripts/test-tmp.d.mts for plan 35105099): the .ts side imports the typed .mjs. Never add @types/node or ambient shims without a plan decision.
