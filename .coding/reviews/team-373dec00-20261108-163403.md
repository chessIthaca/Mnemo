### HOW: the memory check pass — `.coding/knowledge/HEALTH.md` and the `[cites moved paths]` hit note (plan 373dec00 step 5)

`src/memory/health.rs::run(store, workspace_root)` is a deterministic, model-free pass over `.coding/knowledge/{spec,decision,bug,how}/*.md`. It checks: cited repo paths that no longer exist (citation regex `\b((?:src|src-tauri|mnemo2|frontend|tests|scripts|docs)/[\w./-]+\.\w+)`; URLs and `[[links]]` blanked first), unresolved `[[links]]`, duplicate titles (semantic typed live rows, same record type AND normalized title), and agent.md size per `Constitution::scoped` (Classic/Team) against 200 lines / 25 KB. It writes `.coding/knowledge/HEALTH.md` (only when its bytes change) and caches rename resolutions in `.coding/knowledge/.health-state.json` (`{"version":1,"resolved":{"<from>":"<to>"|null}}`), so a warm pass spawns no git. Renames resolve in two steps: `git log -1 --diff-filter=D --format=%H -- <path>` then `git diff-tree -r -M --name-status --no-commit-id <commit>` (`R### old new`); chains up to 5 hops. `git log --follow --diff-filter=R` alone finds nothing for a renamed-away path.

Affected knowledge rows get `data.moved_paths: [{from, to|null}]`, which `memory_search` renders as `[cites moved paths: a -> b; c gone]` (max 4, then `+N more`). Authored bodies are never edited. Recomputed every pass; dropped when no longer stale.

Wiring: only the Mnemo2 app runs it (`src-tauri/src/mnemo2/indexing.rs::spawn_memory_health`, after a 1.5 s quiet window because an in-sync reconcile emits no event), reporting on the Memory status line as `health: …`; a failure never fails the open. `Engine::workspace_root()` was added for it.

Trap (this cost two runtime-test failures): the pass must NOT create `.coding` in a project that has none — the guard is `knowledge_dir.is_dir()`, because an untracked `.coding/knowledge/HEALTH.md` dirties the lead's working tree and trips the clean-tree merge gate. Generated files are also appended to the repository's local `.git/info/exclude` (`ensure_excluded`), mirroring the app's `ignore_project_caches`.

First run on the 2026-11-08 worktree: 111 records cite missing paths, 18 unresolved links, 0 duplicate titles (plan expected ~106).

### HOW: Duplicate plan/review digests are retired by the startup sweep, and what that bought (plan 373dec00 step 12)
