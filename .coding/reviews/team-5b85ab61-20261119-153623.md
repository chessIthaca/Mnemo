### HOW: shell timeout tests in src/tool/agent/shell.rs must measure the shell boot, not use a fixed window

The shell-tool limit tests in src/tool/agent/shell.rs (chatty/silent/hard-cap/tree-kill, plan 5b85ab61) depend on a command's FIRST output landing inside its silence window. A PowerShell boot on the Windows box measured ~1.7 s idle but more than 8 s when the suite spawns shells in parallel or other builds run, so every fixed window was flaky. The tests now call `measured_shell_boot(dir)` (times `echo boot`) and size the window with `silence_window(boot) = (boot*4 + 8s).min(30s)`; hold commands sleep/ping for 300 s so the deadline always ends the run first, and the kill reason is platform-dependent (chatty grandchild ⇒ hard cap, silent ⇒ silence). Keep that pattern for any new limit test.
