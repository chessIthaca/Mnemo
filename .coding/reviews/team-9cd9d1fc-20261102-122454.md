Phases: A check batch → B stop live → C re-check SURVIVORS ONLY (batch = survivor set, so shared-branch flags never let a survivor touch git state of a worker that failed an earlier phase) → D delete each (no `?` early-return). `Self::deletion_decision(preview, discard_work)` replaced check_deletion.

Per-worker checks (rev-parse + `git status --porcelain --untracked-files=normal`, never -uall) run in tokio tasks bounded by DELETION_CHECK_CONCURRENCY=4.
