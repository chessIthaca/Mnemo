### DECISION: Mnemo2 trace backend (plan c3ba2b58 step B) — kernel seam, spawn signature, scope/UTC/deletion semantics

Step B of plan c3ba2b58 (Mnemo2 trace backend) landed on wt/agent-traceBac commit 0cf6b90f. Decisions made inside the frozen contract that reviewers/integration should know:

1. Two kernel touches were REQUIRED and are purely additive (no wire change, Mnemo1 untouched): (a) `TraceApi` (src/headless/stats.rs) gained pass-throughs run_id/set_ring_capacity/ring_capacity/logging_enabled/set_logging_enabled — step A added the LlmRequestLog methods but never exposed them through the headless wrapper, and src-tauri can only reach the log via Engine::trace(); (b) the trace wire types (LlmUsage, TraceAttribution, RawToolCallRecord, LlmRequestRecord, GuardCutDetails, LlmRequestSummary) derive Deserialize so the metadata journal and traces-history lines round-trip — without them, journal reload would need a drifting local mirror type.

2. spawn_worker_session (team.rs) dropped its `name: String` param: the display name now comes from trace_identity.agent_name (identical value at every call site — the WorkerRecord name). Reason: clippy too_many_arguments (8/7) under deny(warnings); folding is principled, not a workaround.

3. Search scope semantics: "reasoning" searches the raw streamed response (reasoning arrives inside response_raw — same corpus as "response"); the "metadata" scope NEVER falls through to payloads, and retained journal-only rows can match only metadata text under "all"/"metadata".

4. Export file names trace-<YYYYMMDD-HHMMSS>.jsonl are UTC (the workspace has no chrono; the manifest carries exported_at_ms for local rendering); same-second collisions get a -N suffix.

5. trace_delete_history removes BOTH retained tiers: the metadata journal (trace-index.jsonl + .1-.4) AND the opt-in body history (traces-history.jsonl + traces-history-<micros>.jsonl) — the design's open question about bodies in the deletion was resolved "include them, normal confirmation". A journal floor (floor_ts_ms = now at delete) prevents the live ring from re-journaling pre-delete calls.

6. Pricing: pricing.rs is the one rule (extracted from usage.rs where insights imported it); a priced model with NO usage costs an honest Some(0), an unpriced model is None (dash, never $0). team.rs's usage_cost_micros (explicit-rows-only worker telemetry helper, no vendor fallback) was deliberately LEFT AS-IS — changing it alters worker telemetry numbers, outside step B's scope; flagged as follow-up.

7. Cursor: opaque "ts_ms:run_id:id" (run ids contain no colons); a cursor naming a key past the newest row returns an empty page, never a wrap-around.

Structure: TraceSupport (ring 128 + journal + 2s writer task) lives in trace_view.rs, held by LeadRuntime.trace_support (set in start_engine, taken in shutdown); TraceJournal state (rows/keys/floor) is a Mutex with the whole query evaluation under one lock (no lock inversion: poll takes kernel locks before the journal lock).
