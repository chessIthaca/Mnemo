### BUG: v2.0.0 tag build — unix O_NOFOLLOW typed u32 (macOS E0308) + racy savings-ledger test

Two independent failures in GitHub Actions run 42024034982 (v2.0.0 tag build), fixed in commit b81e0fdd on wt/agent-tagBuild (plan d283d36f).

1) src-tauri/src/mnemo2/workbench.rs `read_regular_file`: the `#[cfg(target_os = "linux")]` and `#[cfg(target_os = "macos")]` blocks declared `const O_NOFOLLOW: u32`, but `std::os::unix::fs::OpenOptionsExt::custom_flags` takes `i32` (only the Windows extension takes `u32`, which is why the `#[cfg(windows)]` block above is correct as u32). macOS `cargo build -p mnemo-app --features mnemo2 --bin mnemo2` failed E0308 at workbench.rs:402. Fix: both unix constants are now `i32` (linux 0x20000, macOS 0x100; values unchanged). Windows never compiles those blocks, so a Windows-only local check cannot catch this — a linux/macos target (or CI) is the only proof; on this machine no linux target is installed.

2) src/agent/tests.rs `recall_delta_all_elided_set_costs_one_sentinel_line` read `store.savings_events_rows(None)` immediately after the turns, but `AgentLoop::record_savings_event` (src/agent/turn.rs ~4450) writes the durable row in a `tokio::spawn` (fire-and-forget by design — production code NOT changed), so on a slow runner the row is not there yet ("a savings row names the sentinel: []"). Fix: one shared private helper `wait_for_savings_row(store: &Arc<dyn MemoryStoreTrait>, matches: impl Fn(&SavingsEvent) -> bool, timeout: std::time::Duration) -> Vec<SavingsEvent>` polls `savings_events_rows(None)` every 25 ms up to 5 s and returns the matching read (or the last read on timeout, so the caller's own assertion still reports the ledger). Used by the sentinel test, `recall_delta_elides_a_repeat_recall_but_not_a_new_one` (replacing its hand-rolled 50×20 ms loop), and `savings_and_spend_emitted_where_persisted` (replacing a fixed 100 ms sleep). Lesson: any test asserting on the savings ledger right after a turn must poll, never read once or sleep a fixed interval.

Re-store any durable fact above without plan/branch references.
